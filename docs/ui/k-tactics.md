# K 무공창: 행동력·내기·범위와4칸 편성

기존 한지/먹빛 글자/청록 선택·기존 무공 아이콘을 유지하며 실제 게임의 K 창을 개편했다. 선택한 무공과4칸 편성은 기존 진행/저장과 연결된다. 현재 새 행동 게이지·범위는 [가변 격자 전투](../systems/grid-combat.md)에서 실행한다.

## 구성

- 상단:4개 실제 편성 슬롯. 아이콘/무공명/행동력·내기 소모/대상 유형과 전진·후퇴·추격·밀침 요약. 선택한 교체 대상 칸은 기존 청록 표식으로 강조한다.
- 왼쪽: 익힌 무공 목록과 전체/검/도/창/맨손/보조 필터. 각 행에 비용과 이미 편성한 칸 번호를 표시한다. 선택 행을 레이아웃 완료 후 스크롤 안에 온전히 드러낸다.
- 오른쪽: 선택한 무공의 이름/필요 무기/행동력 소모/내기 소모와 ‘범위 도식 참고’ 안내.7×5 격자로 자신·공격 가능한 칸·이동/변위 칸을 구분하고 오른쪽 방향 기준으로 보여 준다.
- 범위 옆: 전진/후퇴/관통/밀치기/추격 등 무공 특징과 대상 수, 지원 무공의 회복/방어/재사용, 장비 불일치/학습 조건 안내. 상세 글은 스크롤로 읽는다.
- 하단 버튼: 고른 무공을 선택한1~4번 칸에 편성. 기본공격/기본방어도 교체·비우기 가능하다.

범위를 ‘인접1칸’ 같은 단일 거리 문구로 요약하지 않는다. 슬롯은 대상 유형/이동 특징, 목록은 비용을 표시하고 실제 공격 가능 위치는7×5 도식으로 보여 준다. 표시 메타데이터의 `attack_offsets`/`move_offsets`와 선택적 `preview_origin`으로 불규칙한 위치 배열도 표현할 수 있다.

## 현재 값과 후속 전투 연결

무공16종+기본행동2종의 비용과 범위는 [최신 재편표](../martial-arts/redesign-v2.md)를 따른다. 행동력은 숫자로 표시하고, 범위는 오른쪽 방향 예시로 표시한다. 본게임은 가변 격자 전투에서 비용/범위를 실제 차감·판정하며 피해/내기는 재편 데이터를 따른다.

내기는 현재 장착 무기의 절감 보정을 반영한다. 공격 위치는 무공별 불규칙한 배열이며 시전자 기준3칸 한도를 검사한다. 범위 옆 스크롤 설명에 등급과 근력/내공 위력식도 표시한다.

## 소스와 유지한 기능

- `data/martial_tactics.json`:18개 플레이어 기술의 표시용 행동력/범위/이동 설계. 기존 피해 계수/무공 내기 비용과 분리했다.
- `scripts/martial_tactics.gd`, `martial_range_preview.gd`:초안 조회/요약/7×5 도식.
- `scripts/martial_menu_panel.gd`:K 레이아웃. `player_menu.gd`는 I/K 열기·닫기/선택/장착·편성/상태 기억을 계속 담당한다.

기존 이미지/아이콘을 재사용하며 새 아이템이나 무공을 추가하지 않았다. 실제 배운 목록/필터·4칸 편성/기본 행동 교체·비우기/장비 안내/키보드·마우스 선택/저장을 유지한다. I 소지품과 가격·보상·학습 조건은 유지한다. 피해·내기는 최신 재편표가 우선하고 격자 행동 엔진은 가변 격자 전투 문서를 따른다. 새 저장 스키마는 만들지 않았다.

## 점검

- `k_tactics.gd`:현재 기술 전체 표시·행동력/현재 내기 분리·7×5 안의 도식·전진/주변/자기 대상·선택 행 표시·표시 메타데이터가 전투 수치/자원을 바꾸지 않음·4칸 편성/비우기/저장 복원. 숫자60은 비용 표시 경로 검사용 임시 값이며 배포된 삼재검법 비용은40이다.
- `paper_menu_live.gd`:실제 I/K 마우스·키보드·장착·복용·편성·필터·빈칸·저장 회귀.
- `ui_states.gd`:선택/포커스와 실행 불가 구분 회귀.
- `capture_k_tactics.gd`:720/1440p와 전진/주변/직선/자기 대상 실제 렌더.

모든 Godot 검사는 사용자 저장과 다른 XDG 폴더에서 실행한다.
