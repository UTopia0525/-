# 시안 미감을 적용한 실제 전투

2026-10-28. [승인 시안](premium-battle-reference.png)의 배경/금테/먹빛 비취/한지 미감을 별도 실사용 그림으로 제작하고 실제 전투에 적용했다. 기존 교환식 화면의 색만 바꾼 것이 아니라 배경과 UI 구조를 교체했다. 기존 격자 계산·진도·학습·가격·전투 수치는 유지한다.

## 격자 선명도와 전투용 도원

격자에는 어두운3px 외곽선과 밝은1.5px 선을 겹쳐 배경 위에서도 읽히게 했다. 이동 칸은 밝은 청록2.5px, 공격 칸은 주홍2px 테두리를 별도로 표시한다. 범위/충돌/비용은 바꾸지 않았다.

전투용 도원은 시안의 청회색 복식·밝은 옷깃·회갈색 허리띠·높이 묶은 검은 머리·모자 없는 실루엣으로 새 제작했다. 검/도/창/맨손4종×준비/출수 준비/타격/피격4종의16개 자세를 전용 원본 PNG와 별도 아틀라스 좌표로 연결한다. 발 위치와 기본 신장을 기준으로 배치해 자세 교체가 크기 보정으로 이어지지 않게 하고, 기존 보행/좌우반전/일반 효과를 유지한다. 탐험 캐릭터와 대화 초상화는 이번 전투 그림 교체 대상이 아니다.

[실제 무기별16자세](../../godot/screenshots/jade-hero-poses.png). 포즈 시트는 image_gen으로 만들었고, 아틀라스 좌표는 주요 불투명 영역/발 기준점으로 정리했다. 원본 PNG를 편집해 덮어쓰지 않는다. 기존 초상화에 맞춘 청회색 옷/회갈색 허리띠는 hero_cloth_palette.gdshader로 표시 색상만 바꾼다. 원본 시트와 아틀라스/외곽선/자세는 유지하며 보행 조각에도 같은 팔레트를 적용한다. 창 끝의 붉은 술은 의상 색 변경 대상에서 제외한다.

## 화면

상단 양끝에는 기존 초상화/이름/무기/체력/내기/행동력을 표시한다. 능력치 상세는 행동력에 커서를 올려 확인한다. 상대 초상화는 기존 인물 등록과 portrait_actor를 따라 고르며 미등록 상대는 공용 그림을 쓴다.

오른쪽 아래는 **이동1개+기존 편성4개**다. 이동을 선택하면 상하좌우1칸만 청록색 화살표로 표시한다. 기본 이동은 행동력20·내기0이며 이번 작업에서 다른 방향/거리/소모를 추가하지 않았다. 무공은 기존 데이터와4칸 편성을 유지하고 새 무공별 전용 연출은 이후에 추가한다.

**화면 하단 중앙**에는 선택한 행동명/사용 행동력/사용 내기/공격이면 위력/설명/실행 불가 이유/사용 버튼이 있다. 그림 속 글자가 아니라 실시간으로 갱신하는 게임 UI다. 왼쪽은 보법 안내와 기본 조작이다. 비용은 새로운 확정 없이 기존 값을 표시한다.

WASD/방향키 이동,1~4 편성 선택,R 방향,Enter 실행을 유지한다. 큰 이동 버튼 외에 B로 기본공격,G로 숨 고르기를 선택할 수 있다. 전투 외 R 호의도는 유지한다.

## 상대를 향한 좌우반전

두 인물의 실제 발밑 X위치에 따라 플레이어와 상대 모두 서로를 바라본다. 이동/전진/후퇴/밀침으로 좌우 관계가 바뀌면 이동 애니메이션 중 실제로 교차하는 시점에 반전한다. 같은 세로줄에서는 직전 방향을 유지해 피격 흔들림 등으로 번갈아 뒤집히지 않게 한다. 선택한 무공의 방향/R 미리보기와 외형 방향은 분리하며 전투 수치나 범위는 바꾸지 않는다. 무기/준비/공격/피격/보행에도 같은 부모 반전을 적용하고 크기는 유지한다. 새로운 전투에서는 기본 좌우 관계로 다시 시작한다.

## 기본 동작

- 대기:기존 자세와 호흡.
- 이동:실제 좌표 보간, 기존 장착 자세를 상체/양발로 나눈 런타임 보행 레이어로 발 교차와 상체의 작은 오르내림, 출발 지점의 먼지.
- 기본 공격:준비/타격/복귀 자세와 일반 궤적·효과음.
- 피격:기존 붉은 섬광/밀림·피해 숫자/체력바 잔상에 일반 타격 파편 추가.
- 방어:일반 방어 광륜. 각 무공 고유의 화려한 연출은 이번 범위에 포함하지 않는다.

도원의 전투 자세16개는 새 시트를 사용하고, 상하좌우 전 방향의 독립 보행 프레임을 새로 그린 것은 아니다. 좌우반전과 절차적 보행/효과를 결합한다. 취소/다른 전투 진입 시 보행 레이어와 이전 효과를 제거하고 원래 인물 표시로 복원한다. 설정 일시정지는 동작에도 적용한다.

## 배경과 확장

기본 공터는 고해상도 대나무/산수 그림,0장은 별도 호송선 갑판 그림이다. 조우에 명시된 다른 배경은 유지하고 premium_background로 전용 미술을 지정할 수 있다. 기존 배경마다 새 그림을 모두 제작한 것은 아니다.

전장과 UI는 배경에 구워 넣지 않는다. [가변 격자/지형 자료](../systems/grid-combat.md)를 유지하며 인물과 효과가 독립적으로 움직인다. 시안의 픽셀 단위 복제가 아니라 실시간 인터페이스로 옮긴 구현이다. 원본 미술/문양/한글/캐릭터 프레임 차이는 실제 캡처에서 확인할 수 있다.

## 검증

grid_opponent_facing은 플레이어/적의 실제 교차 이동·같은 열·범위 방향 독립·무기4종/자세4종·크기·재진입을 검사한다. 실제 grid_battle_live 검사로 이동 레이어·선택 무소비·회전·취소·승리, grid_story_integration으로 실제 게임 진입·전투 저장 차단·일시정지·과거 저장·사망 화면을 확인한다. grid_combat는 계산 규칙을 확인한다. 네이티브720/1440p/선박/기본공격/가변 전장을 캡처한다. 사용자 저장과 분리한 XDG 폴더를 사용한다.
