# 무림맹 정문·총관·교관 기반 구현

## 이번에 적용한 범위

- 정문 좌·우 하급 수문 무사2명을 배치했다. 맹 내부 NPC는 연무장의 교관 곽진석, 총무당 실내의 총관 허문규다. 무창 성외/시내 민간 주민8명은 유지되어 **무창11명, 총무당1명**이다.
- 허문규·곽진석 전용 대화 초상화2장과 네 인물의 도트 아틀라스1장을 제작했다. 수문 무사 대화 그림은 기본18장의 서로 다른 남성 초상화를 재사용한다. 새 주요 인물 초상화는 기본18장에 추가하지 않는다.
- 출입 미확인 상태에서 정문으로 들어가려 하면 경비가 말을 걸고 물리적으로 통행을 막는다. 산적 토벌만 마쳤어도 송지겸의 보증/방문 허가가 없으면 입장하지 못한다. 경비 가까이에서 F로도 대화한다.
- 이후 방문 허가와 전수 완료가 연결될 수 있게 별도 출입 상태를 만들었다. 전수 완료 뒤 본단을 떠나면 출입 허가를 종료하고 재입장을 제지한다. 나가는 길을 가로막거나 같은 자리에서 대사를 계속 반복시키지 않는다.
- 허문규·곽진석의 인물 설정·소개/용무 대화, 정문 제지·재입장 제지, 후속 연결용 신원 보증·가르침 동기·무공 선택/확인 원고를 저장했다.

## 후속 메인 이야기 연결

후속 [메인 이야기](alliance-main-story.md)에서 송지겸의 장사 초대·정문 보증, 허문규 면담, 곽진석의 선택/확인/한 문 전수를 연결했다. 초대 전에는 정문이 닫히며, 허가받은 이번 방문에서 전수까지 마친 뒤 밖으로 나가면 재입장을 제한한다. 안내는 대사·Q 일지·목표 표시로 제공하며 강제 동행/도시 간 순간이동은 하지 않는다. 기존 안쪽 저장의 퇴장도 유지한다.

원고의 `draft_scenes`는 읽기용 대본이며 자동 실행되지 않는다. 소개 대화를 반복해도 무공·돈·능력치를 지급하지 않는다. 캡처와 테스트는 분리된 사용자 데이터에서 방문 허가 상태를 구성해 내부 대화를 보여 준다. 타이틀이나 메뉴에 임의 출입 우회 버튼은 추가하지 않았다.

## 출입 상태와 저장

| 상태 | 의미 | 정문 |
| --- | --- | --- |
| unverified | 초대·보증 미확인, 초기값 | 진입 차단 |
| visiting | 이후 보증 장면이 발급할 방문 허가 | 통행 허용 |
| training_complete | 이후 전수 완료 콜백으로 설정, 방문 중 | 나갈 때까지 허용 |
| closed | 전수 후 본단 밖으로 나감 | 재입장 차단 |

`alliance_visit.gd`의 `grant_visit()`와 `mark_training_complete()`는 다음 스토리 구현에서 연결할 콜백이다. 지금의 NPC 대화는 호출하지 않는다. 이미 종료한 방문은 중복 콜백으로 다시 열지 않는다. 실제 무공 지급 함수와 동일한 것으로 취급하지 않는다.

출입 상태는 schema3 저장의 선택 필드 `alliance_visit.phase`로 보존한다. 기존 파일은 필드가 없어도 읽으며 미확인으로 시작한다. 안쪽에서 불러온 옛 저장은 퇴장을 허용한다. 대화·거래·전투 중 수동 저장 금지는 유지한다.

통행 차단은 정문과 담장 사이의 통로에 독립 충돌체를 사용한다. 길 찾기도 같은 사각 영역을 사용하며, 허가 전후 격자를 재계산할 때 과거 차단 셀이 남지 않도록 초기화한다. 단방향 퇴장 보장은 플레이어가 이미 본단 안쪽이면 출구 차단을 해제하는 방식이며, 바깥에서 접근한 플레이어에게 허가를 부여하지 않는다.
