방어 수치 비교

적의 다음 행동이 예고된다는 가정입니다. 기본방어는 공격 없이 내기 0 소모, 턴 종료 시 정상적으로 내기를 회복합니다. 검법은 공격 후 다음 적 행동의 피해를 줄입니다.

기본방어 감소율 % · 검법 감소율 %

예: 적 전체 피해 70 / 근골 25 / 무기 피해 감소 3%

근골 계산 → 무기 감소 → 선택한 행동의 방어 감소 → 마지막에 버림. 기본방어와 검법 방어는 합산하지 않습니다.

검토 결과: 일부 성장안에서는 70% 방어로 2턴을 더 쓰고 체력 20을 아낄 수 있었습니다. 반면 현재 우두머리를 2턴에 처치하는 성장안에서는 방어가 필요하지 않았습니다. 예고 시점도 함께 조정할 필요가 있습니다.
