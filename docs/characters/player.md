# 도원(陶遠) · 주인공

사용자 확정 이름은 **도원(陶遠)**이다. 성은 도(陶), 이름은 외자 원(遠)이며, 자유롭게 먼 길을 떠돌면서 외로움을 품은 낭인의 분위기를 담는다. 오대세가나 기존 문파의 혈연·사문을 이름의 근거로 추가하지 않는다.

젊은 남성, 기본 표정은 무표정이다. 삿갓 없이 검은 긴 머리를 높게 묶고, 회청색 무복·흰 깃/안감·갈색 천 허리띠·어두운 손목 보호구를 착용한다. 옷은 소박하지만 해지지 않았다. 초상화와 탐험 도트는 기존 전투 캐릭터를 기준으로 맞췄다. 대화 일러스트에는 무기를 그리지 않는다. 기존 표국 해체 뒤 무소속으로 강호를 다니는 설정과 선택에 따른 이야기 흐름은 유지한다.

대화창과 대화 기록의 표시 이름, 전투 인물명과 교전 기록은 도원을 사용한다. 도입/토벌/무림맹 대사의 내부 인물 ID와 기존 저장의 참조 키는 `hero`를 유지한다. 역할을 설명하는 일반 문장의 ‘주인공/플레이어’ 표현은 이름과 구별해 보존한다.
