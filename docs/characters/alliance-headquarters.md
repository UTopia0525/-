# 무림맹 본단 인물

역할과 이름은 사용자가 지정한 흐름을 따르며, 아래 나이·외형·성격·세부 배경은 이번 작업에서 구체화했다. 전투 수치와 독문무공은 부여하지 않는다.

| 인물 | 나이 | 역할 | 외형과 성격 |
| --- | ---: | --- | --- |
| 송지겸 |24| 무림맹 외무 무사·무당 속가제자 | 청회색 무복·태극 장식·문서 가방과 서책. 민초의 사정을 살피며 맹의 연락과 보고를 성실히 맡는 온화한 청년. [전용 그림](song-jigyeom.md). |
| 허문규 |51| 총무당 총관 | 긴 얼굴, 도드라진 광대와 가는 눈, 짧은 반백 수염. 옅은 회색 도포와 장부. 엄정하고 과묵하나 출신보다 실제 행적을 공정하게 본다. |
| 곽진석 |46| 연무장 교관 | 넓은 사각 얼굴, 휜 콧등, 짙고 고르지 않은 눈썹과 굵은 손마디. 짙은 청회색 수련복. 직설적이지만 배우는 사람에게는 끈기가 있다. |
| 좌측 수문 무사 |28| 정문 왼편 경비 | 청회색 근무복, 작은 두건과 허리의 검집. 방문 목적과 신원을 먼저 묻는다. 개인 이름은 아직 정하지 않았다. |
| 우측 수문 무사 |34| 정문 오른편 경비 | 같은 근무복에 더 다부진 체격과 짧은 수염. 절차를 차분히 설명하고 동료를 보조한다. 개인 이름은 아직 정하지 않았다. |

허문규는 외부 방문객·문서·물자와 연락을 관리하며 송지겸의 외무 보고를 접수한다. 곽진석에게 공로자의 지도를 의뢰하는 관계다. 곽진석은 병장기 종류보다 자세·호흡·판단의 기초를 중요하게 여기며 송지겸에게도 급해질 때 어깨에 힘이 들어간다고 지적한다.

허문규 대사: “장부 한 줄에도 사람의 사정이 매달려 있소. 서두르다 빠뜨리는 일이 없도록 하는 것이 내 몫이지.”

곽진석 대사: “배운 초식이 많다고 발밑까지 단단해지는 것은 아니네. 급할수록 어디에 힘을 주는지 살펴보게.”
