# 세력별 인물 및 초상화 제작 원칙

사용자의 지속적인 작업 지침이다.

- 사용자가 세력의 설정을 제시하면 해당 설정을 저장하고, 이를 바탕으로 인물의 이름·나이·역할·외형·성격·배경·관계·갈등·대사 등을 구체화하고 인물별 초상화를 제작한다.
- 사용자 확정 설정과 새로 제안한 인물 설정을 구분한다. 사용자가 인원이나 역할을 지정하면 이를 따르고, 지정하지 않은 부분은 세력에 맞춰 합리적인 초안으로 제안한다.
- 무공은 사용자가 정한 사용 자격과 전수 제한을 지킨다. 무공 설정 및 전투 연출 제안은 전투 수치의 확정과 구분한다.
- 전투 관련 스탯은 임의로 부여하지 않는다. 사용자가 전투 시스템을 설계한 이후 전체 인물에 일괄 부여한다. 기존 남궁세가의 임시 능력치는 폐기한다.
- 초상화는 기존 도트 기반 대화용 초상화 화풍과 세력별 시각 컨셉을 따른다.
- 이미지와 설정을 프로젝트에 저장하고, 확인 가능한 GitHub 링크로 제공한다. 이전에 승인된 같은 저장소에 대한 이미지·설정 업로드 흐름을 이어간다.

- 외모는 인물별 얼굴형·눈·코·귀·수염·표정·생활 흔적을 달리하여 획일적인 미남·미녀상을 피한다. 제갈설하의 정파제일화 시안은 유지하며, 각 인물의 외형 특징은 각 가문 인물 문서의 최신 외형 수정안을 따른다. 남궁세가의 단정함은 유지하되 기존의 미형 요구는 이번 사용자 수정 방향에 맞춰 완화한다.

- 후속 사용자 지정: 남궁서진·남궁연서는 미형 완화 수정 전의 원본 초상화를 사용한다. 제갈설하도 원본을 유지하며, 나머지 6명은 개성을 더한 수정본을 사용한다.

- 사천당가 장녀 당서령은 사용자 지정에 따라 미형으로 제작한다. 가주 당겸과 소가주 당윤재는 수정 후의 개성 있고 덜 이상화된 외모 기준을 따른다.

## 기본 마을 NPC 이미지 재사용 — 사용자 확정

일반 마을 NPC는 별도의 이미지 제작 지시가 없으면 기존 공용10장과 무창 주민8장을 합친 **기본18장**을 재사용한다. 남성10장·여성8장이며 실제 목록은 `godot/data/basic_npc_portraits.json`을 기준으로 한다. 새 일반 주민을 만들 때 성별·연령·직업에 맞춰 선택하고 새 이름·설정·대사만 부여한다. 무창 주민의 원래 이름/설정/배정은 유지하며 그 그림을 다른 도시 주민에게도 사용할 수 있다.

위의 세력별 주요 인물 제작 원칙과 구분되는 일반 주민 예외다. 주인공·기존 장사 거래NPC3장·포졸 전용1장은 기본18장에 포함하지 않는다. 한 대화에서는 서로 다른 인물의 그림이 겹치지 않게 하며, 풀이 부족해도 사용자 별도 지시 없이 새 이미지를 생성하지 않는다.

## 도시 시설 NPC 이미지 — 직업별2종

사용자 확정: 앞으로 모든 도시에 상인·장인·교관을 배치한다. 각 직업은 장사에서 사용한 그림과 무창에서 사용한 그림, **2종 중1종**을 골라 재사용한다. 별도 사용자 지시가 없으면 새 전용 그림을 생성하지 않는다. 실제 후보는 `godot/data/service_npc_portraits.json`을 따른다.

|직업|기본A|기본B|배치 구역|
|---|---|---|---|
|상인|장사 상인 그림|유백초 그림|상점가|
|장인|장사 장인 그림|석대용 그림|공방거리|
|교관|장사 교관 그림|임정산 그림|무관 앞|

도시 제작 시1종을 선택해 해당 인물에 고정하고, 이름·나이·성격·대사는 그림과 분리해 설정한다. `source_actor`는 그림 출처를 뜻하며 그 기존 인물을 새 도시에 복제하는 지시가 아니다. NPC 인물ID를 기준으로 대화와 거래창이 같은 초상화를 사용하게 연결한다. 현재 장사는A, 무창은B를 유지한다. 이 규칙의 교관은 일반 도시 무공 거래 NPC이며 무림맹 주요 인물 곽진석 등의 별도 인물을 자동 대체하지 않는다.

일반 주민의 기본18장 정책은 그대로다. 무창의3장은 일반 주민 풀과 직업 풀이 같은 원본을 공유하며, 장사의3장은 이제 해당 직업의 공용 후보로 재사용할 수 있다. 기본18장에 새3장을 자동 추가하지 않는다. 같은 대화에서 그림이 겹칠 때도 직업별 후보를 우선해 배정하고, 두 후보로 구별할 수 없는 구성은 대화를 나누는 방식으로 처리한다.
