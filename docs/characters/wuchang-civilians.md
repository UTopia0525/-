# 무창 민간 주민 8명

사용자가 채택한 유백초 이하8명만 구현했다. 무림맹주·송지겸·외원 집사·맹 소속 무사는 배치하지 않았다. 초기 배치 시 개인 전투 수치·의뢰·숙박 기능을 추가하지 않았다. 후속으로 유백초의 [약초꾼 의뢰](../quests/wuchang-herbalist.md)를 구현했다. 나머지 주민의 의뢰는 후보 상태다.

F5 → 무창 자유 탐방, 또는 장사 동쪽 농촌 포탈→산길→무창 남쪽 농촌으로 들어온다. NPC에 접근해 F를 누르면 대화를 읽는다. 유백초는 약초꾼 이야기/약재 거래를 고를 수 있다. 유백초·석대용·임정산은 대화 뒤 기존 영약/병장기/무공 거래를 열며 가격과 카탈로그는 기존 그대로다. 나머지5명은 대화만 한다.

## 인물과 대사

### 유백초 · 약재상

54세. 약효보다 복용자의 생활 습관부터 살피는 현실적인 약재상.

회녹색 두건과 약초 주머니, 네모난 얼굴과 고르지 않은 눈썹.

무관의 무리한 수련을 못마땅해하며, 농부 주계복에게 약초 말리는 법을 알려 준 적이 있다.

> 안색부터 보지요. 강호의 명성보다 밤잠을 잘 잤는지가 몸에는 더 중요하답니다.

> 영약은 한 알에 백문입니다. 약부터 찾기 전에 식사는 거르지 마세요.

> 삼백·오백·칠백문짜리가 있소. 지금 손에 맞는 병장기부터 살펴보시오.

## 구현과 검증

`godot/data/wuchang_residents.json`에 안정적인 인물ID·설정·대사·선호 위치·스프라이트 영역·시설을 보관한다. 기존 장사 시민 생성 경로를 공유하되 새 전용8인 도트 시트를 쓴다. 인물 그림은 배경 없이 생성한8장 원본을 그대로 저장하고, 프레이밍 데이터로 주인공과 얼굴 비율·눈높이를 맞춘다. 말하는 인물 강조/청자 어둡게·좌우 시선·H 대화 기록을 공유한다.

시민 전신이 건물/담장과 겹치지 않도록 배치하고 대로 중심을 피한다. 동일한 발 충돌을 물리 이동·클릭 길 찾기에 반영한다. 거래 표시와 시설 지도/안내는 실제 거래하는3명에게만 표시하고, 의뢰가 없는 주민에게 노란 느낌표를 만들지 않는다.

시설ID는 기존 공통 종류를 유지하고 `actor_id`로 무창의 실제 인물 초상화와 이름을 연결한다. 장사의 연계 의뢰는 장사 인물ID로만 진행하므로 무창의 거래로 완료되지 않는다. 기존 저장을 읽으면 시민이8명 한 번씩 생성되며, 과거 위치가 새 시민과 겹치면 공통 안전 위치 복구를 사용한다.

`tests/wuchang_residents.gd`:8인/3시설, 전신 배치·도로 회피·접근 경로, 실제 대화/이름/고유 그림·프레이밍·배경 감광, 거래 초상화·영약100문/무기300문 실제 구매, 의뢰 오진행/가짜표식 방지·시설 안내·저장 불러오기. 회귀 검사: `city_collision`, `trading`, `conversation_tools`, `adventure_features`, `overland_travel`, `saves`. 검사마다 실제 플레이와 다른 XDG 사용자 폴더를 사용한다.

`tests/capture_wuchang_residents.gd`는 실제 Godot 화면으로8인 대화·지도·거래를 캡처한다. 독립 `scenes/wuchang.tscn`의 F6는 종전대로 지형 답사용이며 주민 상호작용은 F5 본게임에서 확인한다.
