# 인물 미술의 공통 기준

사용자 확정: 사용하는 추론 모델이나 추론 강도가 바뀌어도 그림체·인체 비율·완성도의 기준은 유지한다. 아래 기준은 이후 인물 제작에도 적용한다.

## 실제 참조 원본

- 탐험 도트: [남궁서진](../../godot/assets/characters/namgung/seojin.png), [남궁 일반 무인](../../godot/assets/characters/namgung/regular-warrior.png), [공용 인물](../../godot/assets/characters.png).
- 대화 일러스트: [남궁서진](../../godot/assets/portraits/namgung/seojin.png), [은소월](../../godot/assets/portraits/cuiyue/eunsowol.png). 인물의 나이·미형 여부·신분은 각 설정을 따른다.
- 실제 표시 비교: [전체 도트](../../godot/screenshots/exploration-characters-all.png), [취월루 수정 도트와 기준 인물](../../godot/screenshots/cuiyue-art-comparison.png).

탐험은 공용/남궁의 중간 SD 비율로 머리가 크고 몸통·다리가 압축되어 있다. 남궁서진 원본에서 얼굴·머리·몸의 관계를 직접 비교한다. 머리장식이나 상투를 포함했는지에 따라 등신 숫자가 달라지므로 숫자 하나만 맞추어 통과시키지 않는다. 초상화의 성인 인체 비율을 탐험 그림으로 그대로 축소하지 않는다.

픽셀 윤곽과 덩어리로 읽히는 명암, 얼굴·복식·소품의 명확한 구분을 유지한다. 사진 같은 피부·직물, 매끈한 입체 렌더, 잘게 쪼개진 무늬를 추가하는 것은 기존 품질 기준을 대체하지 않는다. 고유 인물의 장신구·자수는 남길 수 있지만 게임 크기에서 실루엣과 얼굴을 해치지 않게 정리한다.

## 제작과 채택

1. 현재 등록된 초상화/도트와 위 기준 이미지를 실제로 열어 본다. 이미지 생성에는 스타일 기준과 외형 기준을 구별해서 참조로 제공한다.
2. 실제 인물의 얼굴·복식·소품은 보존하고 요청한 부분을 수정한다. 초상화는 도원 기준의 대화창 얼굴 크기/눈높이 규칙을 따른다.
3. 투명 여백을 제외한 영역을 측정해 registry와 비교표에 같은 값을 기록한다. PNG 해상도 증가나 런타임 확대만으로 비율 문제를 해결했다고 간주하지 않는다.
4. 도시 표시 규칙 `min(132/영역높이,88/영역너비)`과 공통 발밑선으로 기존 인물 옆에 렌더한다. 얼굴 비중·어깨·다리 길이·윤곽·명암·디테일 밀도를 확인하고 맞지 않으면 다시 제작한다.
5. 실제 대화와 등장 장면을 캡처해 눈높이·잘림·불필요한 여백과 배경 분리를 확인한다. 원본 파일/UID/import를 보존하고 모든 재사용 위치에 공통 경로로 적용한다.

## 취월루 수정

탁문호·은소월 도트는 기존의 길고 사실적인 인체 대신 남궁 기준의 짧은 몸과 읽기 쉬운 얼굴로 교체했다. 탁문호 초상화도 험상·흉터·수염·검은 무복/붉은 갈색 띠·도를 유지하며 피부/옷감의 사진 같은 표현을 완화했다. 은소월의 초상화는 변경하지 않았다. 사건 조건·대사·보상·조우 능력치는 변경하지 않는다.

검수: `tests/capture_cuiyue_art.gd`의 공통 배율 비교/탁문호 발화 화면, `tests/capture_exploration_sprites.gd`의 전체28종 비교, `tests/capture_cuiyue_incident.gd`의 전투→무대→단독 면담→보상 실제 진행을 확인했다. [수정된 탁문호 대화 화면](../../godot/screenshots/cuiyue-tak-portrait.png).
