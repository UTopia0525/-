# 소주 주민 14명

승인된 일반 주민 구성이다. 후속 승인으로 [일반 의뢰5종](../quests/suzhou.md)에 참여하며 전용 세력 인물은 추가하지 않았다. F로 생활 대화를 나누며 석춘매·진덕구·백정수는 대화 뒤 기존 영약/무기/무공 거래를 이용한다.

모든 초상화는 기존 기본18장 안에서 선택했다. 거래 담당3명은 각 직업의 기본B형을 고정 사용하며, 신규 전용 그림은 제작하지 않았다. 탐험 도트도 기존 공용/무창 주민 도트를 재사용한다. 이름과 설정은 그림 출처의 기존 인물과 독립적이다. 원고·말버릇·공용 그림ID는 `godot/data/suzhou_residents.json`, 직업별 배정은 `godot/data/service_npc_portraits.json`에 저장했다.

NPC 발밑은 대로·다리·운하 보행로에서 벗어나고 전신 영역이 건물·나무·소품 및 다른 주민과 겹치지 않도록 배치했다. 후속 일반 의뢰5종의 실제 수락 가능/완료 보고에만 공통 느낌표/물음표를 부여한다. 산길에는 NPC를 추가하지 않았다.
