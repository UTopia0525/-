# 탐험 캐릭터 비교표

현재 실제 탐험에서 사용하는 도원1종과 NPC 도트27종을 중복 제거해 모았다. 대화 초상화18장과는 다른 목록이다. 같은 그림을 여러 인물이 재사용하는 경우 한 번만 실었다. 과거 보관용/현재 미사용 이미지와 전투 전용 도트는 포함하지 않는다.

[전체28종](../../godot/screenshots/exploration-characters-all.png) · [도원 무기4종×방향4종](../../godot/screenshots/exploration-player-variants.png)

실제 `player.tscn` 렌더러와 NPC의 `min(132/영역높이,88/영역너비)` 배율을 사용해 공통2배로 확대했다. 발밑 기준선은 같으며 원본의 여백과 폭 제한은 유지했다. 카메라 줌은 제외했다.0장은 기존104 표시 규칙이라 도시보다 작지만 같은 그림을 사용한다. 비교를 위해 키를 임의로 같게 늘리지 않았다.

현재 도원은 공용/남궁을 기준으로 머리 비중을 줄이고 몸통·다리를 길게 한 새16프레임 탐험 그림을 쓴다. 모용3종은 머리/몸 비율을 다시 맞추고 실제 알파 경계를 측정해 모두132 높이로 표시된다. 도원은140 높이·소박한 청색 복식/흰 깃/갈색 띠를 유지하며 세밀한 얼굴/옷주름/신발/머리카락 표현을 보강했다. 검/도/창은 동일한 무기 없는 몸체 위에 별도로 표시한다. 정지/걷기 크기·속도·충돌과 전투/대화 그림은 변경하지 않았다.
