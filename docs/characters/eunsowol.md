# 은소월 — 공개 가능한 인물 초안

## 사용자 지정 이미지 방향

중원 최대 기루에서 활동하는 명기(名妓). 별호는 **중원제일미**이며 그에 어울리는 아름답고 화려한 외모를 표현한다. 비파를 지니는 인물이다. 이 소개에는 별도로 관리하는 숨겨진 신분이나 그 공개 사건을 포함하지 않는다.

## 인물 제안

- 여성, 31세. 이름은 예명 ‘은소월’로 제안하며 본명은 미정이다.
- 뛰어난 비파 연주와 침착한 응대, 세련된 화술로 알려진 성인 여성 예인이다.
- 외형: 길고 우아한 타원형 얼굴, 섬세하면서도 선명한 눈매, 정교한 이목구비, 은은한 붉은 입술. 성숙한 화려함과 절제된 품위를 함께 지닌다. 정파제일화 제갈설하의 맑은 백색 무복과 구별한다.
- 머리·복식: 긴 검은 머리를 정교하게 틀어 올려 금비녀·작은 진주와 비취 장식을 더한다. 깊은 자주빛·공작청색 비단과 금색 자수, 우아한 겹깃과 넉넉한 소매. 과도한 노출이나 현대 무대복을 사용하지 않는다.
- 악기: 목재 배 모양 몸통과 짧은 목을 지닌 중국 비파. 네 줄과 지판의 괘를 표현하고 몸 앞에 세워 품는다. 고금·쟁·일본 비와로 바꾸지 않는다.
- 공개 성격: 온화하고 말에 여유가 있으며 사람의 이야기를 세심하게 듣는다. 명성을 의식하되 손님에게 친밀감을 강요하지 않는다.
- 공개 대사: “먼 길 오셨군요. 오늘은 어떤 곡을 듣고 싶으신가요?”

이름·나이·배색·세부 복식·성격과 대사는 창작 초안이다. 기루의 이름·도시·운영자·구체적인 직위는 미정이다. 실제 역사적 인물을 재현하지 않는다.

## 초상화 원칙

기존의 세밀한 도트 기반 대화용 화풍·투명 배경. 사용자 지정에 따라 뛰어난 미모와 화려한 예인 복식이 명확하게 드러나도록 한다. 비파 연주를 준비하는 자연스러운 손과 자세, 성숙하고 온화한 시선을 사용한다. 숨겨진 신분을 암시하는 문양·조직 이름·살기·마법 효과·군림하는 자세는 넣지 않는다.
