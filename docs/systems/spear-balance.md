# 초급 창법 밸런스 패치

사용자 방향: **창은 초반에 강력하지만, 후반에는 특별한 무공 없이 다른 방식에 밀린다.** 관풍창법·연환창법을 실제 게임에 반영했다.

## 변경

| 무공 | 기존 피해 | 현재 피해 | 내기 소모 |
|---|---|---|---:|
| 관풍창법 | 근력×3 + 기민×5 + 오성×2 | **120 + 근력×2 + 기민×3 + 오성** | 20 → **18** |
| 연환창법 | 근력×3 + 기민×5 + 내공×3 | **160 + 근력×2 + 기민×3 + 내공** | 34 → **28** |

고정 위력은 능력치에 곱하지 않는 기본 피해다. 여기에 능력치 계수를 더한 뒤 기존 무기·근골·방어 계산을 적용한다. 학습 조건, 각350문 가격, 무기 장착 조건, 창의 내기 절감10/20/30%, 아이콘은 유지했다. 새 무공을 추가한 패치는 아니다.

| 무공 | 균형창 | 유엽창 | 유운창 |
|---|---:|---:|---:|
| 관풍창법 | 17 | 15 | 13 |
| 연환창법 | 26 | 23 | 20 |

연환창법 최소 내공13에서는 처음부터 사용할 수는 없지만, 기본공격·방어로 한 턴을 보내면 내기26으로 사용할 수 있다. 이전 균형창 비용31은 두 번의 회복을 기다려야 했다. 높은 일격 피해와 내기 관리라는 창법의 성격은 유지한다.

## 패치 근거와 실제 산적전

기존 관풍창법은 초반 공격력이 이미 강한 편이었다. 반면 연환창법은 내기 지연으로 불리했고, 두 창법의 높은 성장 계수는 후반 약세라는 목표와 맞지 않았다. 따라서 단순 계수 증가 대신 **고정 위력 상승 + 낮은 성장 계수 + 내기 부담 완화**를 선택했다.

아래는 이전 패치의 성장안과 동일한 스탯·균형창·적 AI·방어·회복 계산으로 재검증한 결과다. 학습 최소 조건을 채운 뒤 오성으로 합계100을 만든 사례이며, 사용 가능한 가장 강한 공격을 고르는 단순 정책이다. 전투는 체력300으로 시작한다.

| 무공 | 길목 산적 처치 | 우두머리 처치 | 우두머리전 잔여 체력 |
|---|---:|---:|---:|
| 관풍창법 | 2 → 2턴 | **4 → 3턴** | 258 → 258 |
| 연환창법 | **5 → 2턴** | **8 → 4턴** | **125 → 258** |

각 능력치20·균형창으로 비교하면 관풍창법의 방어 전 위력은200→240, 연환창법은220→280이다. 체력240·근골15·매3교전 방어하는 수련 대상에서 연환창법은4→2턴으로 줄었다. 수련 대상 비교는 적 반격으로 인한 생존을 계산하지 않으므로 실제 산적전 표와 구분한다.

## 후반 성장 확인

동일한 각 능력치80, 종류별700문 무기에서 방어 전 위력:

| 무공 | 위력 |
|---|---:|
| 관풍창법 | 600 |
| 연환창법 | 640 |
| 유수검법·쇄암검법 / 백련검 | 644 |
| 회풍도법 / 중강도 | 728 |
| 진각권법·운기장법 / 맨손 | 880 |

각 능력치100에서는 창법720/760, 유수·쇄암805, 회풍910, 진각·운기1100이다. 내공이 충분해져 창의 절감 효과가 턴당 사용 횟수에 큰 차이를 주지 않는 구간에서는 공격 성장과 검의 방어 효과가 상대적인 장점이 된다. 모든 스탯 배분에서 창이 반드시 약하다는 뜻은 아니다.

후반 적과 특별한 상위 창법은 아직 미구현이다. 이 표는 현존 초급 무공의 성장 곡선 검증이며 완성된 후반 전체 밸런스를 보장하지 않는다. 향후 상위 창법을 추가할 때에는 별도 계수·효과·이미지를 설정한다. 경지가 오르면 피해를 강제로 깎는 규칙은 넣지 않았다.

## 구현·검증

- `martial_arts.gd`에서 선택적 `base_damage`를 합산한다. 기존 무공은 기본값0이므로 계산이 같다. 플레이어·적 모두 공통 계산을 사용한다.
- 전투 미리보기, K 무공, 교관 설명에 고정 위력을 포함한 식을 표시한다. 실제 장비로 계산한 내기 비용도 확인했다. 기존 저장의 무공ID로 새 수치가 조회되며 저장 형식은 바꾸지 않았다.
- `tests/spear_balance.gd`: 공통 게임 계산으로 전후39개 수련 전투와6개 성장 구간을 비교. 과거 공식은 테스트에서만 보존하고 현재 계산은 실제 카탈로그를 읽는다. 습득 불가능한 무공 조합은 비교에서 제외한다.
- `tests/combat_updates.gd`: 변경 후110개 실제 산적전 사례 모두 승리. 정상 무공 성장안의 최저 잔여 체력154/300. 기존 초회 토벌 통합 진행과 이미지 누락 검사도 통과했다.
- `tests/spear_ui.gd`: K·교관·전투의 고정 위력 표시, 내기 부족 시 무소모 차단, 실제 관풍창법 피해195와 내기17 소모/회복을 확인했다.
- 기존 `martial_arts.gd`, `weapons.gd`, `trading.gd` 테스트도 통과했다.

재현은 분리된 XDG_DATA_HOME을 지정한 뒤 `godot --headless --path godot --script res://tests/spear_balance.gd`와 위 테스트를 실행한다. 결과는 `user://spear_balance_report.json`에 쓴다.
