# 기본공격 — 현재 격자 전투

2026-10-28 사용자 요청으로 기민 피해 계수를 제거했다.

- 방어 전 위력은 **근력 + 내공**. 현재 보유 내기량과 기민은 위력에 영향을 주지 않는다. 시작 능력치 각10이면 기존30에서 **20**으로 내려간다.
- 플레이어·적 모두 `rules.gd` → `combat_actions.gd`의 같은 계산을 사용한다. 기민은 계속 행동력 충전에 관여한다.
- 내기 소모0, 행동력 소모30, 정면1칸. 검·도·창·맨손 모두 사용 가능하며 무기 공격 보너스는 더하지 않는다.
- K창의4칸에서 편성·제외 가능하며 전투에서 B로도 선택한다. 초기 편성은 기본공격/기본방어/삼재검법/빈칸이다.
- 다른 행동과 같이 행동력100 이상을 요구한다. 행동 후 내공만큼 내기를 정상 회복하며 별도 추가 회복은 없다. 최대500.
- 근골·방어·상대 장비의 피해 감소는 기존 계산을 적용한다. 전투·대화·거래 중 수동 저장 금지는 유지한다.

[범위·효과 그림](../martial-arts/range-diagrams/README.md). `tests/grid_combat.gd`에서 양쪽 기민0/100의 실제 기본공격 피해가 같고 행동력 충전은 기존대로 다른지 확인한다.

기존 `tests/basic_attack.gd`와 과거 캡처는 이전 교환식 UI/피해/초기 적을 가정한 자료다. 현재 실제 전투는 `grid_combat.gd`와 `grid_battle_live.gd`로 검증한다.
