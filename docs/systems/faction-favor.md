# 세력 호의도 · R

탐험 중 **R** 또는 화면의 **세력 호의도 · R** 버튼으로 전용 창을 연다. R/ESC/닫기 버튼으로 닫는다. I/K 창에서는 호의도를 분리했으며 명성은 그대로 확인할 수 있다.

- 시작할 때는 빈 목록이며, 아직 호의도를 얻지 않은 세력의 이름이나 수치는 표시하지 않는다.
- 처음 양수 호의도를 얻은 세력부터 목록에 추가한다. 현재 등록 세력은 무림맹이며, 획득하면 **무림맹 5 / 100**과 막대로 표시한다.
- 호의도는 **0~100**이다. 초과 획득은100, 감소로0 미만이 되면0으로 제한한다.
- 한 번 표시된 세력은 이후0이 되어도 목록에 남는다. 처음부터0이거나 양수 호의도를 한 번도 얻지 않은 세력은 숨긴다.
- 명성과 호의도는 별개다. 호의도만 증감해도 명성은 변하지 않는다. 관계 등급·할인·가입·출입 혜택은 아직 정하지 않았다.
- 창을 열면 탐험을 일시정지하고, 닫으면 재개한다. 대화·거래·전투·다른 모달 창 위에서는 열지 않는다. I/K에서는 R로 안전하게 전환할 수 있다.

## 저장과 확장

`player_progress.gd`의 `FACTIONS`에 등록된 세력별 `faction_favor` 값과 `known_factions`(표시된 세력 목록)를 이야기 저장에 함께 보관한다. 조회는 `favor_for(id)`, 증감은 `add_favor(id, amount)`다. 양수 호의도를 처음 얻으면 목록에 자동 등록한다. 새 세력을 등록해도 호의도를 얻기 전에는 UI에 이름을 노출하지 않는다.

구버전 저장에 표시 목록이 없으면 기존 양수 수치로 목록을 복원하고0~100으로 보정한다. 호의도 필드도 없으면0·빈 목록으로 시작한다. 새 플레이 역시 초기화하며 환경 설정과는 별개다.

다른 의뢰에 호의도나 명성을 자동으로 추가하지 않는다. 현재 지급처는 「빌려 쓴 무림맹 이름」의 송지겸 감사 대화 완료뿐이며 무림맹 호의도+5·명성+5다. 해당 의뢰는 무림맹 메인 이야기에서 중급 무공을 전수받은 뒤 활성화된다.
