# 세력 호의도

명성은 강호에서 알려진 정도이고, 호의도는 특정 세력이 도원을 대하는 관계 수치다. 두 수치는 별도로 보존한다.

- 현재 등록 세력은 `murim_alliance`(무림맹)이며 시작값0이다.
- `player_progress.gd`의 `faction_favor` 사전에 세력별 정수를 보관한다. 조회는 `favor_for(id)`, 증감은 `add_favor(id, amount)`를 사용한다. 미등록 세력과 잘못된 저장 자료는 검증에서 거절한다.
- I 소지품/K 무공 창 상단에 명성과 무림맹 호의도를 표시한다.
- 이야기 저장에 포함되며, 구버전 저장에서 필드가 없으면0을 적용한다. 새 플레이를 시작하면 초기화한다. 환경 설정과는 별개다.
- 관계 등급·게임상 상한·할인·가입 조건·추가 출입 허가는 아직 정하지 않았다. 호의도5를 받았다고 닫힌 무림맹 정문을 다시 열지는 않는다.
- 다른 의뢰에 호의도나 명성을 자동으로 추가하지 않는다. 현재 지급처는 「빌려 쓴 무림맹 이름」의 송지겸 감사 대화 완료뿐이며 **무림맹 호의도+5·명성+5**다.

`tests/impostor_quest.gd`에서0 기본값·전수 조건·감사 전후 지급 시점·중복 지급 차단·저장 복원·구버전 호환·I 표시를 검사한다.
