# BGM 반복 재생 보완

사용자가 한 곡이 끝난 뒤 음악이 멈춘다고 보고하여 `music.gd`의 재생 유지 처리를 보완했다. 원본5곡의 OGG/가져오기 설정과 런타임 스트림은 이미 반복을 사용했고, 현재 검사 환경에서는 기본 OGG 경계 반복이 작동했다. 사용자 PC의 오디오 드라이버 문제를 직접 재현한 것으로 단정하지 않는다. 재생이 종료/중단되는 경우를 실제로 만들어 복구 경로를 추가하고 검증했다.

- 기존 네이티브 OGG 반복(`loop=true`, 시작0초)을 유지한다.
- 현재 곡의 실제 `finished`가 발생하면 같은 음원을 같은 플레이어에서 다시 재생한다. 처음부터 교차 페이드를 새로 시작하지 않고 기존 목표 음량으로 복귀한다.
- 종료 신호 없이 활성 플레이어가 멈춘 경우도 최대0.25초 간격의 확인으로 복구한다. 페이드로 끝낸 이전 플레이어는 되살리지 않는다.
- 같은 곡을 다시 요청하면 재생 위치를 유지한다. 이미 멈춘 경우에는 복구하며, 음악 끄기 상태에서는 재생하지 않는다.
- M/설정으로 음악을 끄면 반복 복구도 멈춘다. 다시 켜면 기존 재생을 이어가거나 중단된 현재 곡을 재개한다.
- 음악 노드는 메뉴 일시정지 중에도 계속 동작한다. 서로 다른 상황의 음악으로 전환할 때 기존 교차 페이드를 유지한다.

새 음악·음량 변경·원본 음원 재합성·저장 형식 변경은 없다.

## 검증

`tests/music_loop.gd`는5곡 각각에서 실제 오디오 재생 위치를 끝부분으로 옮겨 두 번의 정상 반복을 확인한다. 이어 반복을 해제한 스트림의 실제 EOF를 발생시켜 종료 신호 후 같은 곡이 재개되고 반복 설정이 복구되는지도 검사한다. 가짜 `finished`만 호출해 통과시키지 않는다. 종료 신호 없는 중단·음악 끄기/켜기·메뉴 일시정지·동일 곡 위치 유지·빠른 상황 전환·이전 곡의 늦은 종료도 확인한다.

`tests/music_full_cycle.gd`는 일반 맵 곡을 **건너뛰기 없이 처음부터 끝까지** 재생하여 다음 반복으로 이어지는지 확인한다. 테스트 부하에서 오디오 드라이버의 샘플 시간이 벽시계와 조금 달라질 수 있어, 타이머만으로 종료를 추정하지 않고 실제 재생 위치가55초 이후 다시 처음으로 돌아오는지 관찰한다.

관련 `smoke.gd`, `saves.gd` 회귀 검사를 함께 수행한다. 실제 플레이 저장과 분리한 XDG 사용자 폴더에서 실행한다. 원본5곡의0.25초 구간별 RMS 검사에서도 무음 구간은 발견하지 못했다. 재생 검사 통과는 사용자 스피커/오디오 장치의 직접 청취 검증을 뜻하지 않는다.
