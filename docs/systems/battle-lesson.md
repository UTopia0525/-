# 0장 흑린채 수적 전투 안내

0장 진행 중 첫 수적 전투에만 `battle_lesson.gd`의 수련 패널을 표시한다. 다른 조우/독립 전투 체험/이전 전투 저장 불러오기에는 표시하지 않는다.

1. 행동력100 이상에서 행동, 행동별 비용, 기민에 따른 충전 설명. 다음 버튼으로 확인한다.
2. WASD/방향키 또는 기존 이동 UI로 실제 한 칸 이동하면 다음 단계다.
3. 삼재검법을 선택하면 범위 안내로 넘어간다. 선택은 자원을 소모하지 않는다.
4. 붉은 공격 칸과 R 방향, Enter/Space/출수를 설명한다. 실제 삼재검법 실행 성공으로 완료한다. 범위 밖 입력은 완료하지 않으며 접근과 회전은 자유다.
5. 기본방어 실제 실행. 다음 자기 실제 행동까지 모든 피격20% 감소와 행동 후 내기 정상 회복을 설명한다.
6. 기본공격 실제 실행. 내기0/행동력30/근력+내공 위력과 B 선택을 설명한다.
7. 자유 전투/L 기록/F2 도움말/전투 저장 금지 안내 후 마친다.

각 단계의 넘기기와 전체 안내 닫기를 제공한다. 안내를 따라야 공격이 허용되는 강제 잠금은 없다. 먼저 승리하면 안내를 닫고 원래0장 침몰/분기 이야기로 이어진다. 패배 시 안내는 닫고 기존0장 재도전 규칙을 유지하며 미완료 안내는 재시도에서 다시 시작한다. 적을 멈추거나 수치/행동력/내기/피해/보상을 바꾸지 않는다. 플레이어 차례는 기존처럼 입력을 기다린다.

완료/전체 닫기는 기존 장치 설정 `preferences.cfg`의 `tutorial.seen`에 `prologue_grid_lesson_v1`로 기억한다. 이야기 저장 형식과 진행도는 바꾸지 않는다. 설정창이 열려 전투가 일시정지되면 안내 버튼도 일반 전투와 함께 멈춘다. 단계를 넘기는 행위 자체는 전투 행동/기록/회복을 발생시키지 않는다.

`tests/battle_lesson.gd`: 실제 이동/선택/공격/방어/기본공격, 범위 밖 무효, 읽기 무소비, 완료 기억, 다른 전투 제외, 구저장 시작 제외, 조기 승리 연결. `grid_story_integration.gd`는 기존 저장 차단/호환과 패배 흐름을 확인한다. 검사는 별도 XDG 폴더를 사용한다. `capture_battle_lesson.gd`로 실제 게임 화면을 캡처한다.
