# 근력·근골 기반 체력 성장과 전투 비교

플레이어와 모든 적에게 `최대 체력 = 300 + (근력−10)×3 + (근골−10)×5 = 220 + 근력×3 + 근골×5`를 적용했다. 별도 지정한 적 체력은 공식 값으로 대체했다. 시작 도원은300, 근력/근골20이면380, 양쪽200이면1,820이다. 기존 피해·행동력·내기·무공·장비·적 AI·승패 후 스토리는 바꾸지 않았다.

## 실제 적용

- `rules.gd:max_health`가 공통 계산이다. 전투 시작마다 양쪽을 현재 최대 체력으로 회복하고, 격자/HUD/체력 잔상/기존 전투창/0장 결산에 반영한다. I/K 하단에 최대 체력을 표시한다.
- 조우 JSON의 `max_hp`도 공식에 맞춰 갱신했다. 실행 시에는 실제 능력치로 재계산하므로 능력치 수정 후 과거 체력이 남지 않는다.
- 새 저장에 `health_revision:1`을 기록한다. 탐험 저장은 전투 밖의 완전 회복 기준이다. 구버전 전투 저장을 읽을 때는 기존 최대 체력 대비 남은 비율로 한 번 이행하며0은0으로 유지한다. 대화/거래/전투 중 새 수동 저장 금지는 유지한다.

## 시뮬레이션 조건

- 실제 `grid_combat.gd`와 `grid_tactical_ai.gd`를 사용했다. 현재 상대14종에 모용유안의7×3 좁은 길 재대련을 별도로 더했다. 일반 전장은7×5, 마운표전은 기존 남궁서진 지원을 양쪽 비교에 동일하게 적용했다.
- 0장: 능력치 모두10, 삼재검법. 이후: 균형형은 근력/기민/근골/내공20·오성21(총합101, 체력380), 의뢰형은 네 전투 능력치18·오성29(총합101, 체력364).
- 장사는 하급8종, 이후는 중급5종을 각각 하나씩 편성하고 기본공격/기본방어/이동을 함께 사용했다. 철산권법의 의뢰형은17/17/18/20/29(체력361), 운기장법은 두 분류 모두16/16/16/26/27(체력348)로 학습 조건을 충족했다. 실제 능력치는 JSON에 모두 기록했다.
- 무기는 기존 기본 배정인 무문철검/후배도/균형창/맨손이다. 모든 무기를 같은 가격으로 맞춘 비교는 아니다.
- 공격 우선(direct)과 대응형(adaptive) 두 방침. 같은 구성으로 변경 전 고정 체력과 변경 후 공식을 비교했다. 총306쌍/612회이며 난수 반복이나 실제 사람의 승률이 아니다. 행동 횟수는 양쪽의 이동/방어/공격을 모두 합한 값이다.
- 학습 가능 여부·행동 합법성·전투 종료를 검사했다. 패배를 테스트 오류로 취급하거나 수치를 다시 조정하지 않았다.

## 확인된 영향

- 튜토리얼 수적 체력이90→242로 올라갔다. 두 방침 모두 승리하지만 시작 캐릭터의 잔여 체력과 전투 길이를 별도로 살펴야 한다.
- 장사 길목 산적170→328, 우두머리240→328. 두 성장형·하급8종·두 방침 모두 승리했다. 회풍/연환 등 일부 구성은 여유 체력이 작다.
- 마운표 체력은750→466으로 낮아졌다. 서진의 고정 위력240/공세65% 차단은 그대로라 변경 후20사례 모두272 이상의 체력을 남겼다. 보스의 위압감은 약해질 수 있다.
- 유소강·마응칠·백정수·모용유안의 일부 중급 구성은 패배했다. 무기 선택 하나가 항상 승리를 보장하지 않으며, 이 결과만으로 해당 무공 전체가 약하다고 단정하지 않는다.
