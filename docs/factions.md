# 구파일방·오대세가 선정 및 거점

무협에는 고정된 단일 정본이 없다. 아래는 한국 무협에서 널리 쓰이는 대표 조합을 게임의 기본안으로 채택한 것이며, 작품별 빈도를 조사해 통계적으로 ‘최다’임을 입증한 목록은 아니다. 실재 지형 위에 창작 조직을 배치한다. 1390년 명나라의 실존 무림 세력 분포라는 의미가 아니다.

## 구파일방

| 조직 | 본산·총타 | 지도 배치 |
|---|---|---|
| 소림사 | 하남 숭산 소실산 | 낙양 동쪽 |
| 무당파 | 호광 무당산 | 형주 북서쪽 |
| 화산파 | 섬서 화산 | 서안 동쪽 |
| 아미파 | 사천 아미산 | 성도 남서쪽 |
| 청성파 | 사천 청성산 | 성도 북서쪽 |
| 공동파 | 감숙 평량 공동산 | 서안 북서쪽 |
| 곤륜파 | 곤륜산맥 동부권의 가상 본산 | 지도 서북 별도 영역 |
| 종남파 | 섬서 종남산 | 서안 남쪽 |
| 점창파 | 운남 대리 점창산(창산) | 지도 남서쪽 |
| 개방 | 개봉 외곽의 가상 총타 | 개봉 인근 |

소림·무당 등 아홉 문파와 개방 하나를 합친 구성이다. 해남파 등을 넣는 다른 판본도 있지만 이번에는 종남·점창을 포함한다. 개방은 전국적인 조직이며 총타 한 곳만으로 활동 범위를 제한하지 않는다. 곤륜파의 데이터 좌표는 광범위한 동부 곤륜권을 가리키는 임시 기준점이며 실재 본산 좌표가 아니다. 화면 표시 좌표는 별도 영역용으로 분리했다.

## 오대세가

| 세가 | 채택 지역 | 이번 게임의 임시 거점 |
|---|---|---|
| 남궁세가 | 안휘권 | 남직례 합비 일대 |
| 모용세가 | 강소 소주권 | 소주 태호권 |
| 사천당가 | 사천 | 성도 외곽 |
| 제갈세가 | 호북 양양권 | 호광 양양 일대 |
| 하북팽가 | 하북 | 보정 일대 |

사용자 지정에 따라 황보세가 대신 하북팽가를 포함한다. 팽가의 장원은 하북 지역의 보정 일대에 임시 배치한다. 이는 현대 하북성 경계를 1390년에 소급한다는 뜻이 아니다. 이번에는 위 다섯 가문을 기준으로 삼는다. ‘안휘·강소·호북’은 독자의 지리 이해를 위한 통상적인 지역 명칭이다. 1390년 당시 해당 성들이 현재 형태로 존재했다는 뜻이 아니므로 지도 설명에는 남직례·호광 등을 사용한다.

세가의 좌표는 지역 관계를 보여주는 가상 장원의 기준점이다. 실제 역사적 가문의 저택 위치나 특정 소설 속 장원의 복제가 아니다. 가문별 무공·성향 등은 아래 개별 설정 문서에서 관리한다. 개별 문서에 없는 인물·관계·사건은 미정이다.

## 구현

- 도시 20개는 유지하고 문파·세가 표식 15개를 별도 레이어로 추가했다.
- 초록 삼각형: 구파일방. 보라 사각형: 오대세가.
- 레이어별 숨기기·표시, 거점 선택 시 위치·선정 근거 표시.
- 밀집 지역에는 실제 기준점과 이름을 연결하는 지시선을 사용한다.
- 산문·장원으로 가는 실제 길과 지역 탐험 맵은 후속 작업이다.

외부 자료 원문 대조는 이전 지도 단계에서 완료되지 않았다. 이번 선정 역시 무협 관습에 대한 설계 판단이며 정량적인 빈도 조사 결과가 아니다.

## 사용자 확정 컨셉

- [남궁세가](factions/namgung.md): 오대세가 연합의 수장. 가치관·직계와 방계의 관계·검법 사용 자격·복장과 외모를 기록했다. 이후 인물 제작 시 이 문서를 우선 참고한다.

- [남궁세가 주요 인물 창작 초안](characters/namgung-family.md): 가주·소가주·차남·막내딸. 사용자 확정 전 제안.

- [하북팽가](factions/peng.md): 짙은 청색, 발달한 근육, 대도, 강함에 대한 집착. [가주·소가주 창작 초안](characters/peng-family.md).

- [제갈세가](factions/zhuge.md): 백색 복식과 지략, 판관필·철선. [가주·소가주·정파제일화 창작 초안](characters/zhuge-family.md).

- [사천당가](factions/tang.md): 독공·독장·암기술과 해독술, 암녹색·검정. 만천화우는 소실, 천라지망은 제외. [가주·장녀·소가주 창작 초안](characters/tang-family.md).

- [모용세가](factions/murong.md): 자색·은회색 복식, 교류와 무학 연구, 반격과 분석 검술. [가주·소가주 창작 초안](characters/murong-family.md).

- [소림](factions/shaolin.md): 자비·계율·구휼, 권장과 봉 중심. [방장·계율 장로·젊은 제자·태상방장 창작 초안](characters/shaolin.md).

- [무당파](factions/wudang.md): 청회색·백색, 조화와 수양, 태극 계열 무학과 장삼봉 전승. [무당검선 운허·젊은 제자 청윤](characters/wudang.md).

- [화산파](factions/huashan.md): 백색·짙은 적색, 절개와 명예, 아십사수매화검법. [장문인 진목·젊은 제자 소운](characters/huashan.md).

- [종남파](factions/zhongnan.md): 짙은 청색·흰색, 천하삼십육검과 후발제인, 전진교의 영향을 받은 별도 문파이며 화산과 앙숙. [정허·담진](characters/zhongnan.md).

- [아미파](factions/emei.md): 여성 문파, 옅은 회색·연보라색, 청련유장과 자립·자비. [정연 사태·묘은](characters/emei.md).

- [청성파](factions/qingcheng.md): 청람검법 채택, 청록·옅은 회색의 지역 도가 문파 초안. [통현·지온](characters/qingcheng.md).
