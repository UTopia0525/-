## 장강수로십팔채

[수로채 설정과 무학](factions/waterbandits.md) · [흑린채 채주 염문악](characters/waterbandits.md)

## 흑도방

[조직 설정과 추가 채택 후보](factions/blackguild.md) · [방주 위중량](characters/blackguild.md)

전국의 여러 작은 흑도 조직을 총괄하고 금전적 이득을 최우선으로 삼는 조직. 총본부는 항주로 확정했다. 추가 운영 설정은 미정이다.

![위중량](../assets/portraits/blackguild/wijungnyang.png)

추가 세력 제안: [무영각·적월문·하오문](factions/heterodox-candidates.md). 적월문·중립 하오문은 채택했고, 무영각은 채택 전 후보이다.
