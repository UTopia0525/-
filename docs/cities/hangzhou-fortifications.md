# 항주 외곽 성곽과 북문 진입

2026-10-31. 기존 항주 시내를 유지하면서 북쪽에 성 밖 흙길과 북문을 추가했다. 소주 방면 운하길에서 F 이동하면 성 밖[1080,90]에 도착한다. 완만하게 굽은 흙길을 따라 남쪽으로 걸어 북문을 통과하면 기존 시내 대로로 이어진다. 시내에 도착하는 별도 자동 이동/대화나 새 NPC는 추가하지 않는다.

## 구성

새 전용 미술 `city-gate.png`의 석조 아치·붉은 문루·회색 기와와 `city-walls.png`의 석조 성벽을 사용한다. 기존 남경 시장 건물의 화풍과 승인된 정면 문 그림을 참조했다. 이미지를 사선 회전하거나 가로세로 비율을 다르게 늘리지 않고, 성벽 끝은 원본 영역을 잘라 동일 축척으로 이어 붙인다.

북·동·남쪽 성벽은 서쪽 수변 성벽으로 이어진다. 북동쪽 운하는 수문 아래로 연결하며 물은 통행할 수 없다. 북문은 중앙만 열고 양옆 석축을 충돌로 막는다. 인물은 문루·아치 뒤에서 가려지고 열린 아랫부분에서 보인다. 성문 위 창은 불투명한 내부로 막아 통행 중 인물이 위층에 보이지 않도록 했다. 수변 유람선과 기존 작은 배들은 유지한다.

건물과 성벽은 바닥에 굽지 않고 독립 오브젝트/충돌/Y정렬로 남긴다. 바닥은 기존 시내 원본을 북쪽 확장만큼 옮겨 샘플링하고, 외곽 잔디·흙길·운하 물길을 같은 재질 경로로 그린다. 미니맵/전체 지도 바닥 캐시도 확장된 크기로 재생성한다.

## 좌표와 저장

새 미술 지도1840×1760/세계5888×5632다. 기존 시내의 건물·주민·조사/의뢰 대상과 실내 출입·귀환 좌표는 세로로400미술 단위(1280월드 단위)만 옮겼다. 시내 내부의 상대 배치는 유지한다.

- 운하길→항주 도착: [1080,90], 돌아가는 포탈: [1080,60].
- 취월루 입구: [785,825], 실내에서 귀환: [785,855].
- 운하 창고 입구/귀환: [1610,618].
- 흑도방 본당 입구/귀환: [1585,1525].

위 좌표는 미술 지도 단위다. 안정적인 포탈/인물/의뢰ID와 보수·능력치·관계 수치는 유지한다. 기존 항주 저장의 layout_version1은 위치Y에1280만 더한 뒤 공통 안전 위치 검사를 거친다. 새 저장은 version2로 기록해 다시 읽어도 중복 이동하지 않는다. 대화·거래·전투 중 새 저장 금지는 유지한다.

## 검증

`hangzhou_fortifications.gd`에서 실제 이동 입력으로 북문 통과/성벽 충돌을 확인하고, 성 밖→시내 길찾기·물길 차단·새 저장과 이전 위치 이행/중복 이행 방지를 검사한다. `hangzhou_map.gd`, `hangzhou_painted.gd`, `hangzhou_residents.gd`는 시내 도로·문턱/거래 접근·전신 겹침·지도/운하 왕복을 확인한다. `hangzhou_quests.gd`, `blackguild_story.gd`, `canal_map.gd`, `saves.gd`, `save_restrictions.gd`로 기존 의뢰/출입·공통 저장을 점검한다. 실제 화면/바닥 캐시는 `capture_hangzhou_painted.gd`로 생성한다.

위 검사9종은 모두 PASS였다.

검사는 Godot4.6.3과 분리된 XDG 저장 폴더에서 실행한다. 소프트웨어 OpenGL 실제 캡처이며 Windows GPU 성능 검증은 아니다.
