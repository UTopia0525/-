# 남경 · 황궁 철거와 성 밖 농촌

2026-10-31 후속 사용자 요청을 반영한 현재 배치다. 이전 [세 도시 성곽](three-city-fortifications.md)의 남경 황궁 부분을 대체한다. 장사·무창 성곽은 그대로다.

![남경 전체 지도](../../godot/screenshots/nanjing-country-full.png)

북쪽 궁전 지붕·궁성문·주칠 벽과 궁전 전용 충돌을 없애고, 북서 성문 동쪽부터 동북 모서리까지 회색 석조 성곽을 이어 붙였다. 중앙 대로는 북쪽 성벽 앞에서 끝난다. 북서쪽 남궁세가 방면 성문은 계속 드나들 수 있다.

최신 후속 수정은 **서쪽 운하 / 북쪽 마른 농촌 / 동쪽 수전**으로 토지 이용을 분리한다. 기존 논·밭의 교대 배치와 농가 주변을 둘러싸던 얇은 수전 띠를 없앴다.

- 서쪽: 농가1동과 모든 논밭을 제거했다. 서쪽 수면을 연속 운하로 잇고 물가에는 마른 둑/흙길을 둔다. 기존 서문 포탈 앞에는 돌로 포장한 접안 공간을 남겨 서문으로 들어갈 수 있다. 새 수면에는 실제 충돌이 있어 물 위로 걸어가지 않는다.
- 북쪽: 기존 북쪽 민가3동/농업 창고1동과7개의 마른 밭을 묶었다. 농가 앞마당·출입 흙길·성벽 아래 관리 길·북서 성문 진입로를 유지한다. 마른 밭 사이에 물논이나 관개 수로를 끼워 넣지 않는다. 서쪽 물가 가까운 북서쪽 여유 공간은 농가/논 대신 둑 풀밭으로 남겼다.
- 동쪽: 기존 민가3동을 제거하고7개의 논을 같은 농업 구역으로 모았다. 진회하 북안에서 북쪽으로 올라가는 본수로와 남안에서 남쪽으로 내려가는 본수로를 두어, 강물과 실제로 이어진 수로가 각 논의 가장자리에 닿게 했다. 짧은 가지 수로가 본수로와 논을 연결한다. 동쪽 흙길과 소주 방면 포탈 앞은 마른 길이다.

기존 건물/논/밭/흙/물 재질을 재사용해 화풍을 유지하고, 배치와 바닥 의미 마스크를 수정했다. 물레방아는 이 평지 관개 구성에 필요하지 않아 추가하지 않았다. 깊은 서쪽 운하는 강 재질, 얕은 동쪽 관개 수로는 기존 수로 재질, 둑 풀밭은 기존 승인된 풀 재질을 사용한다. 남서쪽의 좁은 운하변 농지를 모두 제거하고 수면으로 연결했으며 도시 남쪽 가장자리는 마른 길이다.

성 안의 기존 흙바닥은 중앙 광장에 사용하던 밝은 판석으로 포장하고, 대로/골목 및 관아·주거 구역은 같은 계열의 회색 돌길로 연결했다. 기존 시장의 문턱, 건물 그림자와 접지·강·나루·다리는 유지한다. 바닥/그림·건물 충돌/Y정렬은 분리한다.

건물은 승인된 장사 `painted/living.png`를 비율 보존해 사용한다. 신규 논/채소/수로/흙 재질은 수정하지 않은 생성 원본 `capital/paddy-materials.png`이며 출처/해시는 `paddy-art-manifest.json`에 기록한다. 이전 `rural-materials.png`와 manifest는 작업 이력으로 보존하며 현재 바닥에는 쓰지 않는다. 장사 맵 자체는 이번 작업에서 변경하지 않았다.

전경은 구조 확인용0.45배, 나머지는 기본0.8배 카메라다. 전체 지도/미니맵 바닥 캐시도 현재 지형으로 재생성한다. 위 전체 지도는 건물/바닥을 함께 렌더한 화면이며 NPC 위치도는 아니다.

## 동작과 검증

세계7424×5632·layout_version3·기존 중앙 대로·진회하 세 다리·출입 포탈/도착점은 유지한다. 기존 주민·의뢰·보상·거래·분기·저장 형식은 바꾸지 않는다. 새 NPC/의뢰/농가 내부는 추가하지 않는다. 구version2/1 저장의 기존 위치 이행도 유지한다. 기존 서쪽 농지에서 저장했던 위치는 공통 안전 위치 보정으로 마른 지면에 복원한다.

이번 논밭/석재 포장 변경은 분리된 XDG 저장 폴더/Godot4.6.3에서 다음 검사3종을 통과했다. 이전 성곽 작업의 성문/저장 검사 기록은 앞선 문서를 참조한다.

- `nanjing_countryside.gd`: 황궁 오브젝트 제거, 북쪽 농가/창고4곳 앞 통행·경로 및 서쪽 수면 통행 차단, 이전 서쪽 농지 위치 저장 복원, 북쪽 연속 벽 충돌, 외곽 흙길과 모든 포탈 접근.
- `nanjing_layout.gd`: 남경 다리/강·기존 주민 접근, 건물 비율/회전/부지, 지도 버전.
- `nanjing_market_slice.gd`: 기존 시장 건물·통행·거래와 재질 적용.

`capture_nanjing_countryside.gd`로 전체 지도와 실제 카메라/바닥 캐시를 재생성한다. 캐시를 Godot에서 다시 가져온 뒤 `-- --views-only`로 재촬영하면 미니맵도 현재 바닥을 표시한다. 일부 검사 종료 때 기존 ObjectDB/리소스 정리 경고가 남으나 위 기능 검사 실패는 없다. Windows GPU 성능을 측정한 결과는 아니다.

성 안 보존 확인: 변경 전후 전체 지도에서 북쪽 시내(345,300)~(1660,1070), 남쪽 시내(270,1200)~(1660,1380)의 픽셀이 동일함을 비교했다. 외곽의 지형·서문 접안 공간과 지도 캐시만 달라진다.
