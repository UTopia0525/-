# 항주 · 취월루 실내

취월루 정문 앞에서 **F**로 들어가는 하나의 연회장이다. 5층 외관의 규모는 뒤쪽의 높은 금장 회랑·격자창·비단 휘장으로 느끼게 하며, 위층으로 이동하는 계단이나 층별 맵은 만들지 않았다.

[실제 전체 맵](../../godot/screenshots/cuiyue-hall-full.png) · [실제 플레이 화면](../../godot/screenshots/cuiyue-hall-play.png)

- 북쪽 **금란무대**: 모란·새 문양의 금장 병풍, 붉은 장막, 낮은 공연 단상.
- 중앙 **연회석**: 무대 앞을 향한 붉은 융단과 넓은 통로, 양옆의 술상·과일·주기.
- 양옆 **비단별석**: 금장 장의자와 차상, 시선을 나누는 병풍. 등불을 단 주칠 기둥을 함께 배치한다.
- 바닥은 따뜻한 목재, 붉은 비단과 금장 장식은 무대/가구에 집중한다. 상층은 장식 회랑이며 보행 범위 밖이다.

## 배치·동작

지역 ID `cuiyue_hall`, 월드3072×2048 / 도안1536×1024 / 배율2. 도시와 같은 주인공 높이140·속도360을 유지한다.

항주 `[785,425]` F → 실내 `[768,900]`. 실내 남쪽 `[768,967]` F → 항주 정문 앞 `[785,455]`. 자동 이동 없이 기존 포탈/상호작용 규칙을 따른다.

건축 바탕은 `assets/maps/cuiyue-hall/ground.png`, 무대·술상·차상·병풍·기둥·장의자는 투명 `furniture.png`에서 따로 배치한다. 각 가구의 알파 경계를 측정한 source 영역과 발밑 충돌을 `layout.json`에 기록했다. 물리 충돌과 길찾기는 동일한 데이터이며, 공통 Y정렬로 인물이 기둥·병풍 뒤에서 가려진다. 배경의 북쪽 벽/상층, 옆벽, 남쪽 막힌 벽은 보행 범위/지형 충돌로 막고 남쪽 출입구만 열어 둔다.

기존 미니맵·TAB 전체 지도·I/K/Q/R·설정·탐험 저장/불러오기를 사용한다. 다른 지역의 의뢰/시설을 추적하면 먼저 취월루 출구를 안내한다. 대화·거래·전투 저장 금지는 유지한다. 후속 승인으로 [관리인/연주자/예인/점소이/주고 담당/손님6명](../characters/hangzhou-residents.md)을 배치했다. 설금란·백소아·홍채령은 전용 초상화와 도트를 쓰고 나머지3명은 기본 풀을 쓴다. 후속 [항주 일반 의뢰5종](../quests/hangzhou.md) 중 소길의 짝사랑/공연 의상 및 도시 의뢰 대화를 연결했다. 새 세력 소속은 없으며 하오문 문주는 아직 미배치다.

## 원본·검증

원본은 이미지 생성 도구로 제작하고 원본 파일을 보존했다. 바닥 `exec-c3d8b214-ee2d-43d4-9331-75cc9eb16f40.png`, 투명 가구 아틀라스 `exec-fcc63d5b-2aac-43bb-b53f-e9f7c69839f7.png`. 픽셀 가공 없이 원본을 복사하고 Godot에서 합성한다.

`tests/cuiyue_hall.gd`는 실제 F 왕복/재입장, 주요 통로 접근, 가구/벽 차단, W 이동과 실제 물리 충돌, TAB 지도, 추적 의뢰 출구, 실내 저장/위치 복원을 검사한다. `tests/capture_cuiyue_hall.gd`는 실제 게임 장면과 동일 프리팹의 전체 맵을 캡처한다. 기존 항주 왕복/거래 검사와 저장 제한 검사도 함께 확인한다.
