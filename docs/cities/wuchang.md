# 무창 · 무림맹 본단 도시

## 확정한 방향

무림맹 본단은 **무창**에 둔다. 악주 신설안과 나루 입성안은 사용하지 않는다. 주인공은 산적 토벌로 명성을 얻은 뒤 무당 출신 무림맹 무사에게 감사와 추후 방문 시 보상하겠다는 말을 듣는다. 그 자리에서 따라가는 선택지는 없으며, 이후 스스로 육로를 통해 무창 **남문**으로 들어온다. 보상액과 이후 본편 내용은 미정이다.

이번 구현은 **NPC 배치 전 지도 확인 단계**다. 사절 대화·장사↔무창 육로 이동·임무·거래·본단 입장 제한은 아직 연결하지 않았다. 기존 저장·산적 토벌 보상·전투 수치를 바꾸지 않는다.

## 배치

- 크기8192×6144. 남문→중앙 광장→북동쪽 무림맹 정문이 중심 동선이다.
- 기본6구역: 상점가·관아·무관·공방거리·객잔·주거구역. 장강 나루·하역 창고가, 중앙 광장, 무림맹 본단을 더해9구역이다.
- 무림맹 담장 경내는 전체 직사각형 맵의약26%이며, 강·성 밖을 제외한 시가지의약3분의1이다. 외원 접수처·객사·숙소·군사 집무실·무기고·연무장·회의당을 독립 건물과 마당으로 구분한다. 연무장과 중앙 통로를 넓게 확보했다.
- 전용2층 회의당의 표시 높이는1200으로 일반 가옥452보다 높다. 한 층 건물을 단순히 늘리는 대신 새 투명 전각 그림을 사용했다. 높이에 따라 실제 플레이 화면에서는 전각의 일부만 보일 수 있다.
- 흙길 중심, 본단·관아 마당과 주요 진입로 일부만 석재를 사용한다. 수목은 마당과 강변의 소수만 둔다.
- NPC는0명이며 보이지 않는 거래·의뢰 표식도 없다. 기존 장사 NPC를 복제하지 않았다.

## 확인 방법

최신 소스를 받은 뒤 Godot F5 → 타이틀의 **무창 지도 답사**. 남문에서 시작하며 WASD/방향키·클릭으로 걷는다. TAB은 전체 지도, ESC/답사 마치기는 타이틀 복귀다. NPC나 스토리 없이 지형을 살피는 별도 답사 입구이며 본편 진도를 변경하지 않는다.

에디터에서는 `godot/scenes/wuchang.tscn`을 열고 F6로도 실행할 수 있다. 별도 실행 파일/웹 데모를 내보내지는 않았다.

## 구현과 검증

`assets/maps/wuchang/layout.json`은 구역·도로·오브젝트·육로 입구·검사용 목적지를 가진다. `python godot/tools/build_wuchang_layout.py`로 같은 배치를 재생성할 수 있다. 편집 후에는 검사·캡처를 갱신한다.

`wuchang_ground.gd`는 흙·강·포장만 그린다. 구조물202개는 기존 `city_scenery.gd`와 공용 아틀라스로 각각 생성하고 전용 회의당 그림1종을 더한다. 물리 충돌·발밑Y정렬·문기둥 충돌/중앙 통과/지붕 가림을 유지한다. 클릭 이동은 같은 발밑 충돌 영역으로 만든 길 찾기를 사용한다. 미니맵과 전체 지도는 같은 배치를 별도의2D물리 월드에서 렌더링하므로 작은 복제 충돌체가 실제 도시에 섞이지 않는다.

`tests/wuchang.gd`는 NPC 없음·남쪽 시작·주요 지점 전부 접근·독립 충돌/Y정렬·문 중앙/기둥·실제 남문 이동·본단 규모·지도 크기/입력·타이틀 복귀·진도 불변을 검사한다. `tests/capture_wuchang.gd`는 실제 Godot 화면과 고해상도 전체 지형을 저장한다. 검사 시 사용자 데이터는 분리한 XDG 경로를 사용한다.
