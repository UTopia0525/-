# 무창 · 무림맹 본단 도시

현재 외성·출입구·남경 궁성 배치는 [세 도시 성곽 개선](three-city-fortifications.md)을 따른다. 아래는 이전 구현의 설명이다.

## 확정한 방향

무림맹 본단은 **무창**에 둔다. 악주 신설안과 나루 입성안은 사용하지 않는다. 주인공은 산적 토벌로 명성을 얻은 뒤 무당 출신 무림맹 무사에게 감사와 추후 방문 시 보상하겠다는 말을 듣는다. 그 자리에서 따라가는 선택지는 없으며, 이후 스스로 육로를 통해 무창 **남쪽 농촌**에 도착한 뒤 남문으로 들어온다. 보상액과 이후 본편 내용은 미정이다.

무창의 [민간 주민8명](../characters/wuchang-civilians.md)을 배치하고 짧은 F 대화와 거래3종을 연결했다. 무림맹 경비2명·교관 곽진석을 배치하고 총무당 실내에 허문규를 배치했다. 장사↔무창 육로 이동은 [산길](changsha-wuchang-road.md)로 연결했다. [정문 출입 제한과 인물 대화](../story/alliance-visit-foundation.md)는 구현했다. 사절 초대·보증 연출과 전수 선택/지급은 아직 연결하지 않았다. 기존 저장·산적 토벌 보상·전투 수치를 바꾸지 않는다.

## 배치

- 크기8192×7680. 기존 성내를 유지하고 남쪽 농촌을 덧붙였다. 농촌 끝 포탈→남문→중앙 광장→북동쪽 무림맹 정문이 중심 동선이다.
- 기본6구역: 상점가·관아·무관·공방거리·객잔·주거구역. 장강 나루·하역 창고가, 중앙 광장, 무림맹 본단을 더하고 남문 밖 농촌을 추가해10구역이다.
- 무림맹 담장 경내4000×3280은 기존 규모를 유지한다. 농촌 확장 전 전체 맵의약26%, 시가지의약3분의1이며 새 농촌 때문에 전각이나 경내를 축소하지 않았다. 외원 접수처·객사·숙소·군사 집무실·무기고·연무장·회의당을 독립 건물과 마당으로 구분한다. 연무장과 중앙 통로를 넓게 확보했다.
- 전용2층 회의당의 표시 높이는1200으로 일반 가옥452보다 높다. 한 층 건물을 단순히 늘리는 대신 새 투명 전각 그림을 사용했다. 높이에 따라 실제 플레이 화면에서는 전각의 일부만 보일 수 있다.
- 흙길 중심, 본단·관아 마당과 주요 진입로 일부만 석재를 사용한다. 수목은 마당과 강변의 소수만 둔다.
- 민간 주민8명은 각 구역에 배치한다. 전용 도트와 초상화를 사용하며 대로 중심·건물 겹침을 피한다. 거래3명만 거래 표시를 붙이며, 새 의뢰 표식은 없다.

## 확인 방법

최신 소스를 받은 뒤 Godot F5 → 타이틀의 **무창 자유 탐방**. 남문 밖 농촌 끝 포탈에서 F로 산길을 왕복할 수 있다. 독립 지형 답사는 에디터에서 `scenes/wuchang.tscn` F6로 실행한다. 남쪽 농촌에서 시작하며 WASD/방향키로만 걷는다. TAB은 전체 지도다. 독립 F6 답사에서 ESC/답사 마치기는 타이틀 복귀다. 자유 탐방은 새 플레이 상태이며 기존 저장을 이어갈 때는 불러오기를 사용한다. NPC에 접근해 F를 누르면 대화/거래가 열린다.

에디터에서는 `godot/scenes/wuchang.tscn`을 열고 F6로도 실행할 수 있다. 별도 실행 파일/웹 데모를 내보내지는 않았다.

## 구현과 검증

`assets/maps/wuchang/layout.json`은 구역·도로·오브젝트·육로 입구·검사용 목적지를 가진다. `python godot/tools/build_wuchang_layout.py`로 같은 배치를 재생성할 수 있다. 편집 후에는 검사·캡처를 갱신한다.

`wuchang_ground.gd`는 전용 원화의 흙·강·포장만 표시한다. 구조물224개는 기존 `city_scenery.gd`와 공용 아틀라스로 각각 생성하고 전용 회의당 그림1종을 더한다. 물리 충돌·발밑Y정렬·문기둥 충돌/중앙 통과/지붕 가림을 유지한다. 키보드 이동은 같은 발밑 충돌을 사용하며, 길 찾기 데이터는 접근 가능성 검사에 유지한다. 미니맵과 전체 지도는 같은 배치를 별도의2D물리 월드에서 렌더링하므로 작은 복제 충돌체가 실제 도시에 섞이지 않는다.

`tests/wuchang.gd`는 NPC 없음·남쪽 농촌 시작·주요 지점 전부 접근·독립 충돌/Y정렬·문 중앙/기둥·실제 남문 이동·본단 규모·지도 크기/입력·타이틀 복귀·진도 불변을 검사한다. `tests/capture_wuchang.gd`는 실제 Godot 화면과 고해상도 전체 지형을 저장한다. 검사 시 사용자 데이터는 분리한 XDG 경로를 사용한다.

남문 밖 농촌에는 논/밭4곳과 농가2채·헛간·우물·짐·수목을 배치했다. 작물 안쪽은 지형 충돌과 길 찾기에서 막고 둑길과 마을 길로 돌아갈 수 있다. [포탈 위치와 왕복](changsha-wuchang-road.md).

## 총무당 실내

정문 안 왼편의 기존 `reception` 건물을 총무당으로 지정했다. 건물 앞 푸른 포탈에서 F로 출입하고, 실내 남쪽 포탈에서 외원으로 돌아온다. 별도 지역 `alliance_office`는2048×1440이며 총관 책상·접수 탁자·대기석·문서장·병풍을 독립 충돌/Y정렬 오브젝트로 배치했다. 실내에서도 TAB 지도와 저장/불러오기를 지원한다. 허문규를 실내에 배치하고 경비 제지·교관 기본 대화를 연결했다. 송지겸의 등장과 무공 선택/전수 진행은 아직 적용하지 않았다.

[실내 플레이 화면](../../godot/screenshots/alliance-office-interior.png) · [실내 전체 배치](../../godot/screenshots/alliance-office-map.png). `tests/alliance_office.gd`로 F 왕복·가구 충돌·길 찾기·실내 지도·저장/불러오기·성장 보존을 확인한다. 총무당 바닥과 가구는 전용 원화이며 이전 bake 명령으로 덮어쓰지 않는다. [최신 전체 미술](regional-map-art.md).


## 남동쪽 관아 담장 완성

5시 방향 관아 구역의 앞 담장에 북쪽·서쪽·동쪽 담장을 이어 네 면의 경계를 완성했다. 독립 담장 오브젝트15개를 추가해 전체 구조물은224개다. 북쪽 담장은 대로의 통행 영역과 관아 지붕 사이에 두며, 남쪽 기존 문과 가운데 통로는 유지한다. 포두 육정호의 자리와 접근로도 유지한다. 바닥 그림·퀘스트·보상은 바꾸지 않았다.

[관아 담장 확대](../../godot/screenshots/wuchang-government-walls.png) · [갱신한 무창 전체 지도](../../godot/screenshots/wuchang-full-map.png). 배치 생성기는 `tools/build_wuchang_layout.py`, 캡처는 `tests/capture_government_walls.gd`다. `wuchang.gd`와 `wuchang_residents.gd`로 주요 지점 접근·문 통행·주민 겹침/접근을 확인했다.


## 동문 방향 수정

성곽 동쪽 출입문은 남쪽을 향하던 공용 정문 그림 대신 **동쪽을 향하는 전용 측면 그림**(`east-gate.png`)을 사용한다. 지붕 용마루와 두 기둥은 남북으로 배치하고 가운데를 동서로 통과한다. 남문·관아 문·무림맹 문은 기존 형태를 유지한다.

`layout.json`의 `gate_east` 프리팹과 `east_gate.opening_axis=east_west`, 통과점 `[1949,945]`를 사용한다. 북·남 기둥 밑에만 독립 충돌을 두고 성곽의 문틈도 맞췄다. 도원이 지붕 밑으로 들어가면 기존 발밑 정렬과 투명 영역으로 자연스럽게 가려진다. 전체 지도와 미니맵도 같은 새 그림/배치를 표시한다.

[동문 확대](../../godot/screenshots/wuchang-east-gate.png) · [실제 통행 화면](../../godot/screenshots/wuchang-east-gate-passage.png). `tests/wuchang.gd`는 가운데 통행·기둥 충돌과 실제 키보드 동서 왕복을 검사한다. 주민 접근과 산길 왕복 검사를 유지했다. 갱신 캡처는 `tests/capture_east_gate.gd`다.
