# 남경 전역의 재질·건물 비율 개선

후속 작업: [시장·인접 골목 파일럿](nanjing-market-slice.md)은 이 문서의 시장4개 점포와 해당 바닥만 추가 개선했다. 최신 시장 캡처는 후속 문서를 따른다. 그 외 구역의 설명/그림은 아래 기존 개선 기록이다.

2026-10-30. 취월루 실내를 미감의 기준으로 삼아 남경6144×4096 전체에 적용했다. 기존 도트 윤곽을 고집하기보다 따뜻한 재질과 세밀한2.5D 건축을 사용하고, 인물의 기존 탐험 도트는 유지한다.

## 문제와 적용 방법

| 확인한 문제 | 반영한 방법 |
| --- | --- |
| 도시 전체1536×1024 바탕을4배 확대해 가까운 화면에서 바닥이 흐림 | 실제 월드 좌표로 돌·흙·벽돌의 세부 재질을 샘플링. 창 크기가 커져도 작은 도시 그림만 확대하지 않음 |
| 건물마다 시점/재료/빛이 달라 별도 그림을 붙인 느낌 | 주택·상점·창고·공방·객잔·관아·무관·찻집·서점·사당 등12종을 같은 정면 방향·기와/목재·좌상단 광원 기준으로 재제작 |
| 길쭉한 측면 건물을 가로로 넓은 부지에 억지로 맞춤 | 사선 회전 대신 정면 그림을 사용. 가로 부지는 정면 민가로 교체. 원본 비율을 보존해 부지 안에 맞추고 발밑을 정렬 |
| 건물과 바닥의 접합이 떠 보임 | 건물 밑에 공통 접지 그림자. 그림 자체의 재질과 바닥의 색온도를 맞춤 |
| 본 화면과 지도에서 건물 비율이 다름 | 전체 지도/미니맵도 최종 `visual_rect`를 사용. 바닥만 별도로 Godot 렌더해 지도용 캐시 생성 |
| 비율 변경 후 동쪽 출구 주변의 통행 폭이 부족함 | 출구 앞 작은 민가1동을 제거해 수변 출입 동선 확보. 모든 주민과 양쪽 출구 접근 재검사 |

바닥은 도로/구역 데이터와 같은 좌표로 석재 대로·주거 포장·객잔 벽돌 마당·흙바닥·수변 돌길을 구별한다. 강/해안의 기존 형태와 다리 위치는 유지하고 수면의 색과 세부 결을 맞췄다. 건물/담장/소품은 바닥에 굽지 않으며 각자의 충돌과Y정렬을 유지한다. 인물이 건물 뒤로 지나가면 가려지고, 벽과 물은 통과하지 못한다.

세 돌다리는 같은 석재의 고해상도 원본을 머리/중간/꼬리 구간으로 나누어 실제 통행 길이에 맞춰 조립했다. 다리 전체를 세로로 눌러 돌과 기둥을 찌그러뜨리지 않으며, 양옆 난간 충돌과 가운데 통행을 분리한다. 물빛 보정은 실제 하천/나루 영역에만 적용해 푸른 회색 보도가 물로 보이지 않게 했다.

새 원본은 `assets/maps/nanjing/painted/{civic,landmarks,materials}.png`이며 가공 없이 보관했다. 그림 출처/해시는 기존 `art-manifest.json`에 추가했다. `nanjing_ground.gd`와 `nanjing_terrain.gdshader`가 실제 바닥을 렌더한다. `bake_nanjing_overview_floor.gd`는 **지도용 바닥만** 렌더하며 건물은 계속 별도 오브젝트다.

기존 구역·도시 크기·의뢰·포탈 목적지·보상은 유지한다. 배치 좌표계는 여전히version2이며 새 그림 때문에 막힌 옛 저장 위치에는 기존 안전 위치 보정을 사용한다. 새 저장 형식이나 진도 초기화는 없다. 별도3D 항주 테스트도 변경하지 않는다.

## 검수

`tests/nanjing_layout.gd`에서 건물의 동일한X/Y 확대율·회전 없음·부지 내 배치와 모든 주민/출구의 길을 검사한다. 세 다리 횡단/물 차단과 기존 의뢰의F 상호작용은 기존 남경 의뢰 검사로 확인한다. `capture_nanjing_painted.gd`는 전체 맵과 실제 플레이4곳,2560×1440 화면을 렌더한다. 사진 같은 바탕과 캐릭터의 화풍 차이를 키우는 대신, 기존2D 인물이 읽히는 재질 밀도와 축척을 기준으로 계속 조정한다.

기존 검사 일부가 소주 포탈 추가 이전의 배열 순서나 격자 전투 개편 이전의 무공/체력 수치를 가정하고 있어, 목적지ID와 현재 공식을 확인하도록 고쳤다. 수변 의뢰 검사는 실제 격자 행동의 결정타/피격을 고정한 통합 검사로 승리·사망·의뢰 보고를 확인한다. 게임의 무공 수치나 난이도를 검사 통과 목적으로 변경하지 않았다.

Godot4.6.3/분리된 테스트 저장에서 표정·대화·공용 그림·291개 대화 장면·남경 배치/구휼/비단/수레/서책/징세/수변 의뢰·저장까지13종 검사를 통과했다. 실제 렌더는1280×720와2560×1440에서 확인했다. 일부 검사 종료 시 기존 리소스 정리 경고가 남아 있으며, Windows GPU별 프레임 성능은 별도 측정하지 않았다.
