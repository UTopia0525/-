# 건물 방향과 외부 공간·담장·대문 규칙

사용자가 이전 해석을 정정한 최신 기준이다. 앞으로 건물을 새로 배치하거나 배치를 변경할 때 **실내 구현 여부와 관계없이** 적용한다.

1. **마당이나 담장을 모든 건물에 요구하지 않는다.** 주거/점포/창고의 용도와 환경에 따라 열린 전면·작업 공간 또는 담장으로 구분된 마당을 선택한다.
2. **입구/건물 정면이 접근 도로·골목을 향하도록 건물 방향부터 결정한다.** 길을 등진 건물을 그대로 둔 채 담장에 구멍을 내거나 뒤편으로 새 길을 둘러 해결한 것으로 간주하지 않는다.
3. 카메라에서 보이는 면에 맞는 앞/옆/뒷면 그림을 사용한다. 필요한 방향의 그림이 없으면 추가 제작한다. 평면 회전/비균등 확대나 단순히 문을 뒷벽에 복제하는 방식으로 방향을 속이지 않는다.
4. 길 쪽 문이 카메라 반대편에 있으면 건물 뒷면이 보이는 것이 정상이다. 실제 문 위치는 해당 정면의 바닥 좌표로 등록하고 가려진 문을 후면에 억지로 그리지 않는다.
5. **담장을 설치하는 경우** 소속 공간을 외부와 구분하는 경계로 연결한다. 소속 건물과 마당 영역을 지정하고 외곽 경계에 맞춰 연결한다. 구획과 무관한 외딴 담장이나 쓰임 없는 담장 조각을 두지 않는다.
6. 대문/출입구만 의도적으로 열고 나머지 경계는 이어 준다. 담장은 문 앞 공간/공공 보행로/건물 출입을 막지 않는다. 문기둥은 충돌하되 통로는 인물 발밑 크기와 여유 폭을 확보한다.
7. 담장 출입구를 단순한 끊김으로 끝내지 않는다. 방향/축척에 맞는 문기둥과 문틀 또는 문짝의 별도 대문 그림으로 표현한다. 지붕은 선택 사항이다. 민가의 지붕 대문/창고의 실용적인 목제 문틀 등 용도에 맞게 구별하며 충돌/통로/가림도 에셋과 맞춘다.
8. 마당을 둘 경우 민가는 생활 마당, 창고는 작업 마당처럼 용도에 맞게 구성한다. 담장 없는 점포/작업 공간도 빈 앞자리와 접근 동선을 확보한다. 도로 → 마당 출입구 → 정면 문턱까지 실제로 걸어갈 수 있어야 한다.
9. 건물 바닥 점유/문턱/기단/지붕 가림을 구분한다. 그림·바닥·그림자와 충돌이 같은 방향/배치를 따르는지 플레이 카메라에서 확인한다.

## 독립 시험 구현

민가의 담장/지붕 대문과 창고의 담장/목제 문틀 대문을 비교한다. 창고에는 해당 골목 방향의 새 `warehouse-gate.png`를 사용한다. 두 기둥의 그림 기준점과 실제 발밑 충돌 중심을 짝지어 균일 배율로 배치하며 정면 그림을 평면 회전하거나 비균등하게 늘리지 않는다. 열린 가운데는 비워 두고 문기둥만 통행을 막는다.

외부 앞마당의 목공 작업대는 담장 없는 열린 작업 공간이다. 작업대와 공용 통행을 구분하는 옅은 작업 바닥/빈 앞자리를 사용하며 새 건물이나 담장을 추가하지 않았다. 도시 전체의 담장 설치를 일반화하는 예시가 아니다.

| 데이터 | 역할 |
| --- | --- |
| 건물 `front`, 에셋 `front`/`view` | 실제 정면 방향과 카메라에서 보이는 면 |
| `entrance.threshold` / `facing` / `road_anchor` | 문턱, 정면 방향, 향해야 할 도로 지점 |
| `entrance.visibility` | 원화의 문이 보이는지, 뒷면 그림에 가려지는지 |
| `entrance.approach` / `apron` / `path` | 접근 지점·빈 앞자리·공용 길에서 오는 경로. 담장 없는 전면에도 사용 가능 |
| 선택적 `plot` / `plots` | 담장이 있는 건물의 마당 소속·영역·출입구. 담장 없는 건물에는 강제하지 않음 |
| 대문 `opening` / `colliders` | 실제 통로와 단단한 문기둥 범위 |
| 대문 에셋 `post_pixels` | 서로 다른 방향으로 그린 기둥 하단의 원본 좌표; 실제 충돌 기둥에 대응 |
| `outdoor_spaces`의 `mode: open` | 담장 없이 작업대/빈 앞자리/접근 경로로 구성하는 공간 |

`iso_access_rules.gd`는 모든 건물의 입구 방향/접근을 검사하되 독립 마당을 필수로 요구하지 않는다. 소속 마당을 지정한 건물만 경계/소유 검사를 수행한다. 담장 출입구에는 실제 대문 그림과 문기둥 충돌이 있어야 하며 열린 통로는 인물이 통과할 수 있어야 한다. 열린 작업 공간은 주변 담장 없이 접근 가능한지 검사한다.

이 자동 검사는 현재 작은 직사각형 마당 시험용이다. 본게임 도시 전체를 소급 변경/검사하지 않았으며 비정형 대지·공유 공간·다층/계단 등은 해당 콘텐츠를 만들 때 별도 모델이 필요하다.
