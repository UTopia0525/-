# 장사–무창 육로

장사보다 무창이 동북쪽에 있는 관계를 살려 **아래쪽에서 먼저 동진한 뒤 굽이진 산길로 북상**한다. 남북으로 긴4096×10240 지형이며 실제 도시 간 거리와 이동 시간을 재현한 지도는 아니다. NPC·적·랜덤 전투·새 퀘스트·입장 조건은 추가하지 않았다.

## 이동

1. F5 → **장사 자유 탐방**, 장사 북문 안쪽의 ‘무창 방면 산길 →’에 접근해 **F**.
2. 산길 서쪽 끝에 도착한다. 오른쪽으로 걸어간 뒤 북쪽으로 난 길을 따른다.
3. 북쪽 끝의 ‘↑ 무창 남문’에서 **F**를 누르면 무창 남문 안쪽으로 들어온다.
4. 무창 남문 아래의 ‘↓ 장사 방면 산길’로 나가면 같은 길을 역으로 걸어 장사로 돌아갈 수 있다.

타이틀의 기존 ‘무창 지도 답사’는 **무창 자유 탐방**으로 바꿨다. 이쪽에서도 남문을 통해 산길을 이용할 수 있다. 다른 자유 탐방과 마찬가지로 새 플레이 상태로 시작하므로 기존 진도를 이어갈 때는 저장 불러오기를 사용한다. 독립 `scenes/wuchang.tscn`의 F6 지형 답사는 남겨 두었다.

출입 지점은 이동 표식이며 NPC나 의뢰인이 아니다. 자동 이동·즉시 동행 선택지는 없고 가까이에서 F로 직접 이동한다. 사절 대화와 무림맹의 보상·후속 이야기는 아직 연결하지 않았다. 도착 시 반대편 출구에서 떨어진 안전 위치를 사용해 반복 이동을 방지한다.

## 지형과 기능

바위 능선·흙길·숲과 몇 차례 굽이를 배치했다. 바닥은 지형만 가진 캐시 그림이며 바위·나무82개는 각각 독립 그림/충돌체다. 원본 바위 그림은 이미지 생성 도구로 제작했다. 절벽 경계는 실제 통행 다각형의 선분 충돌과 일치하며, 길 찾기도 같은 다각형과 발 반경을 사용한다. 절벽을 가로질러 목적지로 갈 수 없다.

기존 이동 속도360·인물 높이140·중앙 추적/가장자리 고정을 유지한다. 미니맵은 주변 지형·위치·출입 지점을 표시한다. TAB 전체 지도는 세로로 긴 비율을 보존한다. NPC가 없는 산길/무창에서는 시설 안내 버튼을 표시하지 않는다. I/K/Q/설정은 기존 시스템을 사용하며 BGM은 기존 여정 곡을 사용한다.

산길과 무창에서도 수동 저장/불러오기가 가능하다. schema3을 유지하고 허용 지도ID·좌표 범위를 확장했다. 기존 schema1~3 저장 읽기, 대화/거래/전투 중 저장 금지는 유지한다. 여행은 소지금·장비·무공·의뢰 진도·보상을 변경하지 않는다. 장사로 돌아오면 기존 주민과 의뢰 표식을 복원한다.

## 소스·검사

- `scripts/overland_travel.gd`: 왕복 출입 지점과 안전 도착 위치, 공통 F 이동.
- `scripts/mountain_road_map.gd`: 공용 무창 맵 구조를 확장한 산길 통행·충돌.
- `scripts/mountain_road_ground.gd`, `assets/maps/changsha-wuchang/`: 지형과 독립 바위 자산·배치.
- `python godot/tools/build_mountain_road.py`: 배치 재생성.
- `DISPLAY=:97 godot --path godot --script res://tools/bake_regional_ground.gd`: 건물 없는 지형 캐시 재생성. 창/렌더러가 있는 환경에서 실행한 뒤 에디터로 새 그림을 가져온다.
- `tests/overland_travel.gd`: 실제 F 왕복, 전 구간 물리 통과·가로 이동 후 북상, NPC 없음, 절벽 차단, 지도 비율·시설 숨김, 새 지역 저장·좌표 검증, 소지금/활성 의뢰 유지.
- 회귀 검사: `city_collision`, `adventure_features`, `saves`, `save_restrictions`, `wuchang`. 검사마다 별도 XDG 사용자 경로 사용.
