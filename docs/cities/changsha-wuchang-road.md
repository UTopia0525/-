# 장사–무창 육로

장사보다 무창이 동북쪽에 있는 관계를 살려 **아래쪽에서 먼저 동진한 뒤 굽이진 산길로 북상**한다. 남북으로 긴4096×5120 지형이며 실제 도시 간 거리와 이동 시간을 재현한 지도는 아니다. NPC·적·랜덤 전투·새 퀘스트·입장 조건은 추가하지 않았다.

## 이동

1. F5 → **장사 자유 탐방**, 장사 동문 밖 농촌 동쪽 끝의 ‘무창 방면 산길 →’에 접근해 **F**.
2. 산길 서쪽 끝에 도착한다. 오른쪽으로 걸어간 뒤 북쪽으로 난 길을 따른다.
3. 북쪽 끝의 ‘↑ 무창 남쪽 농촌’에서 **F**를 누르면 무창 남쪽 농촌에 도착한다. 농촌 길을 따라 북쪽 남문으로 들어간다.
4. 무창 남쪽 농촌 끝의 ‘↓ 장사 방면 산길’로 나가면 같은 길을 역으로 걸어 장사로 돌아갈 수 있다.

타이틀의 기존 ‘무창 지도 답사’는 **무창 자유 탐방**으로 바꿨다. 이쪽에서도 남문을 통해 산길을 이용할 수 있다. 다른 자유 탐방과 마찬가지로 새 플레이 상태로 시작하므로 기존 진도를 이어갈 때는 저장 불러오기를 사용한다. 독립 `scenes/wuchang.tscn`의 F6 지형 답사는 남겨 두었다.

장사 동쪽 농촌 끝·산길 서쪽/북쪽 끝·무창 남쪽 농촌 끝, 총4곳에 푸른색 포탈을 표시한다. 포탈은 NPC나 의뢰인이 아니다. 밝은 푸른 타원과 바닥 고리·작은 빛 입자가 움직이며 목적지를 위에 표시한다. 가까이에서 선택되면 밝아지고 F 이동 안내가 나타난다. 자동 이동·즉시 동행 선택지는 없고 가까이에서 F로 직접 이동한다. 사절 대화와 무림맹의 보상·후속 이야기는 아직 연결하지 않았다. 도착 시 반대편 출구에서 떨어진 안전 위치를 사용해 반복 이동을 방지한다.

## 지형과 기능

바위 능선·흙길·숲과 몇 차례 굽이를 배치했다. 바닥은 지형만 가진 캐시 그림이며 바위·나무82개는 각각 독립 그림/충돌체다. 원본 바위 그림은 이미지 생성 도구로 제작했다. 절벽 경계는 실제 통행 다각형의 선분 충돌과 일치하며, 길 찾기도 같은 다각형과 발 반경을 사용한다. 절벽을 가로질러 목적지로 갈 수 없다.

기존 이동 속도360·인물 높이140·중앙 추적/가장자리 고정을 유지한다. 미니맵은 주변 지형·위치·출입 지점을 표시한다. TAB 전체 지도는 세로로 긴 비율을 보존한다. NPC가 없는 산길에서는 시설 안내 버튼을 표시하지 않는다. 무창에는 민간 영약상·장인·교관이 있어 시설 표시와 안내를 지원한다. I/K/Q/설정은 기존 시스템을 사용하며 BGM은 기존 여정 곡을 사용한다.

산길과 무창에서도 수동 저장/불러오기가 가능하다. schema3을 유지하고 허용 지도ID·좌표 범위를 확장했다. 기존 schema1~3 저장 읽기, 대화/거래/전투 중 저장 금지는 유지한다. 여행은 소지금·장비·무공·의뢰 진도·보상을 변경하지 않는다. 장사로 돌아오면 기존 주민과 의뢰 표식을 복원한다.

## 소스·검사

- `scripts/overland_travel.gd`: 왕복 출입 지점과 안전 도착 위치, 공통 F 이동.
- `scripts/mountain_road_map.gd`: 공용 무창 맵 구조를 확장한 산길 통행·충돌.
- `scripts/mountain_road_ground.gd`, `assets/maps/changsha-wuchang/`: 지형과 독립 바위 자산·배치.
- `python godot/tools/build_mountain_road.py`: 배치 재생성.
- `DISPLAY=:97 godot --path godot --script res://tools/bake_regional_ground.gd`: 건물 없는 지형 캐시 재생성. 창/렌더러가 있는 환경에서 실행한 뒤 에디터로 새 그림을 가져온다.
- `tests/overland_travel.gd`: 실제 F 왕복, 전 구간 물리 통과·가로 이동 후 북상, NPC 없음, 절벽 차단, 지도 비율·시설 숨김, 새 지역 저장·좌표 검증, 소지금/활성 의뢰 유지.
- 회귀 검사: `city_collision`, `adventure_features`, `saves`, `save_restrictions`, `wuchang`. 검사마다 별도 XDG 사용자 경로 사용.

실제 실행 화면: [전체 산길](../../godot/screenshots/overland-full-map.png), [구역 지도](../../godot/screenshots/overland-overview.png), [동쪽 굽이](../../godot/screenshots/overland-east-turn.png), [산길](../../godot/screenshots/overland-mountain-pass.png), [무창 도착](../../godot/screenshots/overland-wuchang-arrival.png).

세로 길이는 최초 지도의 절반으로 줄였다. 가로 거리·길 폭·인물·바위/수목 그림 크기는 유지하고 위치와 구역을 재배치했다. 북쪽 출입구는 새 경계 안으로 옮겼다. 이전 긴 산길에서 저장한 진도는 `world.layout_version`이 없으면 Y좌표를 절반으로 변환하고 안전 위치를 찾는다. 새 저장은 버전2를 기록해 다시 불러올 때 중복 변환하지 않는다.

포탈 효과는 `scripts/travel_portal.gd`의 독립 Node2D로 그린다. 충돌체 없이 발밑 Y정렬을 따르며, 클릭하면 포탈까지 걸어가고 F를 눌러야 이동한다. 미니맵의 푸른 고리와 전체 지도의 푸른 목적지 글자로 위치를 구별한다. 설정 일시정지 시 효과도 멈춘다. `tests/overland_travel.gd`는 실제 F키 입력으로 네 포탈 왕복, 가까운 포탈 강조/안내, 먼 거리 이동 금지, 효과 일시정지를 함께 확인한다.

포탈 실제 화면: [장사 동쪽 농촌](../../godot/screenshots/overland-changsha-exit.png), [산길 북쪽](../../godot/screenshots/portal-road-north.png), [무창 남쪽 농촌](../../godot/screenshots/portal-wuchang-south.png).

도시 포탈 위치 조정: 장사(1490,510)는 기존 동문 밖 농촌의 동쪽 끝, 돌아오는 위치는(1440,510)이다. 무창은 기존 성내 좌표를 유지하고 남쪽으로384만큼(배치 좌표) 확장해 월드8192×7680으로 만들었다. 새 농촌의 논밭4곳·농가2채·헛간·우물·짐·수목을 배치하고 포탈은(1100,1840), 도착은(1100,1790)으로 둔다. 기존 무창 저장 위치는 변환하지 않는다. 새 위치 저장과 작물 안쪽 충돌/길 찾기·남문 진입·실제 F 왕복을 검사한다. 산길에 NPC는 추가하지 않았다. 무창의 민간 주민은 별도 인물 데이터로 배치한다.
