# 항주 · 서호와 취월루

남경6144×4096보다 조금 작은5632×4096(배치1760×1280/배율3.2)이며 소주4608×3072보다 크다. 무창의 넓은 외곽까지 포함한8192×7680보다 크다는 뜻은 아니며, 기존 도시 크기는 변경하지 않았다.

- 서쪽 서호·산책로, 서북쪽5층 주루 **취월루**와 수변 정자/풍류거리.
- 북문/관아, 동북 운하 나루·창고, 상점/상회거리, 객잔/차거리, 공방거리, 주거 골목.
- 사용자 예외로 무관과 교관은 미배치. 상인 두청하/장인 한수성은 기존 공용 B형 초상화/탐험 도트를 사용하고 기존 영약·병장기만 거래한다. 후속 승인으로 일반 주민8명을 더해 도시10명이며, 생활 대화와 주민 관계를 연결했다. [명단·실제 대화·배치](../characters/hangzhou-residents.md). 후속 요청으로 [생활 의뢰5종](../quests/hangzhou.md)을 구현했다. 새 세력 사건/영약/무공은 없다.
- 취월루는5층 외관과 독립 충돌/Y정렬을 가진 주루다. 후속 요청으로 [취월루 실내](cuiyue-hall.md)의 단일 연회장과 정문 F 왕복 출입을 구현했다. 위층 회랑은 장식이며 층별 이동은 없다. 다른 주루/객잔/상가를 특정 문파 소속으로 자동 지정하지 않는다.

## 건물과 바닥을 함께 맞추는 방식

`assets/maps/hangzhou/layout.json`에 도로 폭·건물 전체 표시 영역·건물 부지를 함께 정했다. 지붕/계단을 포함한 표시 영역이 도로를 덮지 않는 배치를 먼저 검사했다. `hangzhou_ground.gd`와 `tests/bake_hangzhou_ground.gd`는 같은 데이터에서 `layout-ground.png` 배치 시안을 렌더한다. 이를 참조해 이미지 도구로 작은 석판/꽃잎/부드러운 부지 경계/서호 반사를 마감한 `ground.png`를 만들었다. 건물은 바닥에 굽지 않고 전용 투명 미술로 별도 배치한다.

도로/부지를 바꿀 때는 시안을 다시 렌더하고 최종 바닥을 그 시안에 맞춰 수정해야 한다. 시안 출력이 최종 미술을 자동 덮어쓰지 않게 파일을 분리했다. 무관이나 중앙 대형 연무 문양은 없다.

## 이동·검증

소주→강남 운하길 남쪽 `[1270,930]` F→항주 북쪽 `[1080,110]`. 항주 `[1080,60]` F로 운하길 `[1270,890]`에 돌아온다. 운하길의 이전 ‘통행 불가’ 표시는 제거했다.

카메라 가장자리 고정·지도/미니맵·의뢰 귀환 안내·수동 저장과 복원·상인/장인 대화 거래를 지원한다. 서호와 북쪽 수로는 통행을 막았다. 실제 건물 발밑 충돌을 사용하며5층 지붕도 공통 Y정렬/가림 처리를 따른다.

`tests/hangzhou_map.gd`: 실제 F 항주 왕복·전 건물 앞 접근·전체 도로 통행·호수 차단·지도/저장/복원·소주 귀환 안내·상인/장인 대화 거래. `tests/canal_map.gd`: 기존 운하길 회귀.

## 반복 배치 수정

동쪽의 작은 단독 건물/개별 앞마당 반복을 줄이고5칸/4칸의 서로 다른 점포들이 처마를 맞대는 전용 `market-rows.png`를 만들었다. 북문 장터와 중부 시장에 이어진 점포길을 배치하고, 시장을 가로질러 끊던 일부 세로 골목은 외곽으로 돌렸다. 풍류거리의 중복 객잔은 찻집으로, 남쪽 반복 주택은 작은 집/상회/염색집으로 나누고 공방은 위치와 크기를 달리했다.

각 건물 앞의 작은 노점10개와 반복 가로등을 제거했다. 노점4개는 찻거리의 공동 먹거리 마당에 모았고, 점포의 물건은 점포 문턱/차양 안에 붙였다. 공용 시장 부지를 한 덩어리로 정해 모든 건물에 똑같은 작은 사각 앞마당을 그리지 않는다. 새 바닥은 수정 배치 시안에 맞춰 다시 미술 마감했다. 취월루/관아/서호/포탈·세계 크기·상인과 장인·기존 거래는 유지했다.
