# 모용세가 · 태호 수향 장원

소주 북쪽 F 포탈과 연결한4608×3072 장원. 기존 도시나 남궁 건물을 확대 복제하지 않고 은회색 기와·백벽·자색 장식의 본당/장서각/연무정/수변 회랑/객방/월문을 독립 투명 오브젝트로 배치한다. 중앙 연무석은 테두리를 포함한 보호 구역 `[555,250,430,400]`을 비워두며 기존 크기의 담장과 공통 충돌/Y정렬·문기둥/가림·카메라·TAB·미니맵을 사용한다. 건물 안 별도 실내는 이번 범위에 없다.

인물은 모용경원·모용유안·진석우·일반 무사2명이다. 가주/소가주는 기존 승인 초상화를 사용하고 새 고유 탐험 도트를 등록했다. 일반 무사는 새 전용 초상화와 공용 도트1종을 두 문지기에 재사용한다. 진석우는42세, 가족에게 품삯을 보내는 호송 낭인으로 기본18장 중 `male_common_a`를 재사용한다. 별도 영구 전투 수치는 부여하지 않는다. 유안의 교류 대련 수치는 힘을 제한한 해당 조우만의 설정이다.

의뢰 흐름과 전체 대사는 [적용 대본](../quests/murong-exchange.md)에 기록한다. 세가의 장서·무학 연구·후원 문화와 낭인의 생계 차이가 중심이다. 이번 이야기에 음모나 숨은 배신 암시는 없다.

- 소주 「손에 맞는 병장기」 완료 후 백정수에게 선택 수락.
- 유안 환영→첫 대련→진석우의 사정→좁은 통로 재현/짧은 초식 보완 선택→검증 대련→복기→가주 보고.
- 첫 대련은7×5, 좁은 통로 검증은7×3/모서리 장애물, 초식 보완 검증은7×5. 유안이 두 대련의 상대이고 진석우가 자신의 실전 경험을 설명한다. 화물 호위 별도 승패 목표는 도입하지 않았다.
- 두 대련 모두 비살상이며 패배해도 재도전을 강제하지 않고 다음 복기로 이어진다.
- 마지막 보고에서500문·모용 호의도10. 수련 후원은 진석우에게 주어지며 플레이어 비전 전수는 없다.
- 다른 일반 의뢰와 동시 진행, Q 추적/!/보고?/R 호의도/여러 시점 저장을 지원한다. 대화·거래·전투 중 저장 금지는 유지한다. 기존 저장에 새 의뢰 필드가 없으면 미수락으로 복원한다.

검증: `tests/murong_quest.gd`의 F 상호작용/입장/두 분기/실제 대련과 비살상 패배/보상1회/이전 저장/장원 저장, 기존 `tests/suzhou_quests.gd` 회귀. `tests/capture_murong.gd`는 실제 전체 맵·탐험·대화 화면을 출력한다.

배치 수정: 연무석을 축소하고 주변 녹지를 넓혔다. 본당을 북쪽으로 정리하고 회랑은 서남 녹지, 객방은 동남 녹지에 배치했다. 진석우는 객방 서쪽 앞에 옮겼다. 건물·담장·문 충돌/Y정렬은 유지하며 맵 크기와 포탈 좌표는 같다. 기존 탐험 저장 위치가 새 건물과 겹치면 공통 안전 위치 복원으로 보정한다.

상단 장서각/연무정은 동일한 표시 크기170×170·Y80(발밑 기준250)으로 맞추고 중심X490/1046을 장원 축X768에 대칭 배치했다. 주 횡단 보행로 보호 구역 `[240,390,1080,130]`에 지붕/계단을 포함한 건물 표시 영역이 겹치지 않게 유지한다.
