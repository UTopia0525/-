# 무공 재편: 위력·행동력·내기·범위

2026-10-27 사용자 요청 반영. **이름 있는 플레이어 무공16종 = 입문1 + 하급8 + 중급7**. 기본공격/기본방어2종은 별도다. 새 무공·아이템을 추가하지 않았으며 기존 전용 아이콘을 유지한다.

## 적용 범위

- 실제 카탈로그/학습/거래/기존 전투: 등급·정리된 목록·근력/내공 계수·고정 위력·내기 비용 적용. 가격/보상/학습 조건은 유지한다.
- 실제 K창: 아래 행동력 비용/공격·이동 도식/등급·위력식을 표시한다. 권/장은 한 맨손 탭에서 함께 본다.
- 후속7×5 전투: 아래 범위/이동/밀침/행동력 비용은 실행 데이터다. **현재 본게임은 [가변 격자 전투](../systems/grid-combat.md)에서 새 범위·행동력 차감·행동 시작에 따른 방어 만료를 실행한다.** 기존 HTML 실험실도 자동 갱신하지 않았다.
- 쇄암검법→청풍검법, 진각권법→철산권법으로 정리. 이전 저장은 습득을 이어받고, 두 기술이 같은 편성에 있으면 첫 위치를 유지하고 겹친 뒤 칸만 비운다. 저장 파일 원본은 불러오기만으로 덮어쓰지 않는다.

## 공통 규칙

- 무기 무공은 근력 계수 > 내공 계수, 맨손은 내공 계수 > 근력 계수. 기민/근골/오성은 아래 무공 위력에 합산하지 않는다. 별도 기본공격의 기존 식은 이번 개편 대상에 넣지 않았다.
- 위력은 무기/상대 근골/방어 계산 **이전** 값. 창의 고정 위력도 방어를 무시하는 피해가 아니다.
- 검: 낮은 행동력·내기, 안정적인 검로와 기존 피해20% 감소. 도: 큰 행동력 지출과 높은 위력·광역. 창: 높은 내기와 고정 위력, 무기의 내기 절감10/20/30% 적용. 맨손: 강한 내공 계수와 근접 제압.
- 공격·자기 이동·대상 밀침의 끝 위치 모두 **출수 직전 시전자 기준 가로/세로 이동 합3칸 이내**. 예를 들어 (2,1)은3칸, (3,1)은4칸이라 제외한다. 상급용 장거리 여지를 남긴다.
- 도식은 오른쪽 방향 예시. 실제 격자 엔진에서는 네 방향 회전·전장 밖/장애물/점유 판정이 필요하다. 벽 너머를 자동 관통하지 않는다.
- ‘대상1명’은 칠 수 있는 위치 중1명, ‘범위전체/관통’은 각 대상에게 위력을1회 적용한다. 여러 칸에 걸쳤다고 같은 적을 중복 타격하지 않는다.
- 이동을 포함한 무공은 한 행동이다. 전진 칸이 막히면 사용 불가, 공격 후 후퇴/대상 밀침이 막히면 공격은 유지하고 이동만 생략하는 것을 후속 구현 기준으로 둔다.
- 새 행동마다 게이지100 이상 및 해당 비용 충족이 필요하다. 기본공격30/기본방어20, 나머지는 아래 표. 방어20%는 다음 자기 실제 행동 시작까지 그 사이 모든 공격에 적용하는 기존 후속 합의를 따른다.


## 범위와 명중 편의에 따른 위력 보정

같은 무기·등급에서는 넓게 덮거나 쉽게 맞히는 기술의 **대상당 위력**을 낮춘다. 좁은 직선/단일 대상은 집중 위력을 유지한다. 전진·후퇴와 사방 대응도 명중 편의로 평가한다. 범위/행동력/내기/방어/학습/가격은 이번 보정에서 변경하지 않았다. 조식수원공과 기본 행동도 유지한다.

회풍<단석, 연환<관풍, 운기<철산, 중운<반석, 쇄랑<파악의 대상당 위력을 기준으로 삼는다. 쇄랑은 더 넓은 범위에 힘을 나누므로 이제 파악보다 대상당 위력이 낮다. 창은 고정 위력 중심의 초반 우세를 유지하고, 맨손은 내공 중심을 유지한다. 이동 공격인 반석과 긴 직선인 관악도 명중 편의를 반영해 위력만 낮췄다.
