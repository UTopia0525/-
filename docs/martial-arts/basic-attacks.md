# 삼재검법 상위 초급 공격 무공 10종

사용자 확정: **삼재검법은 근력×3 + 기민×2, 내기 소모 10**이다. 아래 신규 10개는 사용자가 요청한 기준에 맞춰 창작한 수치 제안이며 획득 방법은 전부 미정이다. 문파·전수자·보상·상점 판매처를 부여하거나 주인공에게 자동 지급하지 않는다.

시작 스탯은 다섯 가지 모두 10, 합계 50이다. 신규 학습 조건은 개별 스탯 12~18, 합계 60~80으로 정했다. 명칭이 아직 없는 절정 이전 단계에서 배울 수 있도록 절정(합계100) 조건은 붙이지 않는다. 조건에 적지 않은 스탯은 개별 제한이 없지만 총합 계산에는 다섯 스탯이 모두 들어간다. 개별 조건과 합계 조건은 **모두** 충족해야 한다.

## 무공의 인상

- **청풍검법**: 검 끝의 흔들림을 줄이고 빠르게 한 선을 그어 베는 검법.
- **유수검법**: 힘을 억지로 멈추지 않고 몸의 흐름과 내기를 검 끝에 잇는 검법.
- **쇄암검법**: 단단히 버틴 하체를 바탕으로 무거운 일격을 내려치는 검법.
- **단석도법**: 도의 무게를 실어 짧고 깊게 내려베는 도법.
- **회풍도법**: 몸을 돌려 모은 힘을 넓은 베기 한 번으로 풀어내는 도법.
- **관풍창법**: 상대의 움직임을 읽고 창 끝을 곧게 뻗어 찌르는 창법.
- **연환창법**: 허초와 실초를 이어 마지막 찌르기에 내기를 집중하는 창법.
- **철산권법**: 굳게 선 몸 전체의 힘을 짧은 주먹에 싣는 권법.
- **진각권법**: 발을 굳게 디뎌 얻은 힘과 내기를 한 주먹으로 뻗는 권법.
- **운기장법**: 호흡으로 모은 내기를 손바닥에 집중해 밀어내는 장법.

## 공통 계산과 균형 기준

- 모든 식은 방어 전 전체 피해 D다. 대상 근골 G에 기존 공식 `max(0,D-G)×100/(100+G)`를 한 번 적용한다. 실행 버전의 소수점 버림은 기존 임시 규칙을 유지한다.
- 이번 10개는 모두 공격 1행동의 합산 피해다. 회풍의 넓은 베기를 광역 공격으로 만들거나, 연환을 다중 명중으로 바꾸거나, 쇄암에 방어 무시를 붙이지 않는다. 출혈·기절·관통·명중·치명타 효과도 임의 추가하지 않았다.
- 삼재검법보다 계수 합과 내기 소비가 높고, 무공별 특화 스탯을 다르게 둔다. 내공·근골·오성 비중이 다른 만큼 모든 가능한 스탯 조합에서 항상 같은 무공이 가장 강하다는 의미는 아니다.
- 모든 신규 무공은 내공 12 이상을 요구한다. 기본 삼재검법을 쓰고도 턴마다 내기를 조금씩 축적할 수 있도록 하기 위함이다. 내공10에서 삼재검법(10)을 매턴 쓰면 다음 턴도 내기10이며 비용12 이상을 모을 수 없다는 점을 반영했다.
- 예: 근력16·기민14·근골12·내공12·오성12(합66)일 때 삼재검법 D=76, 청풍검법 D=90, 단석도법 D=92다. 청풍은 비용12로 첫 턴 사용 가능하고, 단석은 비용16으로 기본 공격을 하며 내기를 더 모아야 한다.
- 상위 초급이라는 이름으로 기존 세가 직계 비기나 소실된 비기를 공개 보급하지 않는다. 이번 창작 무공은 특정 기존 세력의 독문무공과 구분한다.

## 데이터와 현재 구현 범위

`godot/data/basic_martial_arts.json`에 삼재검법+신규10종의 피해 계수·내기 비용·개별/총합 학습 조건·획득처 null·설명을 저장했다. 삼재검법은 사용자 확정, 신규10종은 제안으로 표시한다. `martial_arts.gd`는 피해·비용 조회와 학습 조건 판정을 제공한다. 조건을 만족했다고 습득 처리하지 않는다.

현재 전투에 장착된 무공은 여전히 삼재검법 하나다. 전투 실행과 설명의 내기 비용을 10으로 반영했다. 신규 무공의 획득·학습 화면·편성·전투 버튼 연결은 획득 방법과 후속 구현을 정할 때 진행한다. 캐릭터 전투 스탯을 임의로 바꾸지 않는다.

검증: `godot --headless --audio-driver Dummy --path godot --script res://tests/martial_arts.gd`. 열 개의 학습 불가/가능 경계와 개별 조건·총합 조건, 피해 계수, 비용, 미정 획득처와 자료 복사 안전성을 검사한다. `tests/inner_qi.gd`, `tests/smoke.gd`, `tests/saves.gd`로 비용10 반영 후 기존 전투·회복·저장도 확인한다.

## 무기 장착 조건 — 최신 사용자 요청

검법은 **검**, 도법은 **도**, 창법은 **창**을 실제 장착해야 사용할 수 있다. 삼재검법에도 적용한다. 검과 도는 서로 대체되지 않는다. 무기를 보유만 하고 있거나 다른 종류를 장착한 상태는 조건 충족으로 간주하지 않는다. 권법·장법은 현재 특정 무기 조건을 지정하지 않았으며 맨손 전용이나 권갑 필수로 임의 확정하지 않는다.

학습 가능 여부와 사용 가능 여부를 분리한다. 스탯과 총합 조건을 만족해 무공을 배웠어도 맞는 무기를 장착하지 않으면 실행할 수 없다. 해당 무공의 설명은 확인할 수 있고 사용 버튼은 비활성화한다. 무기가 맞지 않는 직접 실행 요청도 피해·내기·턴을 소모하지 않고 차단한다.

`required_weapon_type`을 각 무공 데이터에 추가하고, `martial_arts.can_use_with_weapon()`으로 공통 검사한다. 앞으로 무기 계열 무공을 추가할 때도 해당 필드를 명시한다. 무기 이름·등급·추가 공격력과 장비/인벤토리 화면은 이번에 만들지 않았다. 현재 삼재검법 튜토리얼은 기존 그림과 진행에 맞춰 검 장착 상태로 시작한다. 무기 분류는 수동 슬롯에도 보존하며, 이전 저장에 필드가 없으면 기존 튜토리얼의 검으로 복원한다.

`tests/martial_arts.gd`와 `tests/weapon_requirements.gd`에서 모든 무공의 무기 일치/불일치, 맨손 상태, 잘못된 무기의 무소모 차단, 장착 조건 설명, 저장/과거 저장 호환을 검사한다.

구체 무기 이름·등급별 보정은 [무기 체계](../systems/weapons.md)를 따른다. 새 플레이는 무문철검을 장착하며 기존 무공 계수에 보정이 없다. 검/도 피해 보정과 창 비용 절감은 해당 무기로 쓰는 무공에만 적용한다.
