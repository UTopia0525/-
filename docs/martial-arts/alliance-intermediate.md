# 무림맹 교관 전수용 중급 무공

검·도·창·권·장 각1문, 총5문을 카탈로그와 전용 아이콘에 등록했다. **능력치·경지·선행 무공 학습 조건은 없다.** 검/도/창은 해당 종류 무기, 권/장은 맨손을 사용하며 전투 시 내기를 소모한다. 사용 내기가 부족하면 기본공격/기본방어로 내기를 모을 수 있다. 무공이 늘어나도 4칸 편성은 그대로다.

총관 면담 후 교관에게 한 문을 배우는 후속 이야기의 후보군이다. 정식 전수 장면·선택 UI·보상 지급은 아직 미구현이며, 이번 작업으로 시작 캐릭터에게 무공을 지급하거나 일반 도시 교관의350문 판매 목록에 넣지 않는다. 실제 NPC 스토리를 연결할 때 선택한 한 문을 `learned`에 추가하면 K 편성·공통 전투·저장에 연결된다. 테스트/캡처에서는 격리된 학습 완료 상태를 사용한다.

## 무공과 수치

아래 식은 무기와 적 근골 보정 전 위력이다. 고정 위력은 방어를 무시하는 확정 피해가 아니라 기존 피해 공식에 함께 들어간다.

| 무공 | 사용 조건 | 위력 | 기본 내기 | 개성 |
| --- | --- | --- | --- | --- |
| 회류검법(回流劍法) | 검 | 근력×5 + 기민×4 + 근골×2 + 내공×2 |18| 원으로 검로를 되감아 공격과 수세를 잇는다. 출수 후 다음 적 공격 피해20% 감소. 검의 장비 공격/피해 감소 효과도 적용. |
| 파악도법(破嶽刀法) | 도 | 근력×7 + 기민×5 + 근골×2 |22| 하체와 허리의 힘을 도날에 모아 내려벤다. 별도 방어 없이 높은 피해 계수와 도 장비의 공격 보정에 집중. |
| 관악창법(貫嶽槍法) | 창 | **240** + 근력×2 + 기민×3 + 내공×1 |28| 높은 고정 위력과 낮은 성장 계수. 익힌 직후 강하고 창 장비의 내기 절감을 받는다. 균형창으로 실제 소모26. |
| 반석권법(磐石拳法) | 맨손 | 근력×6 + 근골×4 + 내공×5 |26| 몸을 반석처럼 세워 육체와 내기를 짧은 주먹에 집중. 무기 공격 보정 없이 높은 계수로 성장. |
| 중운장법(重雲掌法) | 맨손 | 근력×2 + 내공×9 + 오성×5 |24| 층층이 모은 내기를 장력으로 풀어낸다. 내공과 오성 중심의 성장. 내기 소모24로 저내공 운용 부담을 줄였다. |

중급 검법에도 기존 검법의20% 수세를 사용한다. 별도 방어 중첩·관통·다단 타격·지속 피해는 새로 도입하지 않았다.

## 비교

모든 능력치20일 때, 장비 보정 전 각 계열 하급 최고 위력과 비교:

| 계열 | 하급 최고 | 중급 |
| --- | --- | --- |
| 검 |140|260|
| 도 |140|280|
| 창 |280|360|
| 권 |220|300|
| 장 |220|320|

모든 능력치100이면 중급 검1300·도1400·창840·권1500·장1600이다. 무기 보정 전부터 검·도·권·장이 창을 앞서므로 고정 위력 중심 창법의 사용자 확정 성장 방향을 유지한다. 실제 효율은 능력치 배분·장비·내기 회복·검의 수세에 따라 달라진다.

## 구현과 확인

- `data/alliance_martial_arts.json`: 독립 전수 카탈로그. 공통 `martial_arts.gd`에서 기본11문과 함께 읽는다.
- `assets/icons/alliance-martial.png`: 새로 생성한3열×2행 원본 아틀라스. 위 행은 검·도·창, 아래 행은 권·장·빈칸이다. 여섯째 칸은 미등록이며 추후 상급 무공에 자동 전용하지 않는다.
- `data/icon_manifest.json`: 안정 ID5개에 연결. 아틀라스의 행 수를 지원해 기존 정사각형 아틀라스와 공존한다.
- `city_service.gd`: 가격이 없는 스토리 전수 무공은 일반 교관 판매 목록에서 제외한다. K와 전투에는 습득 후 표시된다.
- `tests/alliance_arts.gd`: 학습 무제한·무기 일치·하급 대비 위력·10/20/50/100 성장·내기 축적·기본 수치/절정 문턱/균형 성장의 산적전30건·K/전투 아이콘·저장·일반 상점 비판매를 검사한다.
- `tests/combat_updates.gd`: 전체 카탈로그 이미지 검사와 기존 토벌 전 습득 가능한 도시 무공의 초회 난이도110건을 유지한다. 무림맹 전수 무공은 토벌 후 콘텐츠이므로 해당 구매 전 성장 시뮬레이션에 섞지 않고 별도 검사한다.
