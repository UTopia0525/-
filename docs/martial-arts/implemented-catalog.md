# 실제 인게임 무공 목록

플레이어가 습득·편성할 수 있는 이름 있는 무공은 **16종**이다. 기본공격·기본방어2개는 별도다. [최신 위력·비용·전체 범위 도식](redesign-v2.md)을 함께 따른다. 세계관에만 있는 비기는 제외한다.

| 등급 | 사용 무기 | 무공 | 습득 경로 |
|---|---|---|---|
|입문|검|삼재검법|시작 무공|
|하급|검|청풍검법·유수검법|도시 교관 각350문|
|하급|도|단석도법·회풍도법|도시 교관 각350문|
|하급|창|관풍창법·연환창법|도시 교관 각350문|
|하급|맨손·권/장|철산권법·운기장법|도시 교관 각350문|
|중급|검|회류검법|무림맹 교관 선택 전수|
|중급|도|파악도법|무림맹 교관 선택 전수|
|중급|도|쇄랑도법|남경 의뢰 보상 서책 사용|
|중급|창|관악창법|무림맹 교관 선택 전수|
|중급|맨손·권/장|반석권법·중운장법|무림맹 교관 선택 전수|
|중급·보조|무기 무관|조식수원공|무창 연무장 의뢰 보상|

검법/도법/창법은 해당 종류 장착, 권법/장법은 맨손을 요구한다. 무림맹5종은 한 번에1종만 선택 전수한다. 하급8종의 기존 학습 조건은 유지한다. 조식수원공의 회복·방어·대기 효과도 유지한다.

쇄암검법과 진각권법은 현행 목록에서 제외했다. 이전 저장에 있으면 각각 청풍검법/철산권법으로 이어받으며, 겹친 편성 칸만 비운다.

## 공통 기본 행동과 적 전용 기술

기본공격·기본방어는 등급/무기 제한 없는 기본 행동이다. 실제 적 전투에는 하급 도법 **쇄목도법**, 등급 미정 도 공격 **거친 도질·내려찍기**가 연결되어 있다. 적 기술의 수치/행동은 이번 플레이어 무공 재편에서 변경하지 않았다.

반석진각공은 적 계산·아이콘 데이터만 있고 현재 연결된 실제 조우가 없어 실사용 목록에서 제외한다.

## 데이터와 전투 연결

기본 카탈로그9종(입문1+하급8), 무림맹5종, 보상 서책1종, 보조1종이다. 실제 피해·내기·학습·보상 연결은 있다. 새 행동력 비용/범위와 이동·방어는 [가변 격자 전투](../systems/grid-combat.md)에서 실행한다. 기존 HTML 실험실과도 구분한다.
