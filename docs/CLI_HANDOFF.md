# CLI 작업 인계

기준: 2026-10-24 현재 구현. 새 작업은 이 요약과 [작업 색인](README.md)에서 시작한다. 게임 수정 시 [콘텐츠 작업 규칙](../godot/AGENTS.md)을 따른다.

## 현재 구현

- **맵 미술 통일:** 산길·무창·총무당에 장사 기준의 전용 바닥 그림과 상세 실내 가구를 적용했다. 기존 동선/충돌/포탈/NPC 좌표는 유지하며 새 전체/플레이 캡처는 [미술 정리](cities/regional-map-art.md)에 모았다. 원본 해상도와 무관하게 미니맵 좌표가 맞도록 보정했다.

- **주인공:** 이름은 도원(陶遠), 성 도·외자 원으로 확정했다. 대화/대화 기록/전투 표시 이름과 원고에 반영했으며 내부 `hero` ID는 저장 호환을 위해 유지한다. [인물](characters/player.md).
- **본게임:** Godot 4.6+ Standard, `godot/project.godot`. 웹 데모는 이전 비교용이다.
- **맵 조작 통일:** 0장·장사·산길·무창·총무당과 F6 답사는 WASD/방향키 이동만 지원한다. 클릭 이동/자동 접근은 제거했고 F 대화·조사·포탈을 유지한다. 전투·거래·인벤토리 등 UI 마우스 입력은 유지한다. `keyboard_exploration.gd`, `prologue_f_input.gd`로 확인한다.
- **진행:** 0장 출항·첫 전투·침몰·귀물/구조 선택·표국 해체·장사 입성. 귀물 인도 보수 3,000문, 구조 경로는 해당 보수 없음.
- **장사:** 바닥과 독립 건물·담장·문 등152개 오브젝트, 발밑 충돌·Y정렬·문 중앙 통과/지붕 가림, NPC 전신 겹침 방지. 자유 탐험·미니맵·목표 안내·시설 거래. 불필요 주민16명을 제거해 현재 NPC16명(의뢰11·거래3·토벌2)이다. 의뢰11명에게 이름·배경·일상 대사를 부여했으며 [명단](characters/changsha-quest-residents.md)에 정리했다. 도입 3종은 상인→장인→교관으로 이어지고 완료 대화 뒤 100/150/200문·오성 각5를 한 번 지급한다. 독립 일반 의뢰6종도 수락/보류·수행·보고·보상까지 구현했다. 의뢰인은 노란 !, 보고 대기는 ?, 완료 후 표식을 제거한다.
- **무창 지도:** 남쪽 농촌을 거쳐 남문으로 입성하며 북동쪽에 대형 무림맹 본단을 배치했다. 농촌 확장 후8192×7680, 성내 좌표와 본단 크기는 유지한다. 남동쪽 관아의 북·서·동 담장15개를 보강해 관아 경계를 완성했다(구조물224개). 기존 남쪽 문과 주민 접근은 유지한다. 성곽 동문은 전용 측면 그림과 남북 기둥 충돌로 고쳐 동서 왕복 통행하도록 했다. 타이틀의 ‘무창 자유 탐방’으로 확인한다. 민간 주민8명과 영약상·장인·교관 거래3종을 배치했고 주민 초상화/도트·F 대화를 연결했다. 총무당(정문 안 왼편 기존 접수처)에 F 왕복 포탈과 별도 실내를 추가했다. 실내 가구 충돌·지도·저장/불러오기를 지원한다. 무림맹 경비2명과 교관 곽진석을 성내에, 총관 허문규를 총무당 실내에 배치했다(무창11명·실내1명). 정문 출입 제한과 기본 대화를 연결했으며 [이번 범위](story/alliance-visit-foundation.md)에 정리했다. 송지겸 초대·보증 연출·무공 선택/지급은 다음 단계다. 기본 새 플레이는 신원 미확인으로 입장이 막힌다. [주민과 대사](characters/wuchang-civilians.md). 즉시 동행 선택지 없이 나중에 육로로 방문하는 방향. [지도·진행 구분](cities/wuchang.md), [무림맹](factions/murim-alliance.md).
- **도시 간 육로:** 장사 동쪽 농촌 끝 F→동진 후 북상하는 산길→무창 남쪽 농촌 끝 F, 푸른 포탈4곳으로 왕복 가능. 접근 강조·목적지·F 안내와 지도 표식을 지원한다. 산길은4096×5120으로 최초 세로 길이의 절반이며 긴 지도 저장의Y좌표를 호환 변환한다. 새 지역에서도 지도·I/K/Q·저장 지원. 산길 NPC/전투/사절은 추가하지 않았다. [출입·구현·검사](cities/changsha-wuchang-road.md).
- **이동·비율:** 이동 속도360(기존2배), 도시 주인공140·주민132, 0장104. 충돌·카메라·머리 위 표시를 함께 조정했다. [탐험 크기와 이동](systems/exploration-scale.md).
- **편의:** Q 의뢰 일지, 실제 F 대상 발밑 강조, 거래/I/K 비교·조건/잔액 표시, 약/장/무 시설 지도·필터·안내, L 교전 기록/결산, F2 도움말/최초 안내, ESC 환경 설정, 공통 알림·효과음6종. [입구·진행·검사](systems/adventure-usability.md).
- **성장:** 무기 구매·장착, 무공 전수, 영약 구매·복용, I 소지품/K 무공. 영약은 오성을 올리지 않으며 종류별 평생10개 제한이다.
- **산적 토벌:** 1장 도입 완료·스탯 합계100 이상·삼재검법 외 새 무공1종 습득 후 자동 모집. 2연전·철수/재도전·귀환 보고, 보상500문·오성5·명성5.
- **창 중급 조정:** 사용자는 현재 중급 구간에서도 창 최강을 원한다. 가상 강화 적으로1,080건 비교했고 [검토 결과](reviews/alliance-matchups.md)에 현재 관악창법의 내기 부담과360/18 조정안을 정리했다. 사용자가360/18 조정안을 채택해 적용했다(균형창 내기17). 가상 적은 게임에 등록하지 않았다.
- **무림맹 중급 무공:** 검·도·창·권·장5종을 전용 데이터와 아이콘에 등록했다. 능력치/경지 학습 제한은 없고 무기·내기 사용 조건은 유지한다. 반석권법 내공 계수를6으로 강화해 균형20 기준 장법과 동일한320이다. 일반 교관 비판매이며 무림맹 전수 대화/지급은 아직 미연결이다. [수치·비교·이미지](martial-arts/alliance-intermediate.md).
- **전투:** 기본공격/기본방어/삼재검법/빈칸으로 시작하며 **4칸 모두 교체 가능**. 기본방어70%, 검법 사용 후 방어20%. 적도 공통 내기/무공 규칙을 쓰고 플레이어 선택 전에 행동을 확정한다. 예고는 큰 기세만 보여 준다.
- **포졸 초상화:** 기존 토벌 대화의 `bandit_messenger`에 검정·붉은 관아 근무복/관모·捕 표식·포승줄·단봉을 갖춘 `portraits/story/constable-duty.png`를 적용했다. 기본18장과 주인공은 그대로다. [그림·근거·연결](../godot/assets/portraits/story/README.md).
- **표현:** 검·도·창·맨손 전투 모션과 양측 공격·피격 효과음, 걷기 애니메이션, 상황별 BGM, 번들 붓글씨/명조체, 초상화 비율·시선 처리. 기본 NPC 초상화는 기존 공용10장+무창8장=총18장(남10/여8). 일반 마을 NPC는 별도 지시 없이 새 그림을 만들지 않고 재사용한다. `data/basic_npc_portraits.json`이 목록이며 같은 대화의 이미지 중복을 금지한다. 대화 기록 버튼/H키로 현재까지 읽은 줄을 본다. [오브젝트·대화 도구](systems/layered-city-and-conversation.md).
- **저장:** 수동10슬롯, schema1~3 읽기 호환. **대화·거래·전투 중 새 저장/덮어쓰기 금지**, 탐험·분기 선택창 저장 가능. 과거 버전의 대화/거래/전투 저장은 읽을 수 있다. 일반 의뢰 진행·달성·안부 분기와 시설 안내도 보존한다. 환경 설정은 별도 preferences.cfg다. 자동 0장 체크포인트와 수동 저장은 별개다.

## 유지할 설정

스탯은 근력·기민·근골·내공·오성 각0~100. 경지 합계 기준은100/200/300/400/500이다. 매 전투 체력300·내기=내공으로 시작하고 내기 상한500, 다음 턴부터 내공만큼 회복한다. 개별 무공·장비 수치는 `godot/data/`와 해당 기능 문서를 확인한다.

창법은 상급까지 높은 고정 위력·낮은 성장 계수를 중심으로 설계한다. 미정인 콘텐츠·가격·효과·네임드 전투 스탯을 임의 확정하지 않는다. 비공개 제작자 메모는 저장소 밖에 보관하며 Git으로 복원되지 않는다.

## 다음 작업과 검증

후속 스토리·추가 콘텐츠는 사용자 요청에 따라 범위를 정한다. 이 문서의 목록이 자동 구현 지시는 아니다.

[작업 색인](README.md)에서 관련 문서·소스·기존 검사를 선택한다. 명령과 데이터 격리 방법은 [개발 안내](../godot/README.md)를 따른다. 변경한 기능만 검사하고, 공통 진행·저장·전투 코드를 바꿀 때 관련 회귀 검사를 추가한다.

[이전 인계 전체](archive/CLI_HANDOFF-before-cleanup.md)는 과거 단계·폐기된 제안을 포함한 기록이다. 과거 경위가 필요할 때만 읽는다.
