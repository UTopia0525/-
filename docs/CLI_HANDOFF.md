# CLI 작업 인계

기준: 2026-10-24 정리 시 확인한 `8e31b454`의 구현. 새 작업은 이 요약과 [작업 색인](README.md)에서 시작한다. 게임 수정 시 [콘텐츠 작업 규칙](../godot/AGENTS.md)을 따른다.

## 현재 구현

- **본게임:** Godot 4.6+ Standard, `godot/project.godot`. 웹 데모는 이전 비교용이다.
- **진행:** 0장 출항·첫 전투·침몰·귀물/구조 선택·표국 해체·장사 입성. 귀물 인도 보수 3,000문, 구조 경로는 해당 보수 없음.
- **장사:** 자유 탐험·NPC 충돌·미니맵·목표 안내·시설 거래. 도입 3종은 상인→장인→교관으로 이어지고 완료 대화 뒤 100/150/200문·오성 각5를 한 번 지급한다. 나머지 독립 일반 의뢰 6종의 완료·보상은 미구현이다.
- **성장:** 무기 구매·장착, 무공 전수, 영약 구매·복용, I 소지품/K 무공. 영약은 오성을 올리지 않으며 종류별 평생10개 제한이다.
- **산적 토벌:** 1장 도입 완료·스탯 합계100 이상·삼재검법 외 새 무공1종 습득 후 자동 모집. 2연전·철수/재도전·귀환 보고, 보상500문·오성5·명성5.
- **전투:** 기본공격/기본방어/삼재검법/빈칸으로 시작하며 **4칸 모두 교체 가능**. 기본방어70%, 검법 사용 후 방어20%. 적도 공통 내기/무공 규칙을 쓰고 플레이어 선택 전에 행동을 확정한다. 예고는 큰 기세만 보여 준다.
- **표현:** 검·도·창·맨손 전투 모션, 걷기 애니메이션, 상황별 BGM, 번들 붓글씨/명조체, 초상화 비율·시선 처리를 사용한다.
- **저장:** 수동10슬롯, schema1~3 읽기 호환. **대화·거래·전투 중 새 저장/덮어쓰기 금지**, 탐험·분기 선택창 저장 가능. 과거 버전의 대화/거래/전투 저장은 읽을 수 있다. 자동 0장 체크포인트와 수동 저장은 별개다.

## 유지할 설정

스탯은 근력·기민·근골·내공·오성 각0~100. 경지 합계 기준은100/200/300/400/500이다. 매 전투 체력300·내기=내공으로 시작하고 내기 상한500, 다음 턴부터 내공만큼 회복한다. 개별 무공·장비 수치는 `godot/data/`와 해당 기능 문서를 확인한다.

창법은 상급까지 높은 고정 위력·낮은 성장 계수를 중심으로 설계한다. 미정인 콘텐츠·가격·효과·네임드 전투 스탯을 임의 확정하지 않는다. 비공개 제작자 메모는 저장소 밖에 보관하며 Git으로 복원되지 않는다.
