# CLI 작업 인계 — 2026-10-22

## 현재 상태

명 초기(1390년경)를 배경으로 하는 무협 RPG 기획이다. 탑다운 도트 탐험 + 별도 1인 턴제 전투를 사용한다. 실제 탐험·전투는 아직 구현하지 않았으며 게임 엔진과 구현 기술도 결정하지 않았다. 세계 지도는 world-map/index.html로 실행 가능하고, prototypes/의 화면들은 클릭할 수 없는 이미지 시안이다.

## 먼저 읽을 파일

- README.md: 전체 자료 색인
- docs/factions.md, docs/factions-overview.md: 세력과 인물 설정. 개별 docs/factions 및 docs/characters도 확인할 것.
- docs/characters/creation-guidelines.md: 인물 제작 원칙. 기존 인물에게 전투 수치를 임의 부여하지 않는다.
- prototypes/exploration-screen/README.md: 탐험 화면 시안
- prototypes/battle-screen/README.md: 최신 v2 전투 화면 시안

## 현재 전투 설정

- 기본 스탯은 근력·기민·근골·내공·오성. 각각0~100.
- 합계가100이면 절정, 200이면 초절정, 300이면 화경, 400이면 현경, 500이면 자연경. 기준 이상에서 승급하며 0~99 명칭은 미정.
- 경지는 무공 습득 조건에 사용한다. 개별 무공의 스탯 요구치와 전수 자격은 별도로 정한다.
- 최대 체력은 다섯 스탯 외 별도로 올릴 수 있고 경지 합계에는 포함하지 않는다. 성장 수단·증가량·상한·근골의 체력 기여는 미정.
- 기본 피해 공식은 D=공격 측에서 계산한 방어 전 전체 피해, G=방어자의 근골일 때 max(0,D-G)*100/(100+G). 소수 정수화 방식 미정, 최소 피해1을 자동 추가하지 않는다.
- 시작 캐릭터 기준안은 모든 스탯10, 최대 체력300. 초기 무공 삼재검법의 전체 피해는 근력*3+기민*2이므로50.
- 초기 적 기준안: 근골5, 체력150. 삼재검법 피해는 약42.86으로 4회 명중 시 처치. 적 공격력과 나머지 스탯은 미정.
- 각 전투는 최상의 컨디션으로 시작하고 이전 체력 손실은 이월하지 않는다. 탐험 화면에는 체력을 표시하지 않고 전투 화면에서 표시한다. 내력·상태 이상·패배 처리의 세부 규칙은 미정.
- 전투는 주인공 1명. 왼쪽 아래에서 등을 비스듬히 보여 주며 오른쪽 위 적과 대치한다.
- 습득 무공 중 사전에4개를 편성하고 우측 하단2×2 슬롯으로 표시. 초기에는 삼재검법만 있으며 나머지3칸은 빈칸.
- 슬롯을 클릭하면 즉시 공격하지 않고 왼쪽에 설명을 표시한다. 구체적인 무공 효과는 사용자가 추후 설정한다.
- 별도 ‘사용’ 버튼은 현재 v2 시안의 제안이며 사용자가 명시 확정한 조작은 아니다. 전투 중 편성 변경 여부도 미정.

## 스토리 진행 범위

- 본편 전체 스토리는 보류. 현재 호송선 사건을 0장 프롤로그/튜토리얼로 설정했다.
- 출항 전 준비는 몰입용 공통 진행이며 성과·보상 분기를 추가하지 않는다.
- 흑린채와의 전투가 튜토리얼. 배가 침몰하고 표사 대부분이 수장되어 표국이 자연스럽게 해체된다. 본거지 공격·표국 전원 사망을 추가하지 않는다.
- 핵심 선택 A: 귀물을 지킴 → 수령 대상에게 인도 → 해체된 표국 대신 주인공이 대가를 받아 유리하게 출발하지만 구하지 못한 사람에 대한 죄책감이 남음.
- 핵심 선택 B: 사람을 구함 → 귀물 전달 불가 → 수령 대상에게 표행 실패 사실만 보고 → 해당 대가를 받지 못함.
- 어느 경로든 주인공은 표국 해체 후 무소속으로 자유 플레이를 시작한다. 강제 배상·대체 임무를 추가하지 않는다.
- 귀물의 정체·수령인·표국 이름·구조 인물·보수·이후1장 이야기는 미정이다. 앞서 제안했던 장부 회수 분기는 폐기되었다.

## 비공개 메모 인계

일부 비공개 제작자 메모는 이 저장소 외부에만 보관했다. git clone으로 복원되지 않는다. 별도 제공한 cli-handoff-private.zip을 로컬의 프로젝트 밖 폴더에 풀면 author-notes/에 원문이 있다. 비공개 메모를 공개 저장소에 커밋하지 않는다. 옛 초안에는 현재 폐기/보류된 내용도 있으므로 각 문서의 최신 사용자 수정 사항을 우선한다.

## 이어서 작업할 때

확정 설정과 제안을 구분하고, 아직 미정인 무공 효과·전투 수치를 임의 확정하지 않는다. 다음 실제 구현 작업의 범위와 사용할 기술은 사용자가 요청할 때 정한다. 클라우드 대화 전체가 로컬 CLI로 자동 이전된다고 가정하지 않는다.
