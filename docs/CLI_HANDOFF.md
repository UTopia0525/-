# CLI 작업 인계

기준: 2026-10-26 현재 구현. 새 작업은 이 요약과 [작업 색인](README.md)에서 시작한다. 게임 수정 시 [콘텐츠 작업 규칙](../godot/AGENTS.md)을 따른다.

## 검토 중인 시안

- **남경 이야기 초안:** [쌀자루에 찍힌 이름](story/nanjing-outline.md): 사용자 지정으로 육소전 단독 의뢰→연서의 경계/무림맹 공적 확인→공동 조사→진범 체포·남궁 인계→남궁 보상→연서의 의문·육소전 부재로 수정했다. 결말 선택지는 없고 보상 수치는 미정이다. 아직 게임 미구현이다. 사용자 확정으로 하오문 인물 머리 위에는 소속 없이 이름·겉직업만 표시한다.

- **남경 도시/기본 NPC 시안:** [전체 이미지·12명 배치·하오문/남궁 인물 제안](cities/nanjing-preview.md)을 작성했다. 1390년 수도 응천부의 게임용 압축 도시다. 사용자 요청대로 Godot 맵·포탈·NPC·거래·퀘스트는 구현하지 않았다. 다음 구현 전 시안과 세력 인물 선택을 따른다.

[진행·검사·실제 화면](quests/qingya-village.md).

- **1장 탐사 안내:** 장사에서 토벌 모집 전 우측 목표 창에 ‘주요 목표 · 장사를 탐사하세요’를 표시한다. 선택한 의뢰 안내와 함께 유지하며 토벌 시작/다른 지역에서는 숨긴다. [HUD 규칙](ui/compact-a.md).

- **BGM 반복 유지:** 기존 OGG 반복에 실제 종료/중단 복구를 추가했다. 같은 곡을 같은 플레이어에서 재개하며 이전 곡·음악 끄기 설정을 침범하지 않는다.5곡 실제 경계 반복/EOF와 한 곡 전체 재생, 음소거/메뉴/교차 전환을 검사한다. [규칙·검사](systems/bgm-loop.md).


- **산길 단축·보행:** 산길 월드를4096×5120→2560×3200으로 줄여 경로 기준 약19.9→12.5초로 단축했다. 원본 미술/포탈/의뢰 배치는 같은 도안 좌표를 쓰며 이전 저장1/2를 새3의 좌표로 변환한다. 가로 이동은 동일한 몸체 위의 교차 발 동작으로 보완하고 정지/걷기 그림 비율 차이를 제거했다. [구현·실측·동작 GIF](systems/short-road-and-stride.md).


- **작은 A안 HUD·시야·통행:** 먹빛/금선 A안을 실제 적용했다. 미니맵188×174, 추적 의뢰1개, 하단38px 단축키 바이며 도시/산길 카메라0.8로 가로·세로25% 더 보인다. 장사 출발은 토벌 완료+보수 지급 이후다. 장부/물길 의뢰를 각50문 올려 장사9종 총1,250문으로 맞췄고, 이전 완료 저장은 차액을 한 번 보정한다. [실제 화면·조건·검증](ui/compact-a.md).


- **전역 의뢰·표식·경제/적 조정:** Q에서 두 도시의 수락 가능/진행/완료 의뢰를 함께 보고 추적을 선택한다. 다른 의뢰의 진도 변경은 선택한 추적을 덮어쓰지 않으며 지역 밖 출구 안내와 저장을 지원한다. 두 도시 머리 위 의뢰 표식은2배, 전체 지도/미니맵에는 수락 가능 !·보고 ?·목표 ◆를 표시한다. 장사 장인은300문 검/도/창3종만 판매하며 무창과 영약상은 유지한다. 오성5 보상11종을2로 변경해 총+22다. 기존 완료 보상은 소급 감산하지 않는다. 모든 적은 기존 수치/무기를 유지하며 하급 쇄목도법(내기12)과 전용 아이콘을 추가했다. ## 유지할 설정

일반 의뢰는 모든 도시에서 별도로 확정한 선행·배타 조건이 없으면 동시 수락/진행/완료를 기본으로 한다. 의뢰마다 동시 진행 여부를 다시 묻지 않으며 진행·보상·저장 상태를 분리한다. Q 목표 추적 변경은 다른 의뢰를 중단하지 않는다. 공유 NPC의 완료 잡담이 다른 의뢰를 가로막지 않게 한다. [공통 의뢰 원칙](quests/quest-flow.md).

스탯은 근력·기민·근골·내공·오성 각0~100. 경지 합계 기준은100/200/300/400/500이다. 매 전투 체력300·내기=내공으로 시작하고 내기 상한500, 다음 턴부터 내공만큼 회복한다. 개별 무공·장비 수치는 `godot/data/`와 해당 기능 문서를 확인한다.

창법은 상급까지 높은 고정 위력·낮은 성장 계수를 중심으로 설계한다. 미정인 콘텐츠·가격·효과·네임드 전투 스탯을 임의 확정하지 않는다. 비공개 제작자 메모는 저장소 밖에 보관하며 Git으로 복원되지 않는다.
