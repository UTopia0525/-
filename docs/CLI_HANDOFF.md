# CLI 작업 인계

최신 미술: [남경 전역 시장 화풍 확장](cities/nanjing-capital.md). 시장 원본을 참조한 신규 아틀라스2장으로 공방/상가/관아/무관/객잔/수변 누각을 교체하고 물가 누각2동을 추가했다. 작은 부지는 저층 외형으로 맞추며 큰 상가는 기존4동의 부지를 합쳤다. 도시 바닥도 시장 재질로 통일하고 연속 황성 외벽/다리/기존 도원은 유지한다. 수변 주민1명 위치 조정, 비단 의뢰 조사대상 `capital_2`를 새 점포 앞에 보존했다. 기존 시장 파일럿의 ‘확대 대기’는 이번 사용자 승인으로 해제됐다.

최신 미술 작업은 [남경 시장·골목 파일럿](cities/nanjing-market-slice.md)이다. 전용 점포4종·시장 재질/문턱/그림자를 실제 게임에 적용하고 중앙 중복 진열6개를 제거했다. 약재상/행인2명만 길 가장자리로 조정했으며 기존 도원·대화/의뢰/도시 좌표계는 유지한다. 같은 카메라의720p/1440p 전후와 앞모습을 보관했다. 현재 도원은 새 구역과 조화되어 전면 재제작을 권하지 않는다. **남경 다른 구역으로 확대는 화면 검토 후**다.

최신 [이동·방어·복수 무공 비교](reviews/mixed-actions-merit.md)는 무기 우열 대신 같은 판단기에서 선택지를 하나씩 제한해3,108회 검사했다. 최소량50/100 성장식과 초반 실제 상한50, 예측 길이20/40/60, 사용 불가를 제거한 비용70% 대조를 비교했다. 최소량100의 대표 자세 추정72조건에서 이동 이득29/방어11/두 무공29, 모두의 실제 사용과 개별 이득을 동시에 만족한 경우는1이다. 상한만으로 전술 다양성을 확보했다고 판정하지 않는다. 현재 비용을 유지한다면 다음 최소량은100을 추천하되 방어·무공 역할 수정은 미검증 제안이며 **본게임·무공 데이터·저장은 미변경**이다. [실제 시간순 기록/반례](../prototypes/mixed-actions-review/index.html)와 원자료·재현 명령을 보존했다.

최신 [전 구간 무공·내기 성장 검토](reviews/progression-combat-budget.md)는 `최대 내기=max(80,40+내공×2)`를 기준 후보로 내공200까지 계산했다. 중급7종의 비용/시간·위력 재편안과 임시 상급5종/절초2종,41,058회 전투/6,624행 산술표·계산기·기록29개를 추가했다. 기존 계수 유지안도 대조했으며 무기별 최종 전술 균형을 통과한 것은 아니다. **본게임·실제 카탈로그·저장은 미변경**이다. 아래 [고정 상한70~80 검토](reviews/timed-qi-budget.md)는 장사 구간의 이전 실험이며 전체 게임의 고정 상한으로 채택하지 않는다.

2026-10-30 사용자 요청으로3D 개발은 보류한다. 기존2D 전투 개편은 **검토 단계**다. [장사 우두머리 시간제 전투 검토](reviews/timed-combat-changsha.md)에 별도 계산8,316시행·실패/교착 포함 전체 결과·오프라인 기록 재생기를 추가했다. 이동3/5/2와 기존 무공의 제안 시간표를 사용했지만 본게임 전투·수치·저장은 변경하지 않았다. 클리어 가능성은 확인했으나 주력 반복이 남았고, 사람의 재미 향상을 검증한 결과는 아니다.

## 유지할 설정

일반 의뢰는 모든 도시에서 별도로 확정한 선행·배타 조건이 없으면 동시 수락/진행/완료를 기본으로 한다. 의뢰마다 동시 진행 여부를 다시 묻지 않으며 진행·보상·저장 상태를 분리한다. Q 목표 추적 변경은 다른 의뢰를 중단하지 않는다. 공유 NPC의 완료 잡담이 다른 의뢰를 가로막지 않게 한다. [공통 의뢰 원칙](quests/quest-flow.md).

스탯은 근력·기민·근골·내공·오성 각0~200. 경지는 위 상한 변경 절의 새 구간을 표시하며 기존 퀘스트 진입 조건은 이류 달성(총합101 이상)으로 변경했다. 매 전투 체력300·내기=내공으로 시작하고 내기 상한500, 다음 턴부터 내공만큼 회복한다. 개별 무공·장비 수치는 `godot/data/`와 해당 기능 문서를 확인한다.

창법은 상급까지 높은 고정 위력·낮은 성장 계수를 중심으로 설계한다. 미정인 콘텐츠·가격·효과·네임드 전투 스탯을 임의 확정하지 않는다. 비공개 제작자 메모는 저장소 밖에 보관하며 Git으로 복원되지 않는다.
