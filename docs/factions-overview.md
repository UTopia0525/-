# 구파일방·오대세가 통합 설정집

현재 문서 기준으로 15개 세력, 주요 인물 36명의 1차 설정과 초상화가 준비되어 있다. 세력은 오대세가 5개와 구파일방(구파 9개·개방 1개) 10개다. 사용자 지정 설정과 인물의 이름·나이·개인사 등 창작 초안을 구분하며, 세부 내용은 각 문서의 최신 수정안을 따른다. 역사 지도는 1390년경을 기준으로 하되 실제 역사와 무협 창작은 구분한다.

## 인물 관계와 최신 결정

- 현진은 근엄한 외형을 사용한다. 추후 정파제일인 설정 가능성은 있지만 현재 미확정이다.
- 운허의 별호는 무당검선이다. 장삼봉은 게임 내 무당 개조 전승에 포함하되 현재 생존·소재와 운허와의 직접 사제 관계는 미정이다.
- 화산 진목은 전통, 소운은 자유로운 응용을 중시한다. 자하심공은 장문인만 배우며 소운에게 배정하지 않는다.
- 종남 담진은 행실이 바르지만 자만심이 강하고 사문을 모욕당하면 격앙된다.
- 아미 묘은은 어릴 때 버려져 아미에서 자랐고 문파와 장문인에 대한 애정이 깊다. 정연은 부드러운 두건과 온화하고 가는 얼굴선을 사용하는 최신 초상화를 따른다. 사태는 비구니 존칭이며 수장 직책은 장문인이다.
- 청성 통현은 현실적 타협, 지온은 공정한 원칙을 중시한다. 회풍보·청명심공은 미채택이다.
- 공동은 칠상권·진악권을 채택하지 않는다. 실전적 검술과 짙은 살기가 일상적인 잔혹함을 뜻하지는 않는다.
- 곤륜 연하는 중원을 유람한 뒤 돌아오고 싶어 하며 도겸은 반대한다. 운룡십팔식을 검법으로 분류하지 않는다.
- 점창 윤서는 자신감 부족을 피하는 시선과 긴장한 자세로 표현한다. 무능함으로 단정하지 않는다.
- 개방 장로는 8결개이며 소칠은 방주 직전제자가 아니므로 항룡십팔장을 배우지 않는다. 6결이라고 분타주 취임을 확정하지 않는다. 방주는 앉은 자세와 봉을 유지하되 배경은 제거했다.

## 제작 공통 원칙과 미정 사항

- 탐험은 도트 기반 2D 탑다운, 전투는 플레이어 캐릭터 1명의 별도 화면 턴제다.
- 전투 스탯은 전투 시스템 설계 후 일괄 부여한다. 기존 남궁 임시 수치는 폐기했다.
- 초상화는 개성 있는 얼굴을 기본으로 하고 사용자 지정 미형과 복원 선택을 우선한다. 남궁서진·남궁연서·제갈설하는 원본을 유지하고 당서령은 미형으로 제작했다.
- 인물 이름·나이·법명·개인사와 창작 무공의 세부 원리는 수정 가능한 초안이다.
- 전체 이야기, 퀘스트, 무림맹 운영 구조, 마교·사파의 구체적 조직, 무공의 수치·전투 연출은 아직 별도 설계가 필요하다.
- 이 공개 요약에는 제작자용 비밀 사건 설정을 포함하지 않는다.
- 사용자 지정에 따라 무공의 정식 명칭은 **이십사수매화검법·항룡십팔장**으로 통일했다.
