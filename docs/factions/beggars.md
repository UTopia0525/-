# 개방

## 사용자 채택 설정

- 기존 지도대로 개봉 외곽에 총타를 두고 전국 주요 도시·나루에 분타를 둔다.
- 정파에 속하며 격식보다 정보력과 강호의 의리로 존중받는 방회다.
- 의리·상부상조·약자 보호·은혜에 대한 보답을 중시한다.
- 낡은 회갈색·누런색 옷, 수선 자국과 매듭을 사용한다. 가난을 일괄적인 더러움·우스꽝스러움으로 표현하지 않는다.
- 대표 무기는 봉과 맨손이며 생활 속 움직임과 실전 경험을 바탕으로 제압한다.
- 방주·장로·분타주·방도로 구성하고 **결개**, 곧 매듭 수로 계급을 표시하는 설정을 사용한다.
- **방주 9결개, 장로 8결개**. 방회의 수장 직책은 ‘방주’로 통일하며 사용자가 말한 장문은 이 직책에 해당한다.
- **향룡십팔장은 방주와 방주의 직전제자만 익힌다.** ‘직전제자’는 방주에게 직접 전수받는 제자다. 그 수나 후계자 지위는 미정이다.
- **타구봉법은 개방 일반 방도도 대중적으로 배울 수 있다.** 방주 전용 무공으로 제한하지 않는다. 개방 외부인까지 자동으로 전수하는 것은 아니다.
- 격식을 덜 따르고 말투가 거칠며 출신보다 행동과 의리를 중시한다.
- 장터·나루·골목의 소식을 연결하고 교차 확인한다. 모든 일을 즉시 아는 정보망은 아니다.
- 굶주린 이를 돕고 실종·착취·갈취 문제에 관여한다.
- 자기 방도를 돕는 일과 강호 전체의 대의를 위해 위험을 감수하는 일 사이에 갈등이 있다.
- 느슨한 조직 때문에 정보가 왜곡되거나 일부 분타가 지역 권력과 결탁할 수 있다. 구체적 부패 사건은 미정이다.
- 벽에 기대 앉고 긴 봉을 지닌 자유로운 분위기의 방주, 젊고 유능한 방도를 제작한다. 전투 스탯은 없다.

실제 명대의 빈곤·구휼 조직 전체를 개방과 동일시하지 않는다. 무공 이름 ‘향룡십팔장’은 사용자의 최신 표기를 따른다. 앞선 후보 표기 ‘항룡십팔장’과 별개의 두 무공으로 만들지 않는다.

## 결개 계급

방주 9결개·장로 8결개와 이소칠 6결개는 사용자 확정이다. 아래 하위 분류는 인물 제작을 위한 창작 초안이며 확정 규칙으로 강제하지 않는다.

| 결수 | 지위·운용 초안 |
|---|---|
| 9결 | 방주 — 확정 |
| 8결 | 장로 — 확정 |
| 7결 | 총타·광역 실무 책임 방도 — 제안 |
| 6결 | 숙련 방도·분타 실무 책임급 — 직책은 별도 지정. 이소칠의 6결개는 사용자 확정 |
| 1~5결 | 경력·공로·책임에 따라 승결하는 일반 방도 — 제안 |

매듭은 옷이나 띠에 부착한 계급끈의 개별 매듭으로 표시한다. 매듭이 실력·인품의 숫자 점수인 것은 아니다. 무공을 익혔다는 이유만으로 자동 승결하지 않는다. 무결 입문자 제도·승결 절차·장로와 분타주의 겸직 규칙은 미정이다.

## 무학

### 향룡십팔장

강맹한 장력을 강조하는 비전 장법. 방주와 직전제자 외에는 전수하지 않는다. 구체적인 초식·용 형상의 연출·원거리 공격은 미정이다. 직전제자가 아닌 젊은 방도에게 몰래 배정하지 않는다.

### 타구봉법

상대의 무기와 발디딤을 견제하고 간격을 통제하는 실용 봉법으로 각색한다. 개방 안에서 널리 가르치며 습득 가능성과 숙련 수준은 구별한다. 대중적으로 배운다고 방주와 초보 방도의 기량이 같은 것은 아니다.

추가 기초 무공 이름은 이번에 만들지 않는다. 피해량·내공·상태 효과·턴 처리 등은 전투 시스템 설계 이후 결정한다.
