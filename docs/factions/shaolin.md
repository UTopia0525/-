# 소림

## 사용자 채택 기본 설정

- 하남 숭산 소실산의 소림사를 본산으로 한다. 기존 지도 위치 유지.
- 구파일방의 중심이며 정파의 도덕적 권위와 분쟁 중재를 담당하는 문파다. 다른 문파 전체를 지휘할 법적 권한을 뜻하지는 않는다.
- 자비·절제·수행을 중시하고 살생을 경계한다. 무공은 자기 절제와 보호의 수단이다.
- 회색·황토색 승복을 기본으로 하며 고승은 가사를 걸친다. 삭발·염주·수행의 흔적은 공통점이지만 얼굴과 체격은 다양하다.
- 권장법과 봉을 중심으로 기초·내공·단련을 중시한다.
- 방장·장로·전각 책임자가 역할을 나누며 출가승과 속가제자가 있다. 구체적인 전각 명칭·계율·전수 범위는 추후 정한다.
- 구휼·피난민 보호·치료·중재로 민초의 신망을 얻는다.
- 남궁세가와 함께 정파를 지탱하지만 가문의 명예보다 자비와 명분을 우선할 수 있다.
- 자비·교화와 계율·질서 사이의 내부 논쟁이 있다. 전통과 명성을 지키느라 판단이 늦거나 규율을 개인의 사정보다 앞세우는 것이 약점이다.
- 방장·계율 담당 장로·젊은 제자·태상방장을 제작한다.

실제 사찰과 불교의 역사를 그대로 재현하는 것이 아닌 명초 배경 무협 창작 설정이다. 종교적 경지·외모·고령이 전투력 순위를 자동 결정하지 않는다. 전투 스탯은 전투 시스템 설계 이후 부여한다.

## 채택 무학 목록 및 운용 제안

- 나한권: 기초와 몸의 균형을 중시하는 권법.
- 대력금강장: 안정된 자세와 묵직한 장력을 중시하는 장법.
- 금강지: 정밀한 손가락 운용을 사용하는 지법.
- 나한봉법: 거리 조절과 제압 중심의 봉법. ‘소림봉법’은 여기서 봉술의 일반 명칭으로 사용한다.
- 역근경: 게임 안에서는 내공 수련 체계로 각색한다.
- 금종조: 신체 단련 계열. 무적·무조건적 피해 무효를 전제하지 않는다.
- 나한진: 여러 제자가 협력하는 진법. 플레이어는 기존대로 1인이며, NPC 진법의 전투 구현은 미정이다.
- 칠십이절예: 소림 무학의 총칭으로 채택한다. 지금 72개를 모두 정의하지 않으며 위 무공과의 분류·관계·전수 규칙은 추후 정한다.

명칭과 기본 방향을 채택한 것이며 수치·초식·확정 서열은 없다. 문헌의 종교적 의미와 게임의 무공 효과를 동일시하지 않는다.

## 조직과 인물 — 창작 제안

- 현직 방장이 문파의 최종 행정 책임을 맡는다.
- 계율 담당 장로는 조사·징계 절차를 책임지되 방장과 별개로 문파를 장악하지 않는다.
- 태상방장은 전임 방장에게 부여한 게임 내 명예적 호칭이다. 일선에서 물러나 조언하며 현직 방장을 자동으로 지휘하지 않는다. 실제 사찰의 보편적 직제라는 뜻은 아니다.
- 사파 대응은 내부 의견 대립형을 선택한 초안이다. 방장은 교화를, 계율 담당 장로는 우선 제압과 질서를 강조한다. 양쪽 모두 민초 보호와 자비라는 목표를 가진다.
- 법명 세대는 게임용 현–법–혜 순서로 제안한다. 실제 소림의 특정 시대 법맥·항렬을 고증한 것이 아니다.
