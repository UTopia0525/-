# 비단 한 필의 값 — 남경 일반 의뢰

사용자 채택한 첫 주민 의뢰를 구현했다. 선행 조건·전투·필수 지출 없이 유소란에게 F로 선택 수락한다. 다른 모든 일반 의뢰와 동시에 진행할 수 있고, 진행 중인 다른 추적 목표를 덮어쓰지 않는다.

| 단계 | 대상/위치 | 진행 조건 |
| --- | --- | --- |
| 수락 | 시장의 유소란 | 수락/보류 선택, 견본을 보여 주며 자비 구매 금지 안내 |
| 시장 조사 | 기존 비단 노점 | 큰 주문표와 한 필 단위 판매 안내 조사 |
| 소식 | 나루 입구 정소복 | 주씨 아주머니의 자투리 비단을 소개 |
| 허락 | 주거 골목 주씨 아주머니 | 견본을 보고 상자 조사 허락; 마지막 대사 후 승인 |
| 상자 | 주거구역 집 사이 천 상자 | 허락 이후에만 남색 자투리 비단 확보 |
| 전달 | 유소란 | 짙은 비단을 소매/옷단에 함께 두르는 수정안 제안 |
| 회답 | 짧은 ‘잠시 뒤’ 표시 후 자동 대화 | 손님의 동의와 감사, 마지막 대사 뒤150문 지급 |

노점·천 상자는 F 조사 지점이다. 천 상자는 전용 그림·독립 충돌·Y정렬을 사용하며 허락 전 조사해도 물건을 얻지 않는다. 조사와 대화는 마지막 줄을 넘겼을 때만 단계를 갱신한다. 상자는 반복 수거할 수 없다.

견본·자투리 비단은 전용 이미지가 있는 의뢰 상태 물품이다. **Q 의뢰 일지의 상세 화면**에서 확인하며 일반 I 소지품·거래 품목에 추가하지 않아 판매/소비할 수 없다. 전달/완료 후 일지 물품도 정리한다. 기존 소지품과 금전을 지출하지 않는다. 보상은 **150문만**, 오성·명성·세력 호의도 추가 없음이다. 지급 후 재대화·저장 복원으로 보상을 반복할 수 없다.

머리 위 !→수행 중 제거→보고 ?→완료 후 제거, 조사 대상◆, 미니맵/전체 지도·Q 추적을 지원한다. 다른 지역에서는 남경 방향 포탈로 안내한다. 의뢰 종료 후 유소란·주씨 아주머니·정소복에게 관계가 달라진 후일담을 들을 수 있다. 새 NPC/초상화는 추가하지 않았다.

저장 필드는 `silk_quest.phase`이며 기존 저장에 필드가 없으면 미수락으로 읽는다. 대화/시간 전환 중 저장은 차단한다. 시간 전환 중 새 게임/불러오기를 하면 이전 예약 대화가 새 진행에서 재생되지 않도록 취소한다.
