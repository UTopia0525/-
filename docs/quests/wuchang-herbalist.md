# 돌아오지 않는 약초꾼 — 구현

**현재 패배 규칙(2026-10-28):** 사용자 변경으로 이 전투는 패배 시 사망 화면을 표시한 뒤 확인하면 타이틀로 돌아간다. 아래의 과거 후퇴/재도전·비살상 설명과 검사는 이 변경으로 대체된다. 이전 저장 파일은 삭제하거나 덮어쓰지 않는다.

무창 약재상 유백초의 독립 일반 의뢰. 무림맹 방문/중급 무공 전수/다른 의뢰를 선행 조건으로 요구하지 않는다. 사용자 확정 보상은 **완료 보고 후200문만**이다. 오성·기타 능력치·명성·아이템은 지급하지 않는다. 장사 밖 일반 의뢰에 오성을 자동 부여하지 않는 원칙을 따른다.

## 플레이

F5 본게임 → 무창 상점가 유백초의 노란 ! 앞에서F → ‘약초꾼 이야기’ → 대화를 듣고 직접 수락. 같은 첫 메뉴에서 ‘약재를 살펴본다’를 선택하면 기존100문 영약 거래를 그대로 이용할 수 있다. 의뢰를 보류하거나 진행 중이어도 거래를 막지 않는다.

1. 무창 남쪽 농촌 끝의 푸른 포탈에서F로 기존 산길에 진입한다. Q 의뢰 일지/미니맵은 현재 지도에서 필요한 출구를 안내한다.
2. 산길 북부 첫 굽이, 배치 좌표(700,195) 부근의 떨어진 약초 꾸러미를F로 조사한다. 인벤토리 수집 아이템이 아닌 월드 조사 사물이다. 완료 전에는 약초꾼도 구칠도 어떤 지도/몸체/상호작용 목록에도 생성하지 않는다.
3. **마지막 조사 대사를 끝낸 콜백에서만** 단계가search→rescue로 바뀐다. 다음 굽이(760,325) 양옆에 임소평(740,325), 구칠(780,325)을 배치한다. 실제 위치는 공통 전신/발 충돌 회피로 안전하게 보정한다. 두 사람 중 누구에게F를 눌러도 같은 대치 대화→1대1 전투로 이어진다.
4. 승리 후 구칠은 목숨을 구걸하고 돈을 반환한 뒤 퇴장한다. 임소평에게 귀환을 권하는 후속 대화를 끝내면 산길 인물은 모두 사라지고report 대기(ready)가 된다. 느린 동행/호위 조작은 없다.
5. 유백초의 표식이?로 바뀌고 임소평이 약재 노점 곁에 임시 등장한다. 그에게 말을 걸면 유백초에게 보고하도록 안내하며 임의로 완료하지 않는다.
6. 유백초→‘약초꾼 이야기’로 치료/꾸중 대화를 끝내면200문을 한 번 지급한다. 완료 후?와 임시 약초꾼을 제거하고 유백초의 달라진 안부 대사를 남긴다.

임소평29세, 약초와 산길에는 밝지만 무공을 모르며 어머니 약값 때문에 벌이를 놓지 못한다. 구칠은 특정 산채 소속 없이 혼자 다니는 행상/약초꾼을 노리는 불한당이다. 전용 새 초상화 없이 기본18장 중male_young / male_common_a를 각각 사용하며 주인공·유백초와 같은 대화에서 그림을 중복하지 않는다. 산길에서도 대화 배경을 감광하고 알림이 대사 영역을 가리지 않도록 위로 옮긴다.

## 전투와 실패

|항목|구칠|
|---|---|
|체력|320|
|근력 / 기민 / 근골 / 내공 / 오성|18 / 14 / 18 / 12 / 10|
|합계 / 경지|72 / 절정 미만|
|무기|후배도|
|행동|기본공격·기본방어·거친 도질·내려찍기|
|내기|시작12·매 교전 후12 회복·최대500|

승인한 수치를 그대로 사용한다. 공통combat_actions/inner_qi 계산과 기존 전투 모션/효과음/피해 표시를 재사용한다. 적 예고는 공격/수세의 큰 기세만 알려 주고 구체 기술·비용·위력을 공개하지 않는다. 전투 도중 추가 보상을 지급하지 않는다.

패배하면 약초 꾸러미 부근으로 물러나며, 조사를 다시 요구하지 않는다. 약초꾼 사망/시간제한/벌금 없이I/K에서 정비하고 두 사람에게F로 재도전할 수 있다. 새 교전은 체력300·내기=내공으로 시작한다. 교전 결산에도 이 의뢰에 맞는 재도전 안내를 표시한다.

난이도 검증: 초급 공격 무공10종 각각의 최소 학습 능력치에 오성으로 합계100을 맞춘 분배, 균형20 분배, 해당 계열 기본 무기/맨손으로 총20가지 결정론적 전투를 검사했다. 내기가 허락하는 무공/삼재검법을 사용하고 부족하면 기본공격하는 단순 운용에서20/20 승리,2~9교전·잔여 체력30~271이었다. 특정 최소 분배는 여유가 적으며 모든 능력치 분배/무공 편성의 무조건 승리를 보장하지 않는다. 중급 무공이나 고가 장비를 강제하지 않는다.

## 상태와 저장

`herbalist_quest.phase`: available / search / rescue / ready / completed. 수락/조사 완료/구출 완료/완료 보고 끝에서만 전이한다. 대화·거래·전투 중 새 저장 금지는 유지한다. 기존schema1~3 저장에서 새 필드가 없으면available로 시작한다. 지역 이동/재접속/저장 불러오기 시 이 단계로만 조사 사물·사건 인물·노란 표식·목표를 재구성하므로 조사를 건너뛰거나 보상을 중복 지급하지 않는다.

Q 일지는 수락 가능/진행 중/완료와200문 보수를 표시한다. 추적은 무창/산길/장사/총무당에서 각각 필요한 출구 또는 실제 목적지를 가리키며, 조사를 마치기 전에는 약초꾼 좌표를 안내하지 않는다. 장사 일반 의뢰와 상태/보상은 분리한다.

## 소스와 검증

- `godot/data/wuchang_herbalist_quest.json`: 확정 대사 원고, 조사/사건 기준점, 적,200문 보상.
- `godot/scripts/herbalist_quest.gd`: 진행/등장/거래 선택/전투 복귀/완료/저장/지도 안내.
- `godot/scripts/herb_bundle.gd`: 도트 형식의 약초 꾸러미 조사 사물.
- `godot/tests/herbalist_quest.gd`: 실제F 수락·보류·약재 거래·조사 마지막 줄 전까지 미등장·직행 우회 방지·전신 충돌·패배/재도전·귀환 보고·200문 단일 지급/능력치 불변·단계별 저장/구버전 호환·20전투.
- 회귀: wuchang_residents, overland_travel, quest_navigation, adventure_features, saves, save_restrictions, bandit_story. 실제 플레이와 다른XDG 사용자 경로에서 실행한다.
- `godot/tests/capture_herbalist_quest.gd`: 실제Godot 렌더러로 단계별 캡처. 화면 구성 재현용으로 전투 승리 교전에서 적 체력을1로 낮추며 난이도 검증은 위 별도 공통 계산 검사로 진행한다.
