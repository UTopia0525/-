# 남경 의뢰 — 쌀자루에 찍힌 이름

2026-10-26 구현. [이야기 흐름](../story/nanjing-outline.md)을 바탕으로 육소전 단독 수락, 연서와 공동 조사, 범인 인계, 남궁 보상과 육소전의 부재를 연결했다. 실행 프로젝트는 `godot/project.godot`이다. 별도 배포 데모는 만들지 않았다.

## 찾아가는 법과 선행 조건

무창 동쪽 포탈 → 삼거리 산촌 → 동쪽의 **남경** 포탈 → 남경 객잔 앞 **육소전 · 점소이**에게 F.

남경 자체는 전수 전에도 들어갈 수 있지만, 의뢰는 **무림맹 본단에서 곽진석에게 중급 무공 한 문을 실제로 전수받은 이후**에만 수락할 수 있다. 무공 보유만으로는 열리지 않으며 무림맹 방문 이야기의 완료 기록도 확인한다. 전수 전 육소전은 일상 대화만 하며 느낌표·수락 창·일지 수락 가능 목록에는 의뢰가 나타나지 않는다. 청애채 사건의 수락/결말과는 무관하다.

## 실제 진행

| 단계 | F 대상 | 끝까지 읽으면 일어나는 일 |
| --- | --- | --- |
| 수락 | 객잔 육소전 | 최근 구휼 이상과 초엿새 밤의 불출이라는 단서를 듣고 수락/보류 |
| 주민 | 진회하 남쪽 위씨 할머니 | 받지 못했는데 수령 기록이 있다는 증언 |
| 협력 | 창고거리 남궁연서 | 외부인 경계 → 도원 이름과 송지겸 보고 확인 → 협조 요청 |
| 기록 | 창고 서리 윤문식 | 허위 확인서·허만식 지장·야간 불출 기록 |
| 접촉 | 수변 접객 담당 진옥란 | 인부 가족의 안전을 확인하고 은신처 안내 |
| 증인 | 남쪽 우물 부근 허만식 | 강요받은 가담과 조덕승 명의 운송 쪽지 확보 |
| 체포 | 북쪽 창고 조덕승 | 도원과 연서가 증거 제시, 퇴로 차단·결박 후 남궁 호송 인원에게 인계 |
| 보고 | 원래 배분처로 돌아온 연서 | 구휼 정상화 확인, **500문·남궁세가 호의도+10** 일회 지급 |
| 의문 | 보고 직후 연서의 연속 대화 | 육소전이 주민들의 배분 실패 전날 밤의 불출을 먼저 알았다는 의문 |
| 부재 | 객잔 주인 하삼랑 | 육소전이 떠나 원래 자리에 없음을 확인하고 의뢰 완료 |

범인 처리의 결말 선택지는 없다. 체포는 증거와 연서의 협력으로 진행하는 **비전투 대화 장면**이며 이번 의뢰에 새 전투/적 수치를 추가하지 않았다. 허만식은 증언 단계 전에는 맵에 나타나지 않는다. 조덕승은 증거 확보 뒤 체포 단계에만 등장한다. 연서는 체포 때 북쪽 창고로 이동하고, 인계 후 원래 배분처로 돌아온다. 남궁도윤은 이번 구현에 별도 배치하지 않았다.

보고 대화가 끝나야 보상이 지급되고, 이어지는 의문 대화까지 끝나야 육소전이 사라진다. 육소전의 후속 행선지·속내·생사와 문주의 정체는 공개하지 않는다. 금전/호의도 외 능력치·명성·무공 보상은 없다. R에서 남궁세가 10/100을 확인할 수 있으며 기존 호의도가 있다면 +10, 상한100이다.

Q 전역 일지에서 다른 의뢰와 함께 진행·추적할 수 있다. 육소전의 수락 가능 !, 연서의 보고 가능 ?, 각 조사 대상 안내를 머리 위·미니맵·전체 지도에 연결했다. 다른 의뢰를 추적 중이면 이 사건의 진행이 선택을 덮어쓰지 않는다. 다른 지역에서는 남경 방향 출구로 안내한다.

## 육소전과 등장 인물

육소전은26세 남성 점소이로, 붙임성 있고 손님들의 사정을 기억하며 동료의 이름을 함부로 팔지 않는다. 공용 청년 남성 `male_young` 초상화와 기존 도트를 사용한다. 기존 제안의 중년처럼 보이는 공용 그림 대신 나이에 맞는 공용 청년 그림을 선정했다. 새 전용 초상화는 만들지 않았다.

진옥란은41세 접객 담당이며 공용 중년 여성 그림을 사용한다. 육소전/진옥란의 이름표에는 하오문 소속·조직 직책·문양이 없다. 연서는 사용자 지정의 기존 원본 초상화를 그대로 복사해 연결했고 전투 수치를 부여하지 않았다.

## 남경 맵

시안 그림을 통째로 배경에 굽지 않고 전용 바닥 그림과 독립 건물·소품·충돌/Y정렬로 구성했다. 월드4608×3072, 서쪽 장강 나루·창고, 중앙 상점가/객잔, 서남 공방, 동쪽 관아/무관, 주거구역과 남쪽 진회하 골목을 구현했다. 시안의 분위기와 구역 구성을 바탕으로 의뢰용 동선을 재배치한 첫 플레이 가능 맵으로, 실측 역사 지도는 아니다.

기본 주민12명과 시설3종(12명에 포함)을 배치했다. 상인·장인·교관은 각각 기존 직업 그림 B/B/A를 재사용하고, 영약·무기·하급 무공 거래를 지원한다. 일반 주민은 기존18장 풀을 재사용한다. 강에는 충돌이 있고 세 다리로 건넌다. 서쪽 푸른 포탈에서 F로 산촌에 왕복한다.

## 저장과 검사

`nanjing_relief_quest.phase`를 기존 schema3 저장에 추가했다. 새 필드가 없는 기존 저장은 의뢰 미수락으로 읽는다. 남경 위치·추적 단계·남궁 호의도와 공개 여부·육소전의 부재를 보존한다. 진행된 의뢰에 전수 완료 기록이 없거나 알 수 없는 단계가 있으면 저장을 거부한다. 대화 중 저장 금지 원칙은 유지한다.

주요 소스: `godot/scripts/nanjing_relief_quest.gd`, `godot/scripts/nanjing_map.gd`, `godot/data/nanjing_{characters,residents,relief_quest}.json`, `godot/assets/maps/nanjing/layout.json`.

`godot/tests/nanjing_relief.gd`는 실제 F 입력으로 수락/보류·전체 조사·범인 인계·일회 보상·부재·단계별 저장 복원·동시 추적·시설 거래·NPC/건물 비겹침을 확인한다. `saves.gd`, `quest_update.gd`, `qingya_quest.gd`, `faction_favor.gd`로 공유 기능의 회귀를 확인했다. 사용자 저장과 분리된 `/tmp` XDG 폴더에서 실행했다. 화면은 `capture_nanjing.gd`로 실제 게임을 렌더링한 것이다.
