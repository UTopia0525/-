# 돌아올 터전 — 남궁세가와 청애채 토벌

2026-10-28 사용자 승인 흐름을 구현했다. 초기 산촌 잠입 구출의 정괴전은 유지하며, 이번에 별도 마운표전을 추가했다. 새 맵은 합비의 남궁세가 본가(4608×3072) 하나다. 남경 북서쪽 푸른 포탈과 F로 왕복한다. 본가 외원·정문·연무장·객사·본당·담장·정원은 기존 독립 프리팹/충돌/Y정렬/가림을 사용한다. 본가는 도시가 아니므로 새 거래 시설은 추가하지 않았다.

## 선행과 진행

모든 조건을 충족해야 정문의 남궁서진에게 !가 뜬다. 조건 이전에는 일상 대화만 한다.

- 산촌 폐허3곳을 조사하고 도원의 후회 대사까지 마침(`regret_seen`).
- 남경 「끊어진 계선줄」 완료.
- 남궁세가 호의도10 이상.

명성/인품/남궁과의 인연은 이 공적을 근거로 대사에서 인정한다. 미정인 추가 명성 수치 조건을 강제하지 않는다.

정문 서진 대화 → 선택 수락 → 본가에서 정비/저장 가능 → 다시 대화하여 출정 선택 → 서진·무사4명과 청애채 진입 → 마운표 앞에서 결전 선택/정비 보류 → 서진 지원을 받아 제압 → 산적 결박·인질 석방·징수 초소 철거 및 산채 해체 확인 → 본가의 서진에게 보고 → 보상 대화 끝에서 지급 → 산촌 재방문·임수전과 대화 → 완료.

일반 무사들은 산채 외곽 제압과 안전 확보를 담당하는 지도상 동료 NPC다. 별도의 잡몹 연전은 추가하지 않았다. 새로운 실제 전투는 마운표1전이다. 마운표는 제압 후 관에 인계하는 전개이며, 맹목적인 방화로 주민들의 물자를 태우지 않도록 서진이 지시한다. 산촌이 빈 정확한 경위를 새 배후 설정으로 확정하지 않는다.

Q 의뢰 일지와 추적·미니맵/전체 지도 목표를 연결했다. 다른 일반 의뢰와 동시 진행 가능하며 추적 대상 변경은 의뢰를 중단하지 않는다. 도중에 다른 지역을 다녀와도 출정/보고/귀환 단계가 유지된다.

## 마운표와 지원

새 조우 ID `qingya_maunpyo`. 초기 감옥지기 `qingya_chief`를 바꾸거나 마운표로 복원하지 않는다.

| 체력 | 근력 | 기민 | 근골 | 내공 | 오성 | 무기·무공 |
|---:|---:|---:|---:|---:|---:|---|
|750|32|24|30|26|25|맨손 · 기존 반석진각공·철산권법|

반석진각공은 근력×5+내공×3, 기존 내기18, 행동력70.1칸 전진 후 전방3칸을 차고1칸 밀친다. 일반적인 공통 피해·내기·행동력·AI/학습·장비 규칙을 따른다. 기존 보존된 반석진각공 아이콘과 초상화를 사용한다.

플레이어는 도원만 조작한다. 서진은 전장 바깥의 지원 인물로 표시하며 추가 조작 유닛/새 체력·행동 게이지는 없다. 초기 지원 방식은 다음과 같다.

- 도원이 적과 맨해튼 거리3 이내에서 숨 고르기 이외의 실제 행동을 마치면, 서진이 고정 위력240의 검 지원 공격을 한다. 접근/방어 중에도 협력하여 근접 무공의 추격 부담을 줄인다. 선택/미실행/범위 밖 실패/원거리 대기에는 지원하지 않는다.
- 지원 피해도 공통 `combat_actions.damage`로 근골·장비·현재 방어를 적용한다. 주공격으로 이미 승리했다면 추가 공격하지 않는다.
- 마운표의 공격 피해 중65%를 서진의 공세 차단으로 줄인다. 도원 자체 방어/장비 계산 후 적용하며, 도원의 자원이나 능력치를 몰래 늘리지 않는다.
- 서진의 흰색·밝은 푸른색 옷/지원 동작, 방어 효과, 별도의 피해 숫자와 실행된 협공 기록을 표시한다. 적의 미래 공격 종류를 예고하지 않는다.

[실제 비교 결과10조건](../reviews/namgung-campaign-balance.json). 기준 스탯 각20/체력300/기본 장비·중급5종을 비교한10조건에서 단독은5패, 지원은5승(잔여 체력120~187)이었다. 이는 검사한 빌드의 결과이며 모든 빌드/선택의 승리를 보장하지 않는다. 서진 지원은 이 조우의 `support` 설정에만 존재하며 기존 전투는 그대로다. 패배는 사망 화면→확인 후 타이틀이며, 현장 재도전이나 자동 보상은 없다.

## 보상과 주민 귀환

본가의 서진에게 보고하는 마지막 대사를 넘겨야 **1,000문과 창천보원단1개**를 한 번 받는다. 토벌 직후 즉시 지급하지 않고, 보고 전에는 기존 폐허 상태를 유지한다.

창천보원단은 사용자가 정한 남궁 비전 영약이다. 전용 그림/안정ID/인벤토리 복용·알림을 연결했다. 복용 시 근력·기민·근골·내공 각각+3, 오성0, 기존 능력치 상한100. 자동 복용하지 않으며 상점 판매·임의의 추가 복용 한도는 없다. 네 하급 영약의 각10회 규칙/판매는 유지한다. 기존4종만 있는 저장은 새 항목의 보유/복용0으로 읽는다.

보고 후 산촌을 다시 찾으면 주민5명이 돌아오고 길과 우물·집터는 유지된다. 일부 집은 수리되었고 불탄 창고와 한 집의 파손·목재 등 재건 흔적은 남긴다. 임수전은 산채 해체 소식을 듣고 돌아왔음을 말하며 도원은 이번에는 돌아온 얼굴까지 확인하고 떠난다. 원래 폐허/후회 조사 기록은 지우지 않으므로 과거 사건과 선행 조건을 보존한다. 마운표와 기존 감옥지기는 이후 산채에서 재생성되지 않는다.

## 저장과 검사

`namgung_campaign.phase`를 저장하며 예전 저장에서 필드가 없으면 미수락이다. 새 지역 위치와 단계를 검증하고 대화·거래·전투 중 저장 금지는 유지한다. 보상 지급은 보고 단계→귀환 단계 전이로 중복을 막는다. 새 항목 보유/복용·능력치·주민/재건 상태는 저장 후에도 유지된다.

`tests/namgung_campaign.gd`는 선행3종 개별 차단/선택 수락/출정 동료4명/보스 접근 길/5단독+5지원 시뮬레이션/실제 지원 전투 승리·사망/HUD·카메라 복귀/단계별 저장·구소지품 호환/중복 보상 방지/영약 복용·오성 불변/주민 귀환을 검사한다. 전체 카탈로그 아이콘을 확인하며 `trading.gd`는 기존4종의40회 복용·거래와 새 격자에서 학습 기술 실행을 검증한다. `grid_combat.gd`/`grid_story_integration.gd`로 기존 전투/저장·사망 연결을 회귀 검사한다. 검사는 독립 XDG 폴더에서 실행한다.
