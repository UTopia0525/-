# 퀘스트 수락·진행·완료 규칙

사용자 확정 기획. 장사 도입 연계와 일반 퀘스트를 구분한다. 0장 종료 후 장사 항구 진입은 구현했다. 0장 직후 포목상 대화와 첫 의뢰 자동 수락·목표 추적은 구현했다. 배달/완료·나머지 의뢰·일반 의뢰 표식은 후속 작업이다.

## 첫 세 개 — 장사 입성 도입 연계

최신 사용자 요청으로 0장 종료 위치는 **장사 항구**다. 항구의 마지막 혼잣말 후 플레이어가 시내로 걸어 들어간다. 기존 동문 바깥 시작 초안은 이 규칙으로 대체한다. 첫 도입 의뢰는 포목상이 먼저 말을 거는 형식이다. 현재 동문 쪽 포목상을 항구 출발 동선과 연결하는 접근 이벤트는 퀘스트 기능 구현 시 조정한다. 기존 포목상 의뢰인의 위치는 이 도입에 맞춰 조정한다.

```text
0장 종료 → 장사 항구에서 조작 재개
  → 일거리를 찾는 혼잣말
  → 플레이어가 항구에서 시내로 이동
  → 포목상이 먼저 말을 거는 도입 대화
  → 맡겨 둔 옷감 자동 수락
  → 의뢰 수행·완료 보고
  → 객잔 점소이와 이어지는 의뢰 대화 → 돌아오지 않은 그릇 자동 수락
  → 의뢰 수행·완료 보고
  → 공방 목수와 이어지는 의뢰 대화 → 농가의 부러진 자루 자동 수락
  → 의뢰 수행·완료 보고 → 도입 연계 종료
```

- 세 의뢰는 각자의 의뢰 대화가 끝날 때 순서대로 자동 수락한다. 한 번에 세 개를 모두 지급하지 않는다.
- 수락·거절·나중에 선택지는 없다. 첫 시작은 성안 진입으로, 후속 단계는 선행 의뢰 완료 후 다음 의뢰인에게 접근하여 이어지는 도입 대화로 시작한다.
- 선행 단계가 끝나기 전에는 다음 도입 의뢰를 수락하지 않는다. 이미 재생한 도입·수락 장면을 접근할 때마다 반복하지 않는다.
- 자동 수락은 자동 완료와 다르다. 물건 전달·회수·보고 등 각 의뢰의 달성 조건과 완료 대화는 그대로 필요하다.
- 후속 의뢰인이 언급되는 것만으로 다음 의뢰가 즉시 수락되지는 않는다. 실제 해당 의뢰인의 대화로 부탁을 듣고 수락 상태가 된다.
- 이동은 플레이어가 한다. 다른 곳으로 순간 이동하거나, 도입 연계 때문에 여섯 일반 퀘스트를 잠그지 않는다.
- 일반 퀘스트의 느낌표를 찾아 수락하는 방식과 구분한다. 이 도입 연계가 나머지 여섯 의뢰나 1장 진입 조건까지 강제로 이어지지는 않는다.

## 일반 퀘스트 — 사용자 지정 명칭

첫 세 개처럼 자동으로 받아지는 의뢰를 제외하고, NPC의 표식을 보고 대화하여 직접 받는 의뢰를 **일반 퀘스트**라고 부른다. 장사의 나머지 여섯 의뢰가 여기에 해당한다.

| 상태 | 의뢰인 머리 위 표식 | 대화와 처리 |
| --- | --- | --- |
| 수락 가능 | 노란색 `!` | 말을 걸면 의뢰 소개. 수락하면 진행 상태로 전환하고, 보류하면 수락 가능 상태 유지. |
| 수락 후 진행 중 | `!` 유지 | 의뢰를 중복 지급하지 않고 해당 의뢰의 진행 중 대사를 재생한다. |
| 달성 조건 충족·완료 보고 대기 | `!`를 노란색 `?`로 변경 | 완료 보고를 받을 NPC에게 말을 걸면 완료 대화를 재생한다. 아직 완료 처리·보상 지급은 하지 않은 상태다. |
| 완료 | 해당 의뢰 표식 제거 | 완료 대화가 끝나면 완료 처리. 이후에는 완료 후 한마디를 재생한다. |

사용자의 ‘달성 조건이 완료되면 느낌표가 물음표로 바뀐다’는 흐름에 맞춰 진행 중에도 느낌표를 유지한다. 수락 여부는 표식만이 아니라 대화·퀘스트 상태로 구분한다.

- 기본 절차: **노란 ! → NPC 대화·수락 → 의뢰 수행 → 노란 ? → NPC 대화·완료**.
- 조건 충족만으로 완료·보상을 자동 처리하지 않는다. 수락과 완료는 각각 한 번만 처리한다.
- 현재 여섯 의뢰의 완료 보고 대상은 의뢰인이다. 전달받는 상대·탐문 상대·낱장 조사 지점 모두에게 `!`나 `?`를 붙이지 않는다.
- 진행 중 대화는 아직 찾지 못했는지, 전달 후 보고만 남았는지 등 실제 상태에 맞춘다.
- NPC가 여러 용건을 가질 경우 완료 보고와 의뢰 소개가 섞이지 않게 구분한다. 상세 UI는 구현 시 정한다.
- 보상은 [장사 의뢰 보상](changsha-rewards.md)의 금액과 오성+5다. 완료 보고 대화가 끝나 완료 처리할 때 한 번 지급한다. 조건 달성이나 수락만으로 지급하지 않는다. 오성 상한100을 유지하며 실제 상승분만 기존 경지 합계에 반영한다.

### 현재 일반 퀘스트 목록

1. 뒤바뀐 바구니
2. 어느 길로 갔더라
3. 표식이 같은 짐
4. 젖기 전에
5. 막힌 물길
6. 오늘도 오지 않는 아들

이 여섯 의뢰에는 서로의 선행 조건이 없다. 「막힌 물길」은 농기구 전달 뒤 자동으로 이어지는 네 번째 의뢰가 아니다.

## 1장 시작 — 최신 사용자 요청

0장 마지막 항구 독백 → 포목상 도입 대화 자동 시작 → 옷감 의뢰 수락 → 중앙 ‘1장’ 한 번 표시 → 조작 재개가 최신 규칙이다. 기존 항구에서 먼저 걸어 들어가 접근 이벤트를 기다리는 초안보다 우선한다. 제목은 미정이다. 포목상은 항구 앞 노점으로 옮겼다. 구현 범위와 저장 호환은 [1장 도입 안내](../story/chapter-01-intro.md)를 따른다.
