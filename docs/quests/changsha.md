# 장사 초기 의뢰 — 채택 설정

2026-10-23 사용자가 제안된 의뢰 중 「울타리 밖의 닭」만 제외하고 나머지 9개를 채택했다. 도입3종은 [거래 안내 연계](trade-intro.md)로 내용을 변경하여 실제 완료·보상까지 연결했다. 나머지 독립6종은 기획 상태다.

장사 첫 탐험에서 시장·객잔·나루·공방·주거지·농촌을 알아가는 짧고 단순한 의뢰들이다. 보상은 [장사 의뢰 보상](changsha-rewards.md)의 100~200문·오성+2 배정안을 따른다. 인물의 고유 이름·1장 진입 조건은 별도 결정 사항이다. 대화 원고 9편은 [장사 의뢰 대화](changsha-dialogues.md)에 작성했으며, 아래 최신 연계 규칙을 따른다.

## 배치·구현 시 지킬 방향

- 기존 생활 주민 일부를 의뢰인으로 구체화한다. 전 주민이 의뢰를 주는 구성으로 만들지 않는다. 시장·객잔에 의뢰인을 조금 더 밀집시키고, 나루·농촌에는 듬성듬성 배치한다.
- 사용자 후속 확정: **「맡겨 둔 옷감 → 돌려준 약사발 → 무관의 새 자루」 세 의뢰만 연계**한다. 0장 마지막 항구 독백 뒤 포목상이 먼저 말을 걸며 첫 의뢰를 자동 수락한다. 후속 두 개도 선행 완료 후 이어지는 해당 NPC의 의뢰 대화가 끝날 때 순서대로 자동 수락한다.
- 나머지 여섯 의뢰(바구니·보따리·표식 짐·장부·물길·안부)는 **일반 퀘스트**다. 처음부터 각각 노란 느낌표 NPC와 대화해 수락한다. 달성 조건이 충족되면 노란 물음표로 바뀌고, 완료 보고 대화를 해야 완료된다. [퀘스트 진행 규칙](quest-flow.md)을 따른다. 특히 「막힌 물길」을 농기구 전달의 후속 의뢰로 연결하지 않는다. 주민 간 관계나 같은 지역을 이용한다는 이유로 추가 선행 조건을 만들지 않는다.
- 보상은 연계100→150→200문, 일반100/150문으로 배정하며 각 의뢰 완료 시 오성+2를 준다. 완료 보고 대화가 끝날 때 한 번 지급하고 오성 상한100을 유지한다. 추가 아이템이나1장 진입 조건은 부여하지 않는다. 상세 내역은 [보상표](changsha-rewards.md)를 따른다.
- 모든 의뢰를 끝내야만 1장으로 넘어갈 수 있다고 확정하지 않는다.
- 의뢰인 초상화는 기존 성별·연령별 엑스트라 공용 일러스트를 활용할 수 있다. 개별 이름·외형과 전용 일러스트를 새로 확정한 것은 아니다.

## 제외

「울타리 밖의 닭」(농가에서 달아난 닭 세 마리를 몰아 울타리로 돌려보내는 의뢰)은 사용자 선택으로 제외한다. 대체 퀘스트는 아직 정하지 않는다.
