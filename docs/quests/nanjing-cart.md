# 한 수레의 무게 — 남경 일반 의뢰2

곽만재에게 F 대화로 선택 수락한다. 선행 조건과 전투는 없으며 「비단 한 필의 값」·구휼 사건·타 지역 의뢰와 동시에 진행할 수 있다.

| 단계 | 대상 | 내용 |
| --- | --- | --- |
| 수락 | 나루 곽만재 | 왕복생의 수리비 공제 우려를 듣고 수락/보류 |
| 증언 | 왕복생 | 납기 압박과 마지막 자루를 실은 경위 |
| 조사 | 창고거리 남쪽 부서진 수레 | 오래된 금·편중 적재를 확인, 차축 조각 확보 |
| 진단 | 장인 유철생 | 기존 손상과 과적이 함께 원인임을 확인 |
| 반출 | 서리 윤문식 | 급히 짐을 보내도록 재촉한 사정 인정 |
| 협의 | 객잔 부근 석문수 | 약속한 납기 수당과 책임을 함께 고려, 품삯 공제 철회 |
| 보고 | 곽만재·왕복생 | 잘못을 없던 일로 하지 않되 책임을 혼자 지우지 않는 마무리 |

보상은 완료 대화 마지막 줄 뒤 **200문 한 번**이다. 수리비나 진단료를 플레이어가 내지 않는다. 오성·기타 능력치·명성·호의도는 올리지 않는다. 곽만재·왕복생·유철생·윤문식·석문수 모두 완료 후 대사가 달라진다. 신규 NPC나 인물 초상화를 추가하지 않았다.

수레는 나루/창고거리의 기존 짐수레 자리를 재사용한다. 미수락/진행 중에는 한쪽에 짐을 몰아 실은 파손 수레, 완료 뒤에는 짐을 덜고 나무 받침을 댄 수리 대기 수레로 바뀐다. 바퀴를 마법처럼 고치지는 않는다. 두 상태의 충돌과 표시 크기는 같아서 전환 시 통행과 NPC 배치가 바뀌지 않는다. 미니맵·전체 지도에도 변경된 수레 그림을 반영한다.

차축 조각의 전용 아이콘과 수레2종 그림을 제작했다. 차축은 의뢰 상태로 보유하며 **Q 일지 상세 화면**에 표시한다. 일반 I 소지품이나 거래에 들어가지 않아 판매/소비할 수 없고 완료 후 정리한다.

장인의 진단과 병장기 거래는 용건 선택으로 모두 접근할 수 있다. 윤문식에게 구휼 사건의 장부 확인과 수레 반출 확인이 겹치면 용건을 고른다. 한 의뢰만 진행되고 다른 진도는 유지하며, 수레 의뢰 완료 잡담은 진행 중인 구휼 대화를 막지 않는다.

단계별 저장과 구 저장 읽기를 지원한다. 새 `cart_quest` 필드가 없는 저장은 미수락으로 읽는다. 모든 조사·증언은 대화가 끝나야 반영한다. 왕복생의 설명 전에 수레를 조사해도 증거를 먼저 얻을 수 없다. 노란 !→보고 ?→완료 후 제거, 수레 조사◆와 전역 Q 추적·지역 밖 포탈 안내를 연결했다.
