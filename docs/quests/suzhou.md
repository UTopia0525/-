# 소주 일반 의뢰 5종

사용자 승인한 생활 의뢰3종과 전투 의뢰2종을 구현했다. 모든 의뢰는 선행/배타 조건 없이 함께 수락·진행·완료할 수 있다. 수락은 실제 NPC와 F 대화 후 선택하며 Q에서는 목표만 추적한다. 완료 보고 대화의 마지막 줄 이후 금전만 한 번 지급한다. 오성·다른 능력치·아이템·명성·호의도를 자동 지급하지 않는다.

|의뢰|의뢰인|주요 흐름|보수·보고 대상|
|---|---|---|---|
|물들지 않은 한 필|하옥주|정소만→곽아성→직접 고백 격려/도원이 먼저 설명→정소만과 분할 납품 결정|200문 · 하옥주|
|낡은 옷의 품삯|임소교|진덕구에게 가위 손질→임소교에게 돌려주고 침구 받기→객잔 전달|150문 · 오향란|
|소문에 붙은 두 배|주경복|장문식에게 규정 확인→노만강에게 전달→공개 정정/장문식의 직접 설명 주선|200문 · 주경복|
|새벽 나루의 자릿세|유채령|장문식에게 허가 확인→남쪽 하역 마당 갈취범 저지→실전 전투→관아 인계|300문 · 장문식|
|손에 맞는 병장기|진덕구|백정수와 힘을 제한한 지도 대련→승리 후 공방 보고|200문 · 진덕구|

다섯 의뢰의 금전 합계는 **1,050문**이다. 주민의 나이·영구 능력치나 기존 무공/무기 계산식을 바꾸지 않았다. 가위·침구 전달은 의뢰 진행 상태로 관리하며 일반 판매품이나 새 장비로 등록하지 않는다.

## 대사와 공유 NPC

곽아성의 대사는 사용자 수정대로 다음과 같다.

> 혼나는 건 견디겠는데…… 이번에도 품삯을 못 보내면 집에서는 제가 잘 못 지내는 줄 알고 걱정할 겁니다.

[전체 대화와 선택지 원고](suzhou-dialogues.md). 두 선택 의뢰의 금전 보수는 어느 방법을 골라도 같다. 선택에 따라 곽아성의 고백/도원의 설명, 주경복의 공개 정정/장문식 방문 주선 장면이 달라지며, 완료 후에는 관련 주민들의 잡담이 바뀐다.

하나의 NPC가 여러 의뢰·거래·잡담에 참여할 때 용건 목록을 표시한다. 진행 중인 다른 의뢰를 중단하지 않고 필요한 대화만 고를 수 있으며 거래도 계속 이용한다. 완료한 의뢰 대사가 다른 의뢰의 진행을 가로막지 않는다. 잡담은 보상이나 수락을 발생시키지 않는다.

- 수락 가능한 의뢰인 `!`, 실제 보고 대상 `?`, 수행 대상은 공통 목표 표시를 사용한다.
- 같은 인물에게 수락과 보고가 함께 있으면 `?`를 우선한다. 미니맵·전체 지도에도 같은 판정이 적용된다.
- 산길/남경 등 다른 지역에서도 진도는 유지되며 소주로 돌아가는 포탈을 안내한다.
- 대화/거래/전투/용건·선택 창은 기존 수동 저장 제한을 유지한다. 탐험 중에는 분기 선택 직전 단계 등 어느 시점도 여러 칸에 저장할 수 있다.

## 전투

### 새벽 나루의 자릿세

장문식에게 불법 징수임을 확인한 후에만 갈취범이 남쪽 하역 마당[1130,925]에 등장한다. 기존 산적 공용 초상화·탐험 도트를 재사용하며 기본 주민14명과 별개의 임시 인물이다. 접근하거나 F로 개입하면 대화 끝에 즉시 전투에 들어가며 정비/중재 선택지를 추가하지 않았다. 붙잡은 뒤 임시 NPC를 제거하고 장문식에게 보고해야 포상금을 받는다.

|전투 설정|값|
|---|---|
|체력|200|
|근력/기민/근골/내공/오성|14 / 12 / 12 / 14 / 20|
|장비·무공|후배도 · 단석도법|
|행동|공통 내기/행동력·이동·기본공격/방어·적응형 AI|
|패배|사망 종료 화면→타이틀. 기존 저장 삭제/덮어쓰기 없음|

전용 소주 운하 나루 전투 배경을 제작해 적용했다.

### 손에 맞는 병장기

기존 장착 무기/편성 무공으로 백정수와 대련한다. 새로운 병장기를 살 필요는 없다. 대련 시작은 선택할 수 있으며, 패배하면 교관이 출수를 거두고 조언한 뒤 재도전 상태로 돌아간다. 승리 전에는 보수 보고가 열리지 않는다.

|전투 설정|값|
|---|---|
|체력|220|
|제한된 근력/기민/근골/내공/오성|12 / 12 / 12 / 14 / 24|
|장비·무공|정련검 · 청풍검법·유수검법|
|패배|비살상, 조언 후 재도전 가능|

이는 **힘을 제한한 시험 조우용 수치**이며 백정수의 영구 설정 능력치를 확정하는 자료가 아니다. 배경은 기존 대나무 연무장 자산을 사용한다.

## 구현·검증

- `data/suzhou_quests.json`: 대화·분기·보상·조우.
- `scripts/suzhou_errand.gd`: 의뢰별 독립 진행, 대화 종료 시 단계 변경, 중복 보상 차단.
- `scripts/suzhou_quests.gd`: 공유 인물의 용건 선택, 완료 잡담, 임시 적과 통합 표식.
- 저장은 `suzhou_quests`의 의뢰별 단계/선택을 기록한다. 필드가 없는 구버전 저장은 모두 수락 가능 상태로 읽으며 알 수 없는 단계/선택·전투 상태 불일치는 거부한다.
- `tests/suzhou_quests.gd`: 실제 F 수락·보류·동시5개 진행·일지/추적·공유NPC/거래·두 선택의 양쪽 분기·보고 전후 보수·총액/중복 지급 방지·실제 승리·대련 패배/재도전·실전 사망·저장/구버전 호환.
- `tests/suzhou_quest_balance.gd`: 모든 능력치20·체력300·무기별 중급 무공1종으로 두 조우를 공통 격자 AI와 계산해10조합 모두 승리 확인. 창이 가장 여유 있고, 짧은 사거리의 반석권법은 대련에서 가장 까다롭다. 모든 편성과 수동 플레이의 승리를 보장하는 검사는 아니다.
- `tests/suzhou_residents.gd`: 새 용건 목록에서 기존 잡담·3종 거래 유지.
- `tests/suzhou_maps.gd`: 도시/산길 왕복과 기존 지형 충돌 유지.
