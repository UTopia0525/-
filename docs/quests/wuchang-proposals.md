# 무창 주민 의뢰 목록 — 약초꾼/장인/대련/객잔/사칭 사건 구현·나머지 후보

「돌아오지 않는 약초꾼」은 사용자가 채택해 [실제 구현](wuchang-herbalist.md)했다. 「장인의 이름값」도 사용자가 채택해 [구현](wuchang-artisan.md)했다. 「세 걸음의 대련」도 [구현](wuchang-duel-proposal.md)했다. 「밥값보다 큰 소리」도 [구현](wuchang-inn.md)했다. 「빌려 쓴 무림맹 이름」도 [구현](wuchang-impostor.md)했다(구현된 무림맹 메인 이야기의 중급 전수 완료 후 활성화). 나머지3개는 사용자가 선택할 후보로, 실제 의뢰/적/보상/아이템을 등록하지 않았다. 주민8인의 기존 직업·성격·관계를 바탕으로 생활 의뢰와 전투 의뢰를 섞는다. 모든 의뢰는 우선 서로 독립적으로 제안하며, 같은 주민이 다른 의뢰에 등장하더라도 선행 연계 조건을 붙이지 않는다. 수치·보상·정확한 적 구성은 채택 후 결정한다.

송지겸은 사용자 확정에 따라 상시 배치 NPC가 아니다. 토벌 후 초대나 정문 신원 보증처럼 사건에 맞춰 등장하고 역할을 마치면 현장에서 사라지는 인물로 다룬다. 아래 주민 의뢰의 상시 의뢰인/완료 대상에 송지겸을 사용하지 않는다.

## 구성 의도

전투 필수3종(약초꾼 구조·대련·사칭범 체포), 선택 전투1종(객잔 시비), 비전투4종으로 섞는다. 사람과 싸우는 의뢰는 승리 후 상대가 죽었다고 자동 서술하지 않고 퇴각·항복·포박 등 사건에 맞는 결말로 제안한다. 모든 의뢰를 또 다른 산적 토벌로 만들지 않는다.

약초꾼 구조는 장사→무창 산길을 재활용할 수 있고, 나머지는 무창의 무관·객잔·나루·공방·주거·농촌/관아 구역에 분산한다. 사건용 엑스트라는 필요할 때 등장시키고 기존 기본 초상화18장을 재사용한다. 정확한 위치와 새 전투 장소는 채택 후 결정한다.

임정산의 대련은 전투 의뢰 입문용으로 먼저 권한다. 약초꾼 구조와 사칭범 체포는 그보다 높은 난이도 후보이며, 실제 적 수치 설정 때 현행 중급 무공5종과 장비 등급으로 검사한다. 모든 의뢰를 무림맹 전수 완료 뒤에만 열어 두는 조건은 아직 정하지 않는다.

구현 시 기존 일반 의뢰 규칙을 사용한다. 가능할 때 노란 !, F 대화로 수락, 조건 달성 후 ?, 완료 보고 끝에서 한 번만 보상을 지급한다. 전투가 있는 의뢰도 사건 해결 뒤 의뢰인에게 보고하는 흐름을 기본으로 한다. 반복 의뢰·새 성장 수치·강제 유료 구매는 제안하지 않는다.

사용자 후속 확정: 장사 밖의 일반 의뢰에는 오성을 기본 보상으로 자동 부여하지 않는다. 약초꾼 의뢰는200문만 지급한다.

장인 의뢰 후속 확정: 수정 문구 ‘의심할 필요가 있소?’를 반영하고 기존 주계복/오덕수와 조사한다. 완료 보고 후150문만 지급한다.

세 번째 「세 걸음의 대련」의 [진행/대사/무공 보상 구상](wuchang-duel-proposal.md)을 정리했다. 사용자가 장소를‘연무장’으로 수정하고 금전 대신 무기 공통 방어/내기 회복 무공을 요청했다. 조식수원공은 사용자 수정에 따라 내공의200% 내기 회복/피해20%감소/사용 후3턴 재사용 불가로 정리했고 전수 대사도 수정했다. 의뢰·연무장 제자·승패 공통 전수·무공 효과·K 편성·대기 턴 표시·아이콘·저장 복원까지 구현했다.
