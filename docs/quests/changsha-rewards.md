# 장사 초기 의뢰 보상

사용자 지정: 금전 보상은100~200을50단위로, 연계 의뢰는 점차 높이고 일반 의뢰는 낮은 보상 위주로 둔다. 각 의뢰 보상으로 오성을 약5 준다. 기존 화폐 단위를 유지해 **문**으로 표시하며 오성 상승량은 **+5**로 통일한다. 아래는 해당 기준에 따른 금액 배정안이다.

| 구분 | 의뢰 | 금전 | 오성 |
|---|---|---:|---:|
| 연계1 | 맡겨 둔 옷감 | 100문 | +5 |
| 연계2 | 돌아오지 않은 그릇 | 150문 | +5 |
| 연계3 | 농가의 부러진 자루 | 200문 | +5 |
| 일반 | 뒤바뀐 바구니 | 100문 | +5 |
| 일반 | 어느 길로 갔더라 | 100문 | +5 |
| 일반 | 표식이 같은 짐 | 150문 | +5 |
| 일반 | 젖기 전에 | 100문 | +5 |
| 일반 | 막힌 물길 | 150문 | +5 |
| 일반 | 오늘도 오지 않는 아들 | 100문 | +5 |
| 합계 | 9개 완료 | **1,150문** | **+45** |

연계는 도시를 점차 넓게 돌아보는 흐름에 맞춰100→150→200문으로 높인다. 일반 의뢰는100문을 기본으로 하되 짐 운반과 여러 지점의 물길 정리는150문으로 배정한다. 일반 의뢰 사이에 새 선행 조건을 만들지 않는다.

## 지급과 성장

- 완료 보고 대화가 끝나 의뢰를 완료 처리할 때 금전과 오성을 한 번 지급한다. 단순 수락이나 목표 조건 달성으로 먼저 지급하지 않는다. 완료 후 잡담·재방문·불러오기로 다시 지급하지 않는다. 추후 구현 시 완료/지급 상태와 실제 소지금·오성을 같은 저장 상태에 보존해야 한다.
- 오성은 영구 기본 스탯 증가이고 상한100을 유지한다. 오성98에서 완료하면100이 되며 초과3을 다른 스탯으로 옮기지 않는다. 실제 상승분은 기존 경지 합계에 포함한다.
- 오성의 성장은 의뢰 경험에 따른 깨달음으로 취급한다. 영약으로 오성을 올릴 수 없다는 규칙은 유지한다.
- 「오늘도 오지 않는 아들」의 두 전달 선택은 같은 보상을 준다. 대화 선택에 보상 차등을 붙이지 않는다.
- 9개를 모두 완료하면1,150문을 벌고 오성은 시작10에서55가 된다. 다른 성장이 없다면 다섯 스탯 합계는50→95다. 이 합계 자체를 메인 스토리 시작 조건으로 지정하지 않는다.
- 연계3개만 완료하면450문·오성+15다. 0장 귀물 보수3,000문은 별도이므로 전부 완료 후 금전 합계는 귀물 경로4,150문, 구조 경로1,150문이다(다른 수입·지출이 없는 경우).

## 구현 범위

`godot/data/changsha_quest_rewards.json`에 보상 데이터를 저장한다. 현재 퀘스트 완료 판정과 플레이어 성장 시스템은 미구현이므로 실제 지급이나 기존 저장 형식 변경은 하지 않았다. 이후 완료 기능에 이 데이터를 연결한다. 장비·영약 가격이나 별도 아이템 보상은 이번에 정하지 않는다.
