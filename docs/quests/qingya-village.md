# 떠나는 자, 남는 자 — 산촌·청애채

무창 동문에서 동쪽 산길로 나가 삼거리 산촌의 임수전에게 **F로 말을 걸어 선택 수락**하는 일반 의뢰다. 무창–남경 사이 산길·산촌1개와 청애채1개, 신규2맵을 본게임에 연결했다. 다른 일반 의뢰와 동시 진행하며 Q에서 추적을 바꿀 수 있다. 지나가기만 하면 수락/전투가 발생하지 않는다.

## 찾아가는 길

- 무창 동문 부근 푸른 포탈 **산촌·청애채 방면 →**에서F.
- 산촌 서쪽: 무창 귀환. 북쪽: 청애채. 동쪽: 남경 방면 표시만 있으며 남경 맵 미구현 안내 후 현 위치에 머문다.
- 산촌 주민4명, 사건 중 방문하는 후육, 청애채 문지기 정괴·채주 마운표·입장 허가 후 보이는 임수의를 배치했다. 기존 [인물 설정과 그림](../characters/qingya-cast.md)을 사용한다.

## 진행

```text
임수전 F → 사정 듣기 → 수락/보류
  → 주민3명 조사 (자유 순서)
  → 방문한 후육과 대면
       ├─ 채주에게 직접 듣겠소 → 청애채 방문
       └─ 그 자루에서 손을 떼시오 → 후육 전투 → 청애채 방문
  → 정괴에게 용건 설명 → 임수의의 사정 듣기 → 마운표 면담
  → 최종 방향 선택 + 재확인
       ├─ 토벌 → 마운표 전투 → 산촌 보고 → 능력치 선택 → 보상
       └─ 현상 유지 → 산촌 보고 → 오성 보상
```

최초 충돌의 대응은 최종 분기를 잠그지 않는다. 전투 패배는 해당 대면 단계로 돌아가 재도전/정비할 수 있으며 보상이나 완료를 지급하지 않는다. 토벌 전투 승리 대사는 산채의 징수 중단과 인질 귀환을 알리되 마운표의 생사를 확정하지 않는다. 미토벌 시에는 인질의 최종 처우를 별도로 확정하지 않는다.

현재 원고는 `godot/data/qingya_quest.json`의 `scenes`다. 주민의 만류, 보호와 수탈의 모순, 두 결말의 후회, 폐허 조사 대사를 게임에서 같은 자료로 사용한다. 마을 피해/보복의 증언은 사실 확인의 한계를 대사에 남기고 폐허의 직접 원인이나 주민들의 행방은 밝히지 않는다.

## 보상과 재방문

| 선택 | 완료 보고 후 보상 | 이후 |
| --- | --- | --- |
| 토벌 |200문 + 근력/기민/근골 중1종+5 |보상 후 산촌을 떠나 다른 맵에 갔다 돌아오면 폐허 |
| 현상 유지 |오성+5만 |마을과 주민 유지, 수탈의 여운 |

능력치 상한100. 토벌 보상은 마지막 보고 대사 이후 선택창에서 고른 순간 **돈·선택한 능력치·완료 상태를 함께 한 번 지급**한다. 선택창을 닫아도 임수전에게 다시 말을 걸어 선택할 수 있다. 선택 전 진행도 저장 가능하며 반복 보고/콜백/재로드로 누적되지 않는다. 다른 능력치·명성·호의도는 바꾸지 않는다.

완료한 토벌 경로는 포탈로 산촌에서 다른 지역으로 나갈 때 `departed`를 기록하고, 산촌 재입장 때 `ruined`로 전환한다. 단순 저장/불러오기는 출발로 세지 않는다. 첫 귀환/보상 직후에는 주민이 남아 있다. 폐허 상태에서는 주민/산적/주민 의뢰 표식을 제거하고 같은 위치의 집·창고를 무너진 자산으로 바꾼다. 우물·삼거리·집터를 유지한다.

재입장 독백 → 불탄 창고/빈집/임수전을 만났던 자리3곳 F 조사(자유 순서) → 마지막 후회 독백으로 이어진다. 추가 보상은 없고 조사 완료/후회 재생 여부도 저장한다.

## 맵·전투 구현

- 두 맵1536×1024 도안 /4608×3072 월드. 이동/카메라/크기/F/전체 지도/미니맵/I/K/Q/R/설정은 공통 시스템을 사용한다.
- 바닥2장과 투명 구조물 아틀라스를 이미지 도구로 생성했다. 개별 건물·목책·문·나무·바위는 공유 `city_scenery.gd`의 충돌·발밑 Y정렬을 쓴다. 문 가운데는 통행, 기둥은 충돌한다. 아틀라스는 원본을 편집하지 않고 개별 영역 메타데이터로 참조한다.
- 폐허는 세 번째 맵이 아니라 산촌의 상태다. 미니맵/전체 지도도 같은 건물 배치를 읽는다.
- 후육: 체력180, 근력14/기민12/근골12/내공12/오성10, 하급 도와 기존 쇄목도법/거친 도질.
- 마운표: 체력460, 근력22/기민18/근골18/내공20/오성12, 맨손·반석진각공. 강한 하체와 짧은 발차기의 기존 설정을 공유 공격 계산(근력×3+기민×2+내공×2, 내기18)에 연결하고 전용 아이콘을 제작했다. 플레이어에게 자동 전수/판매하지 않는다.
- 기존 공격 의도 예고·내기·방어·모션·효과음을 사용한다. 적의 구체 기술은 실제 출수 전 예고에서 노출하지 않는다.

## 저장·검사

새 `qingya_quest` 필드는 진도·조사·입장·분기·선택 보상·출발·폐허·후회 상태를 보존한다. 구버전 저장에 필드가 없으면 미수락으로 시작한다. 새 지역 좌표/교전 일관성과 분기/폐허 불일치를 검증한다. 기존 대화·거래·전투 중 저장 금지 규칙은 유지한다. 선택창을 닫고 마운표 앞에서 결정 전 저장할 수 있다.

- `tests/qingya_quest.gd`: 실제F 대상/접근 경로, 미수락 통과, 자유 조사, 대화/충돌, 선택·보고, 두 결말, 보상3종·상한·중복, 패배 후 재도전, 왕복/폐허/조사, 진도별 저장과 구버전 호환, 다른 의뢰 추적 유지.
- `tests/qingya_balance.gd`: 중급5종×성장3수준×적2종=30회 공유 전투 계산. 첫 단순 공격 운용으로 모두 승리했으며 극단적인 편중/무성장까지 승리를 보장하는 검사는 아니다.
- 기존 `saves`, `overland_travel`, `quest_update`, `combat_updates`, `prologue_f_input` 회귀 검사. 모든 저장은 실제 플레이와 분리한 XDG 폴더에서 수행한다.
- 통합 검사는 주요 인물까지의 실제 길 찾기/F 이벤트와 실제 교전을 사용하되 긴 이동은 접근 경로 끝점으로 옮긴다. 처음부터 모든 구간을 수동 보행한 기록과 구분한다.
