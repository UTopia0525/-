# 떠나는 자, 남는 자 — 산촌·청애채 잠입 구출

사용자 수정(2026-10-26): 무창 이야기를 끝낸 도원이 녹림 총채주 후보 마운표를 이기는 전개를 폐기했다. **이번 의뢰의 전투는 감옥 앞의 일반 산적 정괴 한 명뿐**이다. 청애채에 몰래 잠입해 임수의를 구하며 마운표와 대면/전투하거나 산채를 해산시키지 않는다.

## 진입과 진행

무창 동문 푸른 포탈 F→삼거리 산촌. 노란! 임수전에게 F로 사정을 듣고 수락/보류한다. 다른 의뢰와 동시에 진행하고 Q에서 추적을 바꿀 수 있다. 지나가기만 하면 수락·전투를 시작하지 않는다.

```text
임수전에게 선택 수락
  → 주민3명 조사 (자유 순서)
  → 후육의 징수 방문 · 주민이 말려 직접 싸우지 않고 물러남
  → 북쪽 길로 청애채 외곽 도착
  → 정문은 경비/목책에 막힘 · 서쪽 목책 틈 탐색
  → 목책 틈 F 잠입
  → 잠긴 감옥 F 조사 · 안쪽 임수의의 목소리 듣기
  → 감옥지기 제압·구출 / 개입 포기 선택과 확인
      ├─ 구출: 정괴와 전투 → 임수의 구출 대화 → 마지막 대사 후 산촌으로 자동 전환
      │       → 임수전에게 F 완료 보고 → 능력치 선택·보상
      └─ 포기: 임수의에게 뜻 전함 → 목책 틈 F로 빠져나옴 → 산촌 귀환·보고
```

후육전/마운표전은 더 이상 발생하지 않는다. 마운표는 두려움의 근거로 대사에서만 언급하며 이번 의뢰의 NPC로 배치하지 않는다. 목책을 통과하는 F 상호작용과 잠입 대사·위치 전환으로 잠입을 표현하며 별도의 시야/소음/순찰 AI는 추가하지 않았다.

정문 가운데에는 실제 충돌을 가진 목책을 설치했다. 서쪽 훼손된 목책 틈은 F로 몸을 낮춰 들어가며, 안쪽 F 출구로 다시 나올 수 있다. 입장 허가를 받고 정문으로 들어가는 과거 경로는 없다. 잠입 전에는 감옥지기/감옥 조사 지점을 나타내지 않는다. 위치 안내는 밖에서는 잠입 지점, 안에서는 감옥/감옥지기, 포기 후에는 목책 출구와 산촌 귀환을 가리킨다.

## 전투·구출 후 장면 전환

정괴는 청애채의 일반 감옥지기다. 체력280, 근력16/기민14/근골14/내공14/오성12, 하급 도와 기존 쇄목도법·거친 도질을 사용한다. 일반 산적 전용2번 그림을 사용한다. 감옥 창고 앞의 전용 전투 배경을 생성해 적용했다. 이는 별도 탐험 맵이 아니므로 신규 맵은 여전히2개다. 마운표의 반석진각공을 쓰지 않는다.

패배 시 사망→종료 화면→확인하여 타이틀 복귀. 이전 저장은 유지한다. 전투 전 사망 경고·확인을 유지하며 정비/저장을 위해 결정을 보류할 수 있다. [공통 사망 규칙](../systems/combat-death.md).

승리 후 감옥 앞에서 임수의와 문을 열고 빠져나가자는 대화를 한다. **마지막 대사를 넘기기 전에는 청애채에 머물고, 대화를 끝내면 산촌으로 즉시 전환**한다. 산채 밖으로 다시 걷거나 포탈을 찾아갈 필요가 없다. 산촌에는 임수의를 배치하며 임수전에게 완료 보고한다.

마을 대사도 산채 토벌/징수 중단이 아닌 아우의 귀환에 대한 감사와 남은 두려움으로 바꿨다. 청애채·마운표는 그대로 남으며, 주민을 구했다는 이유로 산채의 수탈이 영구히 끝났다고 말하지 않는다. 폐허 대사에서도 간수 한 명을 쓰러뜨리고 떠난 자신의 한계를 돌아본다.

## 보상과 폐허 재방문

| 선택 | 완료 보고 후 보상 | 이후 |
| --- | --- | --- |
| 잠입 구출 |200문 + 근력/기민/근골 중1종+5 |보상 후 다른 맵에 갔다가 산촌에 돌아오면 폐허 |
| 개입 포기 |오성+5만 |마을과 주민 유지 |

기존 보상과 결과를 구출 경로로 이어받았다. 능력치 상한100, 마지막 보고 대사와 능력치 선택 후 한 번만 지급하며 다른 수치/명성/호의도는 바꾸지 않는다. 보상 선택창을 닫아도 임수전에게 다시 말을 걸어 선택할 수 있다.

구출 직후 자동 산촌 전환은 완료 보상 전이므로 폐허를 발생시키지 않는다. 완료 보상 후 산촌에서 다른 맵으로 나간 경우에만 재방문 결과를 예약한다. 단순 저장/불러오기는 출발로 세지 않는다. 폐허는 같은 산촌 맵에서 집·창고를 무너진 자산으로 바꾸고 주민/표식을 제거한다. 우물·삼거리·집터는 유지한다.

재입장 독백→불탄 창고/빈집/임수전을 만났던 자리3곳 F 조사→후회 대화. 추가 보상은 없고 조사/재생 여부도 저장한다. 폐허 원인과 주민들의 행방은 아직 밝히지 않는다.

## 맵과 저장 호환

신규 맵은 산길·산촌1개와 청애채1개, 총2개다. 각각1536×1024 도안/4608×3072 월드, 바닥/개별 충돌/Y정렬/가림·NPC·미니맵·전체 지도를 공유한다. 남경 방면은 아직 안내만 하며 실제 남경 이동은 막는다.

`qingya_quest` 저장 자료는 버전2로 기록한다. 이전 미완료 마운표 면담 단계(`camp`/`decision`)는 목책 잠입부터 진행하도록 바꾸고, 이미 완료한 분기/보상/폐허는 보존해 중복 지급하지 않는다. 구버전 저장에 남은 마운표 전투의 체력·내기 예고 정보도 감옥지기 조우로 변환해 불러오며 원본 저장 파일은 고치지 않는다. 버전2 잠입·선택 저장은 같은 지점에 복원한다. 데이터에 없는 구버전 저장은 미수락으로 시작한다.

저장 호환을 위해 구출 분기의 내부 ID `assault`와 실제 감옥지기 전투의 과거 ID `qingya_chief`/단계 `fight_chief`는 유지한다. **ID와 달리 실제 적은 정괴이며 마운표 조우가 아니다.** 과거 후육 조우는 `legacy_encounters`에 읽기 호환용으로만 남기고 신규 진행에서는 참조하지 않는다. 마운표의 초상화/인물 설정/외공 아이콘은 후속 콘텐츠를 위해 보존한다.

## 검사와 실제 화면

- `qingya_quest.gd`: 실제F 접근 경로, 선택 수락·조사·비전투 대면, 닫힌 정문·목책 잠입·감옥 조사, 마운표 미등장/전투1회, 두 분기, 구출 대화 마지막 줄 뒤 자동 귀환, 보상3종/중복/상한, 재방문·폐허, 기존/새 저장 호환.
- `qingya_balance.gd`: 중급5종×성장3수준×감옥지기1명=15회 공유 전투 계산. 일반적인 성장 구간에서 모두 승리하며 극단적 편중/무성장까지 승리를 보장하지 않는다.
- `death_flow.gd`, `saves`, `quest_update`: 실제 피격 사망/타이틀 복귀·저장 보존·공용 의뢰 안내 회귀 검사. 저장은 분리된 XDG 폴더에서 수행한다.
- 통합 검사는 실제 길 찾기/F 이벤트와 실제 교전을 사용하되 긴 이동은 접근 경로 끝점으로 옮긴다. 모든 구간을 수동 보행한 기록과 구분한다.
