# 등불 밖의 셈 — 흑도방 후속 의뢰

취월루 「등불 아래의 칼끝」 완료 후 설금란에게 선택 수락한다. 자동 사건으로 기존 점소이 소개·상점 안내를 가로채지 않는다.

## 실제 진행

설금란 수락 → 심옥분 → 한수성 → 방소길 → 항주 나루의 탁문호 → 은소월 → 운하 창고 송계수 대면/집행 무인 전투 → 정만수와 계약 원본·정산 대조 → 은소월과 두 노선 선택 → 흑도방 본당 위중량 교섭 → 취월루 설금란 완료 보고.

- 공개: 당사자들에게 차등 청구와 협조 내역을 공개하고 공동 계약 철회를 이끈다. 정만수는 잃은 신용을 스스로 회복하려 한다.
- 합의: 협조자 이름을 감추고 계약 철회·과다 징수금 반환·거래 방해 중단을 문서로 받는다. 주민은 생업 회복에 안도하고 남은 약속을 지켜본다. 도원에게 노골적인 비난·불만을 말하지 않는다.
- 위중량은 본당에서 직접 만나는 비교전 인물이다. 방주 전투나 흑도방 해체를 추가하지 않는다. 은소월도 교섭에 함께한다. 밖에서의 이름표는 은소월/취월루주이며 하오문 공개 표시는 추가하지 않는다.
- 사용자 확정 완료 보상은 양 노선 모두500문·하오문 호의도+30이다. 마지막 보고 대사가 끝나야 한 번 지급하며 능력치·명성은 올리지 않는다. 이미 완료한 옛 저장은 재지급하지 않는다. 피해 회복금은 각 거래처에게 돌아가며 도원 소지금에서 차감하지 않는다.

## 장소와 미술

항주 서호변의 F 포탈 두 곳에서 운하 창고와 흑도방 본당으로 왕복한다. 창고는 조사 후, 본당은 해결 노선 선택 후 개방한다. 창고의 사무 책상·서가를 제거하고 짐18더미를 배치했다. 중앙 운반 통로와 가로 통로는 비우고 송계수·정만수는 통로 가장자리로 옮겼다. 실내 각각3072×2048, 별도 바닥 원화·독립 가구 충돌/Y정렬·중앙 통로·문 통행을 사용한다. 검은 목재·탁한 금색·넓은 흑석 바닥·높은 상석·두 호위를 배치해 본당의 위세를 표현했다. 위중량은 기존 초상화와 이를 따른 전용 탐험 도트를 registry에 등록했다. 정만수/송계수는 기존 기본 초상화 풀을 재사용한다.

## 전투·저장·일지

흑도방 집행 무인: 근력65/기민50/근골55/내공55/오성40, 합계265, 체력690. 기존 도/회풍도법과 공통 격자 AI를 사용한다. 새 무공은 추가하지 않는다. 실전 패배는 사망→타이틀, 기존 저장 유지다. 의뢰 수락 전에 이를 안내한다.

Q 독립 기록/추적, NPC !/보고 ?, 미니맵·전체지도 표시와 지역 이동 안내를 공통 경로에 연결했다. 다른 의뢰를 중단시키지 않는다. 대화·거래·전투 저장 금지를 유지하며 탐험에서 저장할 수 있다. 선택창은 기존 메뉴 저장 제한을 따르며 Esc로 닫은 뒤 미결정 상태를 저장하고, 불러온 뒤 은소월과 다시 대화해 선택을 이어간다. 선택은 해당 대화 마지막 줄 뒤 확정한다. 구저장에서는 새 의뢰를 미수락으로 이행한다.

검증: `tests/blackguild_story.gd`는 실제 F 입력으로 양 노선 조사/전투/교섭/보고, 수락 보류, 지역 왕복, 선택창 닫기/분기 전후 저장 복원, 보상 중복 방지, 사망/저장 보존과 구저장을 검사한다. `tests/blackguild_balance.gd`는 공통 AI와 중급5계통×4성장 수준20건을 비교한다. 합계101은0/5,201은2/5,251·301은각5/5승으로, 낮은 성장의 패배를 없애려고 기존 수치를 변경하지 않았다. `capture_blackguild.gd`는 실제 렌더를 저장한다.
