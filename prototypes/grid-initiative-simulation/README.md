# 7×5 행동권 실험 리플레이

[실험 조건·결과](../../docs/reviews/grid-initiative-paak.md)

`index.html`을 다운로드해 브라우저로 열면 설치 없이 재생한다. GitHub의 HTML 코드 화면은 실행 화면이 아니다. 파일 우측 위 **Download raw file**로 저장한다. 데이터가 HTML 안에 포함되어 한 파일만으로 재생·유형/위치/체력 비교가 가능하다.

이는 실제 계산 결과를 재생하는 분석용 도구다. 자유 조작하는 새 게임 데모가 아니며 본게임의 전투 시스템이나 NPC 수치를 변경하지 않았다. 체력1,120은 연속 행동을 관찰하기 위한 검증용 표적이고 실제 정괴는280이다.

- 도원: 기민50형/동일 총합의 근력50형/기민형의 행동 속도만 적과 같게 고정한 대조군.
- 중앙·인접·대각·모서리·진영 반전5가지 시작 위치.
- 실제 체력280과 검증용1,120.
- 검증용 중앙 기민형에 한해 내기 회복을 공통 박자/행동별로 비교.
- 이전/다음·자동 재생·시점 막대와 전체 계산 JSON 내려받기.

`godot/tests/simulate_grid_initiative.gd` 실행 후 `python scripts/build_grid_initiative_replay.py`로 HTML 데이터를 갱신한다. 결과는 결정론적이며31개 조건은 승률 표본이 아니다.
