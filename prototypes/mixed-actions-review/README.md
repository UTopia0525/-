# 이동·방어·복수 무공의 비교 이득 검사

2026-10-30. **기획 검토 전용. 본게임 전투/데이터/저장은 변경하지 않는다.**

목표는 무기 순위가 아니라, 같은 상대와 시작 조건에서 선택지를 하나씩 빼면 결과가 나빠지는지 확인하는 것이다. 별도 접근 이동은 언제나 허용한다. 무공 자체의 전진/후퇴, 검법의 수동 방어도 제거하지 않는다.

```bash
cd prototypes/mixed-actions-review
python -m unittest -v test_experiment.py
python experiment.py                 # 2,016회, floor50/100 성장식
python experiment.py --exact50       # 252회, 초반 실제 상한50
python sensitivity.py               # 336회, 예측 길이20/60
python cost_probe.py                # 504회, 비용70%로 실제 상한50/100 대조
python report.py                    # 보고서/단독 HTML 재생기 생성
```

`--pilot`은 소규모 동작 확인이다. 본 실험 횟수에 합산하지 않는다. 각 명령이 끝난 뒤 다음 단계로 진행한다. 기본 Python 표준 라이브러리만 사용한다.

## 고정한 것

- 앞선 `progression-combat-review`의 graded 검토 위력·내기 비용·준비/출수/회수 시간. 기존 파일과 Godot 런타임을 수정하지 않는다.
- 행동 완료 때 내공만큼 회복, 대기는 회복 없음, 전투 시작 내기=내공.
- 기본공격/기본방어/무공A/무공B의4칸과 별도 이동. 기본방어20%, 이동3/5/2.
- 플레이어는 검법 조합 하나를 성장 구간별로 사용한다. 상대는 검/강공 도/원거리 창3유형. 무기 우열 검사가 아니며 맨손·모든 조합의 일반화 검증도 아니다.
- 기민 속도 보정·장애물·다수전·피격 경직은 추가하지 않는다.

## 같은 판단 방식,7가지 제한

전체 허용 / 회피·거리조절 이동 제한 / 기본방어 제한 / A만 / B만 / 이동·방어 없이 A만 / 이동·방어 없이 B만. 마지막 두 경우에도 필수 접근과 기본공격은 가능하다.

동일한 짧은 미래 예측으로 피해·생존·종료 시간을 평가한다. 행동을 섞었다는 가산점, 반복 벌점, 강제 순환은 없다. 미래 적 명령이나 실제 난수는 읽지 않는다. 다만 상대 AI는 같은 예측기를 쓰지 않으므로 승률 자체를 난이도나 사람의 실력으로 해석하면 안 된다.

`committed`는 현재 시작한 적 기술의 정확한 수치를 안다는 숙련자 상한 조건이다. `coarse`는 그 기술을 자세/단계에 따른 대표 기술로 추정한다. 후자도 상대의 능력치와 보유 기술을 아는 가상 조건이며, 실제 UI·초심자 반응 검사가 아니다. 무기와 현재 방향·이동 방향은 관측 가능하다고 가정한다. 향후 행동은 공통 단순 정책으로 예측하므로 최적해를 증명하지 않는다.

## 통과 기준

비교 이득은 패배/시간초과를 승리로 바꾸거나, 둘 다 승리할 때 최대 체력10% 이상 더 남기고 소요시간 증가50% 이내이거나, 체력을 덜 잃으면서 시간을20% 이상 줄이는 경우다. 단순히 오래 버티거나 여러 행동을 사용하면 통과시키지 않는다.

각 기능의 이득과 별도로, 실제로 회피·거리조절 이동에 성공하고/기본방어로 피해를 줄이고/A·B를 모두 명중시킨 경우를 센다. 엄격한 결합 통과는 이 실제 사용과 이동·방어·두 번째 무공의 개별 비교 이득을 같은 전투에서 모두 만족해야 한다. 복수 무공 이득은 A 단독과 B 단독 **양쪽**보다 좋아야 한다.

결과는 [검토 보고서](../../docs/reviews/mixed-actions-merit.md), [기록 재생기](index.html), 원자료 `results.csv`/`exact50.csv`/`sensitivity.csv`를 참조한다. 예측 길이에 따른 결과 변동과 실패/시간초과도 보존한다.
