# 전투 전용 미술 자산

2026-10-28 승인된 대나무 전투 시안의 미감에 맞춰 image_gen으로 제작했다. 시안의 글자/인물/UI가 합쳐진 그림을 배경으로 사용하지 않는다. 실제 지형 격자/인물/한글/상태 수치/선택은 Godot에서 독립적으로 그린다.

- bamboo-court.png: 빈 산중 대나무 공터/폭포 배경.
- river-deck.png:0장용 빈 명나라 호송선 갑판/강 배경.
- jade-frame.png: 투명 외곽·비취 바탕·금테의 빈 UI 프레임.
- paper-frame.png: 투명 외곽·한지·먹그림·금테의 빈 UI 프레임.

원본 PNG를 유지한다. 실제 피부/텍스트는 battle_art_skin.gd와 grid_battle_hud.gd가 배치하며 get_used_rect로 투명 바깥 여백만 렌더 영역에서 제외한다. 사각형의 각기 다른 비율에는 프레임 그림이 늘어나므로 시안 전체 화면의 픽셀 단위 복제는 아니다. 배경/패널/실제 인물은 분리해 애니메이션 가능 상태를 유지한다.

hero-jade-poses.png는 시안의 녹색 복식을 따른 도원 전투 시트16자세(무기4×자세4)이며 hero-jade-frames.json이 아틀라스 위치/발 기준점을 제공한다. 적 전투 그림/초상화/무공 아이콘은 기존 자산을 재사용한다. 새 기술·아이템을 추가하지 않았으며 새 무공 전용 효과도 만들지 않았다.
