# 전투 배경과 캐릭터 자산

- `deck-empty.png`, `road-empty.png`: 기존 전투 그림을 바탕으로 인물을 제거해 생성한 배경.
- `hero-poses.png`, `enemy-poses.png`: 투명 배경으로 생성한4×4 캐릭터 시트. 열은 검/도/창/맨손, 행은 준비/공격 예비/타격/피격.
- `frames.json`: 실제 인물별 영역과 발의 위치. 인접 칸의 무기 조각이 섞이지 않고 자세의 발 높이가 유지되도록 지정한다. 표시용 영역 지정이며 원본 PNG를 변형하지 않는다.

표시는 `battle_actor.gd`의 AtlasTexture와 Tween을 사용한다. 새 이미지를 생성하거나 기존 시트를 수정하면16개 영역과 발 위치도 다시 확인한다. 현재 같은 무기 종류 안의 등급별 모습은 공유한다. 대화용 주인공 초상화는 별도 자산을 그대로 사용한다.
