# 공통 효과음

외부 녹음이나 다운로드 없이 직접 합성한 원본 PCM WAV 10종이다. 22,050Hz·16bit·모노이며 효과음은 Effects 버스, 기존 상황별 BGM은 Music 버스를 사용한다. 음량과 음소거는 독립적이다.

| 파일 | 용도 | 길이 |
| --- | --- | --- |
| confirm.wav | 결정·일반 UI 적용 | 0.13초 |
| coin.wav | 물품 구매 | 0.30초 |
| quest.wav | 의뢰 수락·갱신·완료 | 0.45초 |
| learn.wav | 무공 습득 | 0.45초 |
| attack_sword.wav | 검 베기 | 0.24초 |
| attack_saber.wav | 무거운 도 휘두르기 | 0.30초 |
| attack_spear.wav | 창 찌르기 | 0.22초 |
| attack_none.wav | 맨손 출수 | 0.18초 |
| hit.wav | 실제 타격 | 0.16초 |
| block.wav | 실제 방어 행동/차단 | 0.20초 |

커서 올림이나 적 행동 예고만으로 소리를 재생하지 않는다. 의뢰 보류/실패한 구매로 구매 완료음을 내지 않는다. `scripts/game_options.gd`가 짧은 동시 재생용 보이스를 관리한다. 재생성은 저장소 루트에서 `python godot/tools/generate_sfx.py`로 한다. BGM 5곡과 그 제목·용도는 기존대로 유지한다.

전투는 양측 모두 타격 자세로 전환하는 순간 무기별 공격음을 내고, 실제 피해가 발생하는 시점에 피격음을 재생한다. 피해0은 차단음으로 구별한다. 행동 선택/예고/미리보기에서는 공격음을 내지 않고, 방어 행동에는 차단음을 사용한다. `battle.sound_requested`를 공통 효과음 플레이어에 연결하며 교전 기록은 소리를 중복 재생하지 않는다. 모션 취소 시 미실행 타격 콜백도 취소되고, 일시정지 시 공격 콜백과 피해 처리가 함께 멈춘다. `tests/battle_motion.gd`에서 양측 공격→피격 순서, 중복 방지, 실제 재생 연결, 음소거를 검증한다.
