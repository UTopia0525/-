# 청애채 공용 구조물과 바닥

`ground.png`는 바닥만 있는 전용 원화이며 `props.png`는 이미지 도구로 생성한 투명 구조물/폐허 아틀라스다. 원본을 잘라 새 PNG를 만들지 않고 두 지역의 `layout.json` 안 `prefabs.source`로 각 오브젝트 영역을 참조한다. 생성 결과의 실제 그림 경계에 맞춰 영역을 측정했으므로 처음 요청한 균일 셀 간격과 다르다. `art-manifest.json`에 두 맵 바닥·아틀라스·신규 외공 아이콘의 원본 해시를 기록했다.

청애채·산촌은 `qingya_map.gd`/공통 `city_scenery.gd`의 개별 충돌/Y정렬을 사용한다. 산촌 평상시와 폐허는 동일한 배치 데이터를 쓰되 집·창고 프리팹만 바꾼다. [진행·원고·보상·검사](../../../../docs/quests/qingya-village.md).
