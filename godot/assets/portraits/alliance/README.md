# 무림맹 총관·교관 초상화

허문규51세(총관)와 곽진석46세(교관)의 전용 대화 그림이다. 이미지 생성 도구로 기존 주인공의 화풍·허리 위 구도를 기준으로 제작하고, 대화창에서 사각 배경이 생기지 않도록 투명 배경 버전을 적용했다. 원본 PNG는 픽셀 후처리 없이 보관하며 표시 비율과 방향은 `data/portrait_framing.json`과 공통 대화 셰이더가 처리한다.

허문규는 긴 얼굴·가는 눈·반백 수염·회색 도포·장부, 곽진석은 사각 얼굴·휜 코·거친 수염 자국·청회색 수련복·손목 감개로 구별한다. 두 사람은 세력의 주요 인물이며 기본 마을 초상화18장에는 포함하지 않는다. 정문 경비2명은 기존 기본 이미지의 청년/중년 남성을 서로 다르게 재사용한다. 전투 수치는 부여하지 않았다.

현재 인물 대화와 배치만 구현했으며 신원 보증 연출과 무공 선택/전수는 후속 작업이다. [인물 설정](../../../../docs/characters/alliance-headquarters.md).
