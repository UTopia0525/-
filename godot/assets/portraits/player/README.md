# 도원(陶遠) · 주인공 대화 일러스트

![주인공 기본 표정](hero.png)

사용자 확정 이름은 도원(陶遠)이다. 내부 인물 ID는 `hero`를 유지한다.

사용자 지정 외형을 반영한 주인공/플레이어 전용 초상화이다.

- 젊은 남성, 기본 표정은 무표정.
- 전투 캐릭터에 맞춘 회청색·푸른색 무복, 흰 교차 깃/소매 안감, 소박한 갈색 천 허리띠와 어두운 손목 보호구. 소탈하지만 해지거나 찢어지지 않은 복장이다.
- 삿갓과 모자 끈·어깨 천은 제거했다. 검은 머리를 높게 묶어 뒤로 늘어뜨린 묶음머리와 느슨한 앞머리를 사용한다. 관식이나 문파 문장은 없다.
- 무기는 플레이어가 추후 선택하므로 무기·칼집·장비를 그리지 않는다.
- 기존 대화 초상화와 어울리는 도트 질감 반신 일러스트, 투명 배경 PNG.

AI 이미지 생성 도구로 제작했다. `scripts/dialogue_portraits.gd`의 `hero.portrait`에 연결했으며 주인공에게 사용하던 공용 청년 남성 초상화를 대체한다. 발언 시 원래 밝기, 듣는 동안 어둡게 표시하는 규칙은 그대로 적용한다.

이 이미지는 대화용이다. 탐험 도트도 같은 묶음머리·푸른 무복으로 맞췄으며 전투 스프라이트는 기존 기준을 유지한다. 이름·성격·추가 배경·전투 수치를 확정하지 않는다.
