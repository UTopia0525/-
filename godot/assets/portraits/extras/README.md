# 엑스트라 공용 대화 일러스트

명 초기 무협 배경의 일반 인물에게 반복 사용하는 투명 배경 PNG 6장이다. 특정 세력·직업이나 고유 인물을 의미하지 않으며, 성별·나이대는 초상화 선택용 분류이다. 청년은 성인이다. 인물별 전투 수치와 새 스토리는 추가하지 않았다.

기존 인물 초상화에 맞춘 도트 질감의 반신 일러스트이다. 각 연령대의 주름·체형·머리·얼굴형·평상복 색상을 달리하고, 모두를 미남·미녀로 통일하지 않는다. AI 이미지 생성 도구로 제작했다.

## Godot 대화 연결

`scripts/dialogue_portraits.gd`의 `ACTORS`에 인물 ID, 표시 이름, `extra` 분류를 등록한다. 전용 일러스트를 받으면 같은 항목에 `portrait: "res://...png"`를 넣는다. 로드할 수 있는 전용 초상화가 공용 분류보다 우선한다.

현재 0장에서는 육승에게 청년 남성, 서문길·허만복에게 중년 남성, 진소옥에게 청년 여성을 임시 연결했다. 주인공은 [전용 초상화](../player/README.md)를 사용한다. 엑스트라 공용 그림 연결은 해당 인물의 전용 디자인을 확정한 것이 아니다. 다른 연령·성별 초상화도 즉시 사용할 수 있다.

대화 줄은 `[인물ID, 대사]` 형식이다. `say(대사목록, 종료콜백, 듣는인물ID목록)`에서 마지막 인수를 생략하면 주인공이 포함된다. 모든 발언자와 지정한 청자가 대화 처음부터 끝까지 함께 표시된다. 독백은 주인공 한 명만 표시된다. 발언 순서가 바뀌어도 자리와 그림은 유지되며, 발언자만 원래 밝기이고 나머지는 RGB 32%로 어두워진다. 동일 공용 그림을 쓰는 인물도 ID별로 따로 강조한다. 5명 이상은 여러 줄로 배치하며 대화 종료·전투 전환·재시작 시 모두 숨긴다.

공용 초상화만 추가한 것이므로 탐험용 도트 스프라이트의 외형과 걷기 애니메이션은 그대로이다.
