# 무창 민간 주민 전용 초상화

유백초·석대용·임정산·도삼랑·육정호·오덕수·정씨 할머니·주계복8명의 전용 원본 PNG다. 이미지 생성 도구로 기존 주인공의 화풍/구도만 참고해 새 인물로 제작했다. 픽셀 후처리나 기존 주인공 그림 교체는 하지 않았다. 얼굴형·연령·생활 흔적·복식·표정을 구분했다.

`data/portrait_framing.json`에 눈높이·얼굴 기준 크기·오른쪽 기본 시선을 등록했다. 실제 대화에서는 셰이더 프레이밍과 좌우 반전으로 주인공과 비율을 맞춘다. [인물 설정과 실제 대화](../../../../docs/characters/wuchang-civilians.md).

사용자 후속 지정에 따라 이8장은 기존 공용10장과 함께 **기본 NPC 이미지18장**에 포함된다. 무창 인물의 배정은 유지하면서 다른 도시의 일반 주민에게도 재사용한다. `data/basic_npc_portraits.json`의 직업별ID로 참조하며 별도 지시 없이 새 일반 주민 그림을 만들지 않는다.
