# 이야기 인물 전용 대화 일러스트

## 포졸

![포졸 전용 일러스트](constable.png)

장사의 모집 소식을 전하고 토벌 집결·철수·귀환을 돕는 bandit_messenger의 전용 초상화다. 검고 소박한 두건형 관모, 짙은 남색 평상 근무복과 절제된 붉은 깃, 허리의 포승줄로 낮은 직급의 관아 일꾼임을 표현한다. 둥근 턱과 넓은 코, 작은 눈과 햇볕에 탄 피부로 주인공과 구별되는 투박하고 성실한 인상이다.

투명 배경 PNG이며 기존 대화의 발언자 강조·청자 어둡게 처리·도시 배경 어둡게 처리를 그대로 따른다. 주인공 전용 일러스트를 수정하거나 전투 스탯·새 이름·계급을 부여하지 않는다. 정 포두와 구별되는 인물이며 현재 탐험용 스프라이트는 기존 배치를 유지한다.
