# 主人公 / 주인공 걷기 프레임

기존 캐릭터 외형을 참고해 새로 만든 네 방향 걷기 시트입니다. 앞뒤 이동은4프레임·도시 기준 초당10프레임을 사용하고, 좌우 이동은 기준 몸체 위에서 발을 교차하는 보행을 적용합니다. 정지하거나 대화가 시작되면 같은 걷기 시트의 기준 몸체를 사용하는 정지 자세로 돌아갑니다. 벽에 막혀 실제로 움직이지 않을 때도 정지 자세로 전환합니다.

- `hero_walk.png`: 4방향×4동작, 총16프레임의 알파 PNG. 행 순서는 아래·왼쪽·오른쪽·위입니다.
- `hero_walk_frames.json`: 생성 시트의 불균일한 여백을 보정하는 AtlasTexture 영역·머리 중심·발 기준점 데이터.
- `scripts/player.gd`: `AnimatedSprite2D`와 `SpriteFrames`로 걷기/정지를 연결합니다.

프레임마다 PNG를 잘라 다시 저장하지 않고, 원본의 각 그림을 Godot의 아틀라스로 참조합니다. 기준점을 맞춰 머리·발 잘림과 좌우 흔들림을 줄였습니다. 실제 걷기 프레임 전환을 사용하므로 기존의 단순 상하 흔들림 코드는 제거했습니다.

새 시트로 바꾸면 저장소의 다음 도구로 영역과 기준점을 다시 측정할 수 있습니다. 도구는 PNG를 수정하지 않고 메타데이터만 기록합니다.

```sh
python tools/measure_walk_sheet.py
```

이 시트는 기본 걷기용입니다. 달리기·공격·피격 애니메이션은 포함하지 않습니다. 현재 움직이는 주인공에 연결했으며, 이동하지 않는 NPC의 연출은 변경하지 않았습니다.

현재 탐험 속도는 초당360이며 도시 주인공140·주민132, 0장 인물104 높이를 사용합니다. 발 기준점은 유지하고 작은 인물은 보폭에 맞춰 애니메이션 재생을 보정합니다. [탐험 크기와 이동](../../../docs/systems/exploration-scale.md).

## 가로 보행과 정지/걷기 크기 고정

기존16장 중 좌우4장의 발 모양이 거의 같았고, 정지 시트와 걷기 시트의 머리/몸통 비율도 달랐다. 현재는 정지·걷기 모두 `hero_walk.png`의 같은 방향 기준 몸체와 동일 배율을 사용한다. 좌우 이동은 몸체를 고정하고 `side_walk.gdshader`로 하체를 교차시킨다. 두 다리의 경계를 분리해 신발이 서로 잡아 늘어나지 않게 하며, 신발 아래쪽은 형태를 유지한 채 앞뒤 이동/발 들기를 적용한다. 원본 PNG는 수정하지 않았다.

보행 위상은 실제 이동 거리에 연결한다. 멈춤·대화·벽에 막힘에서는 중립 발 자세로 돌아가며, 발밑 충돌·이동 속도·카메라 기준점은 유지한다. 0장의104와 도시의140이라는 맵별 기존 표시 높이는 유지한다.
