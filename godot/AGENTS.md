# 게임 콘텐츠 작업 규칙

- 새 무공은 전용 아이콘과 함께 `data/martial_tactics.json`에 공격 칸·전진/후퇴·밀침 데이터를 등록한다. 범위·효과 그림은 공통 `martial_range_preview.gd`가 자동 생성하여 전투 왼쪽 하단과 K창에 표시한다. 방어·내기 회복·재사용 대기는 무공 카탈로그의 효과 필드를 사용한다. 별도 텍스트 설명만 남기거나 각 화면에 범위를 따로 하드코딩하지 않는다. 새 무공을 추가할 때 `tests/range_diagram_ui.gd`로 표시를 확인하고 문서용 범위 도해도 다시 생성한다.

- 새 아이템·무공을 추가할 때는 사용자의 별도 요청 없이 해당 콘텐츠의 전용 아이콘/일러스트도 생성하고, `data/icon_manifest.json`에 안정적인 ID로 연결한다. 기존과 같은 미술 규칙을 유지하되 새 상위 등급은 구별되게 만든다. 미등록 상위 시각 예시를 새 콘텐츠의 확정 이미지로 자동 전용하지 않는다.
- 전투 선택지, I 소지품, K 무공, 상점에서 새 이미지가 실제로 표시되는지 확인한다. `tests/combat_updates.gd`의 전체 카탈로그 이미지 검증을 실행한다. 이미지 생성 도구가 불가하면 누락을 명시하며 완료로 보고하지 않는다.
- 플레이어·적 모두 `combat_actions.gd`와 `inner_qi.gd`의 공통 계산을 사용한다. 적 예고는 플레이어 선택 전에 확정하고 선택/저장 불러오기로 재추첨하지 않는다.
- 새 전투 콘텐츠는 최소 학습 조건과 절정 진입 수준의 여러 무기/무공으로 초회 클리어 난이도를 점검한다. 테스트는 분리된 XDG 사용자 폴더에서 실행해 실제 저장을 건드리지 않는다.

- 무공 성장 곡선에 대한 사용자 확정: 상급을 포함한 모든 등급의 창법은 높은 고정 위력(`base_damage`)과 상대적으로 낮은 능력치 계수를 중심으로 만든다. 상급 검법·도법·권법·장법 등은 동급 창법보다 높은 성장 계수로 후반 효율이 앞서도록 설계한다. 상급 창법의 고정 위력은 등급에 맞춰 높일 수 있으나 높은 계수까지 자동 부여하지 않는다. 구체 수치는 개별 무공 제작 시 결정하며, 동급 장비·학습 직후/후반 성장 구간에서 비교한다. `docs/systems/spear-balance.md`를 따른다.

- 대사·UI는 한국어 무협풍을 유지한다. 사문·표행·강호·초식·출수 등의 표현은 인물의 신분과 상황에 맞게 쓰고, 민초는 생활감 있는 말투를 유지한다. 과도한 고어·한자어로 뜻이나 조작법을 흐리지 않는다. 보상·분기·말하는 인물·콜백은 문체 수정만으로 바꾸지 않는다.
- 서체는 제목·인물 이름에 번들된 붓글씨, 긴 대사·설명·수치에 번들된 명조체를 사용한다. 새 문구의 글리프 지원·줄바꿈·잘림을 확인한다. 새 무공·아이템 행은 공통 아이콘/하이라이트 처리를 사용해 마우스와 키보드 가시성을 유지한다.
- 적 행동 예고는 공격/수세 같은 큰 기세만 표시한다. 공격 종류·무공명·내기 비용·위력·전용 아이콘·툴팁을 예고에서 노출하지 않는다. 실제 출수한 뒤의 전투 기록은 구분한다.

- 수동 저장은 대화·거래·전투 중 금지한다. 버튼 비활성화와 실제 쓰기 차단은 `save_system.gd`의 공통 제한을 따른다. 탐험·분기 선택창 저장 및 구버전의 대화·거래·전투 저장 불러오기는 유지한다. 회귀 검사에 필요한 과거 저장은 테스트 전용 `legacy_save_fixture.gd`로 구성하며 런타임 우회 경로는 만들지 않는다.

- 도시 확장 시 바닥에 건물·담장·문을 다시 굽지 않는다. `city_scenery.gd`와 공통 프리팹의 투명 그림·발밑 충돌·Y정렬을 사용하고, 열린 문은 가운데 통행/좌우 기둥 충돌/지붕 가림을 함께 확인한다. NPC는 발뿐 아니라 전신 표시 영역도 건물과 겹치지 않게 배치한다. 미니맵과 전체 지도는 같은 오브젝트 배치를 따른다.
- 일반 마을 NPC는 별도 지시가 없으면 `data/basic_npc_portraits.json`의 기본18장(기존 공용10장+무창 주민8장)을 재사용한다. 성별·나이·직업에 맞춰 고르고 이름·설정과 그림 파일을 분리한다. 새 전용 이미지의 자동 제작을 금지하며 사용자가 별도 지시할 때만 추가한다.
- 한 대화의 다른 인물에게 같은 초상화 파일을 쓰지 않는다. 같은 성별의 기본 풀에서 빈 그림을 배정한다. 부족하면 대화를 나누는 등 구성으로 해결하고 자동으로 새 그림을 생성하지 않는다. 대화 기록은 현재까지 표시한 줄만 보여 주며, 미래 대사/미선택 분기를 노출하거나 읽는 동안 진행/보상을 발생시키지 않는다.

- Q는 의뢰 일지, F는 NPC/거래/조사, F2는 도움말, L은 실행된 교전 기록이다. 일반 의뢰는 실제 수락/보류·수행·완료 보고가 연결된 의뢰인에게만 !를 표시하고, 달성 후 ?/완료 후 제거 규칙을 따른다. 일반 의뢰는 별도로 확정한 선행·배타 조건이 없으면 모두 동시에 수락·진행·완료할 수 있는 것을 기본으로 한다. 새 의뢰마다 동시 진행 여부를 사용자에게 다시 묻지 않는다. 진행/완료/보상 상태를 의뢰별로 분리하고, 목표 추적 변경이 다른 의뢰를 중단하지 않게 한다. 공유 NPC의 진행 대화를 완료 잡담이 가로막지 않게 한다. 보상은 완료 대화 끝에서 한 번만 지급한다. `adventure-usability.md`의 현재 입구·저장 호환을 유지한다.
- 구매·습득·복용·의뢰 갱신 등은 공통 알림/효과음 경로를 사용하고, 커서 올림이나 적의 미래 계획을 소리/기록으로 노출하지 않는다. 환경 설정은 이야기 저장과 분리하고 새 상태 필드는 구버전 읽기 기본값·검증을 함께 추가한다.

- 맵 이동은 WASD/방향키만 사용하고 인물·조사·포탈은 F로 상호작용한다. 클릭 이동·인물 클릭 자동 접근을 재도입하지 않는다. 마우스는 전투·거래·인벤토리·지도 안내 등 UI 선택에 유지한다.

- 장사 밖의 일반 의뢰에는 오성을 기본 보상으로 자동 부여하지 않는다. 의뢰별 사용자 확정을 따르며, 무창 「돌아오지 않는 약초꾼」은 완료 보고 후200문만 지급하고 능력치·명성은 올리지 않는다. 무창 「품삯에서 빠진 세 줄」은 사용자 지정 예외로100문·오성2(상한100)를 보고 완료 후 한 번 지급하며 명성·호의도는 올리지 않는다.

- 모든 새 도시에는 상인·장인·교관을 배치하고, 시설 NPC의 초상화는 `data/service_npc_portraits.json`의 해당 직업2종 중1종을 선택해 재사용한다. 도시 제작 시 선택을 고정하며 새 전용 그림은 사용자 지시가 있을 때만 만든다. 이름/설정/인물ID는 그림 출처 인물과 분리하고 대화·거래는 같은 그림을 사용한다. 현재 장사A·무창B와 일반 주민 기본18장은 유지한다. [직업 이미지 규칙](../docs/characters/creation-guidelines.md)을 따른다.

- 주요 전투 패배의 기본은 사망이다. 새 조우는 `combat_outcome.gd`의 기본 `death`를 사용하며, 청애채 잠입 구출의 일반 감옥지기 정괴 전투는 패배 시 쓰러짐→사망 종료 화면→확인 후 타이틀로 돌아간다. 저장 파일은 삭제/자동 덮어쓰기하지 않는다. 대련은 `nonlethal`, 명시적인 재도전 예외는 `retry`로 조우에 선언한다. 사용자 확정으로 구칠(약초꾼 구출)·장만길(객잔 시비)·마응칠(사칭범)은 패배 시 `death`다. 장만길의 전투 전 말로 중재 경로는 유지한다. 장사 토벌만 명시적 `retry`를 유지하며 유소강 대련은 `nonlethal`이다. 빈 조우의0장 튜토리얼/전투 체험도 기존 예외다. 신규 주요 전투에 재정비/재도전 예외를 자동 부여하지 않는다. 사망 중에는 탐험·메뉴·저장·자동 전투 결산창이 재개되지 않도록 공통 처리를 사용한다.

- 청애채 의뢰는 무창 직후 도원이 마운표를 이기는 전개를 사용하지 않는다. 후육과의 마을 대면은 비전투, 서쪽 목책 F 잠입→감옥 앞 일반 산적 정괴1명과 전투→임수의 구출 대화 마지막 줄 후 산촌으로 자동 전환한다. 마운표는 이번 의뢰에서 대면/전투/NPC 배치하지 않으며 산채도 해산하지 않는다. 기존 보상·폐허 재방문은 구출 분기에 유지한다. 내부 `qingya_chief`/`fight_chief`/`assault`는 저장 호환용 이름이며 실제 적/내용을 그 ID에서 추정하지 않는다.

- 하오문 인물의 머리 위 이름표는 이름과 겉직업만 표시한다. ‘하오문’ 소속·조직 직책·조직 문양을 붙이지 않는다. 육소전은 점소이, 진옥란은 접객 담당으로 표시하며, 추후 관계 공개 뒤에도 머리 위 표시는 유지한다. 일반 기루/찻집/객잔 종사자를 자동으로 하오문 소속으로 만들지 않는다.

- 남경 「쌀자루에 찍힌 이름」은 무림맹 중급 무공 전수 완료 이후 육소전에게서만 수락한다. 주민 조사→연서의 경계/공적 확인→공동 조사→조덕승 비전투 체포·남궁 인계→500문/남궁 호의도+10→연서의 의문→육소전 부재 순서를 유지한다. 범인 처리 결말 선택지를 재도입하지 않는다. 부재는 보상/의문 대화가 끝난 뒤 적용하고 저장/맵 재방문에도 유지한다. 육소전의 속내·행선지와 문주의 정체는 미정이다.

- 남경 맵 확장/수정은 `docs/cities/designs/nanjing-npc-preview.png`의 원 시안에 맞춘 구역 위치·밀집한 골목·중앙 대형 객잔·동쪽 높은 황성 외벽·진회하 수변을 따른다. 성긴 격자형 소도시 배치로 되돌리지 않는다. 새 그림을 통째로 배경에 굽지 않고 독립 오브젝트/충돌/Y정렬을 유지하며, 기존 저장의 배치 버전 이행을 함께 점검한다.

- 남경의 서쪽은 장강 나루와 번화가로 바로 이어지는 열린 하역 입구다. 황성용 그림을 재사용한 서쪽 성문과 단절 벽 조각은 제거했으므로 재배치하지 않는다. 붉은 황성 외벽은 동쪽에만 두고 맵 바깥으로 이어지는 궁성으로 표현한다.

- 남궁세가 후속 「돌아올 터전」은 초기 산촌 잠입과 별개다. 초기 구출에서 마운표가 등장하지 않는 규칙은 유지한다. 폐허3곳 조사·후회 대사 완료/남경 끊어진 계선줄 완료/남궁 호의도10 이상이면 합비 본가 정문의 장남 남궁서진에게서 선택 수락한다. 무사4명과 청애채로 출정→서진 지원으로 마운표 제압→청애채 해체→본가 보고 대화 끝에1,000문·창천보원단1개를 한 번 지급→산촌 주민 재회로 완료한다. 패배는 사망이다. 창천보원단은 오성을 제외한4능력치 각각+3, 상한100, 하급 영약과 별개인 비전 보상이며 상점 판매나 별도 복용 상한을 임의로 추가하지 않는다. 영약을 즉시 자동 복용시키지 않고 I에서 복용한다. 귀환 산촌은 초기 폐허 기록을 보존하며 주민과 일부 수리된 집/남은 수리 흔적을 표시한다.
