# 게임 콘텐츠 작업 규칙

- 최신 사용자 확정: 모든 도시의 시내 도로·골목·생활 마당은 기존 미술 기준의 돌/판석으로 포장한다. 과거 문서의 장사·무창 등의 흙 중심 시내 기준보다 우선한다. 도시 바깥의 흙길/농지, 수로·목재 부두·곡물 작업장 같은 기능 구역은 구분해 유지한다. 지역 경계 밖까지 포장을 확장하지 않고 건물/주민/충돌/진행은 바꾸지 않는다. [공통 돌 포장](../docs/cities/city-stone-paving.md).

- 장사·무창·남경 외성은 항주의 회색 석조 성곽과 `fortification_layout.gd`의 동일 월드 축척을 사용한다. 동서 통로는 `fortifications/side-gate.png`의 별도 측면 그림/좌우 반전으로 맞추며 정면 문을 회전하지 않는다. 작은 남북 보조문도 전용 낮은 문루를 사용한다. 남경은 후속 사용자 승인으로 중앙 남북 대로·북쪽 연속 성곽·성 안 판석/돌길·성 밖 수전/밭과 흙길/layout_version3(7424×5632)이다. 외곽 토지 이용은 서쪽 연속 운하/둑길, 북쪽 마른 밭과 농가, 동쪽 연속 관개 수로와 논으로 구분한다. 운하 바로 옆에 농가/논을 붙이거나 논·밭을 교대 배치하지 않는다. 후속 요청으로 황궁을 철거했으므로 북쪽 황궁이나 예전 동쪽 황성을 되살리지 않는다. [세 도시 성곽](../docs/cities/three-city-fortifications.md) · [남경 성 밖 농촌](../docs/cities/nanjing-countryside.md).

- 항주 북쪽은 성 밖 흙길→북문 통과→시내 진입이다. 세계5888×5632/layout_version2이며 옛 시내와 주민·출입 좌표는 Y+400미술 단위로 이동했다. 옛 항주 저장은 Y+1280월드 단위로 한 번 이행한다. 북문 중앙 통행/양옆 석축 충돌·문루 가림과 수문 물 차단을 유지한다. [외곽 성곽](../docs/cities/hangzhou-fortifications.md).

- 항주는 `hangzhou/painted/`의 정면5층 취월루·연속 시장 점포·객잔·창고·낡은 주거/흑도방과 남경 시장 재질을 사용한다. 프리팹은 항주 layout 안에서만 재정의하며 바닥/충돌/Y정렬을 분리한다. 본당/운하 창고 출입·귀환 좌표와 지도 캐시는 같은 배치에 맞추고 기존 취월루 사건/흑도방 의뢰를 유지한다. 무관/교관은 예외로 미배치다. [항주 미술](../docs/cities/hangzhou-painted.md).

- 소주는 `suzhou/painted/`의 곡물·운하 건물과 벼 재질을 사용한다. 같은 화풍/문 비율/접지 그림자와 기존 비단 공방·운하3교를 유지하고 소주 `layout.json` 안에서 프리팹을 재정의한다. 지역 미술 변경으로 다른 도시의 공유 프리팹을 덮어쓰지 않는다. [소주 미술](../docs/cities/suzhou-painted.md).

- 무창은 `wuchang/painted/`의 무림맹 전용 본부와 실용적인 객잔·술집·다루·보급점, 장사 전용 미술의 동일 시점/비율을 사용한다. 무창 `layout.json` 안에서 프리팹을 재정의하며 다른 도시 공유 프리팹을 덮어쓰지 않는다. 무림맹 정문 통제·총무당 포탈/전수와 주민 접근을 미술 변경 후 점검한다. [무창 미술](../docs/cities/wuchang-painted.md).

- 장사는 `changsha/painted/prefabs.json`의 소박한 전용 건물과 남경 시장 계열의 흙/포장 재질을 사용한다. 다른 도시가 공유하는 `changsha/layered/prefabs.json`을 장사 미술 변경으로 덮어쓰지 않는다. 캐릭터·문 비율/발밑 충돌과 실제 표시 사각형의 지도 동기화를 유지한다. [장사 미술](../docs/cities/changsha-painted.md).

- 대화 표정은 `portrait_expressions.json`의 원본 그림별4표정 시트를 쓴다. 기존 중립 원본은 유지하고 `emotion`/`emotions` 또는 `dialogue_expression_cues.json`으로 지정한다. 얼굴 크기·좌우 반전·공용 그림 중복 방지는 공통 경로를 유지하며 새 전용 그림을 만들면 표정 연결과 실제 대화 비교도 확인한다. [표정 규칙](../docs/systems/dialogue-expressions.md).
- 남경 건물은 시장 `market-slice/`와 전역 `capital/`의 동일한 정면 시점·비율 보존 배치를 사용한다. 기존 `painted/`는 이전 원본/다리용으로 보존한다. 정면 그림을 사선 회전하거나 X/Y로 다르게 늘려 측면을 만들지 않는다. 바닥 재질/그림자/건물·담장 충돌은 별도 층으로 유지하고 지도에서도 최종 표시 사각형을 사용한다. [최신 남경 개선](../docs/cities/nanjing-capital.md).

- 사용자 확정: 추론 모델/추론 강도에 관계없이 기존 일러스트·탐험 도트의 화풍·비율·품질을 동일 기준으로 유지한다. 새 그림 제작 전 [미술 일관성 기준](../docs/characters/art-consistency.md)의 승인 원본을 실제로 보고 이미지 생성 참조로 제공한다. 초상화의 사실적 비율과 탐험용 중간 SD를 혼동하지 않는다. 원본 크기만 보고 채택하지 말고 실제132 표시 높이/공통 발밑 비교표와 게임 내 대화에서 대조한다. 더 사실적인 피부·옷감/더 많은 디테일을 품질 향상으로 간주하지 않으며 기준과 어긋나면 재생성 후 반영한다.

- 앞으로 고유 초상화가 있는 주요 인물을 새로 구현하거나 전용 그림을 추가할 때는 같은 외형의 고유 탐험 도트도 함께 제작한다. `data/dedicated_npc_visuals.json`에 인물ID별 초상화·도트·투명 여백을 제외한 영역을 등록하고 공통 NPC 생성 경로로 모든 등장 맵에 적용한다. 실제 배치·일반 무사와의 구별·저장 복원을 확인한다. 일반 주민18장/시설 직업 공용 풀 재사용 규칙은 유지하며 기존 인물 전체를 요청 없이 일괄 재제작하지 않는다.

- 새 무공은 전용 아이콘과 함께 `data/martial_tactics.json`에 공격 칸·전진/후퇴·밀침 데이터를 등록한다. 범위·효과 그림은 공통 `martial_range_preview.gd`가 자동 생성하여 전투 왼쪽 하단과 K창에 표시한다. 방어·내기 회복·재사용 대기는 무공 카탈로그의 효과 필드를 사용한다. 별도 텍스트 설명만 남기거나 각 화면에 범위를 따로 하드코딩하지 않는다. 새 무공을 추가할 때 `tests/range_diagram_ui.gd`로 표시를 확인하고 문서용 범위 도해도 다시 생성한다.

- 새 아이템·무공을 추가할 때는 사용자의 별도 요청 없이 해당 콘텐츠의 전용 아이콘/일러스트도 생성하고, `data/icon_manifest.json`에 안정적인 ID로 연결한다. 기존과 같은 미술 규칙을 유지하되 새 상위 등급은 구별되게 만든다. 미등록 상위 시각 예시를 새 콘텐츠의 확정 이미지로 자동 전용하지 않는다.
- 전투 선택지, I 소지품, K 무공, 상점에서 새 이미지가 실제로 표시되는지 확인한다. `tests/combat_updates.gd`의 전체 카탈로그 이미지 검증을 실행한다. 이미지 생성 도구가 불가하면 누락을 명시하며 완료로 보고하지 않는다.
- 플레이어·적 모두 `combat_actions.gd`와 `inner_qi.gd`의 공통 계산을 사용한다. 적 예고는 플레이어 선택 전에 확정하고 선택/저장 불러오기로 재추첨하지 않는다.
- 새 전투 콘텐츠는 최소 학습 조건과 절정 진입 수준의 여러 무기/무공으로 초회 클리어 난이도를 점검한다. 테스트는 분리된 XDG 사용자 폴더에서 실행해 실제 저장을 건드리지 않는다.

- 무공 성장 곡선에 대한 사용자 확정: 상급을 포함한 모든 등급의 창법은 높은 고정 위력(`base_damage`)과 상대적으로 낮은 능력치 계수를 중심으로 만든다. 상급 검법·도법·권법·장법 등은 동급 창법보다 높은 성장 계수로 후반 효율이 앞서도록 설계한다. 상급 창법의 고정 위력은 등급에 맞춰 높일 수 있으나 높은 계수까지 자동 부여하지 않는다. 구체 수치는 개별 무공 제작 시 결정하며, 동급 장비·학습 직후/후반 성장 구간에서 비교한다. `docs/systems/spear-balance.md`를 따른다.

- 대사·UI는 한국어 무협풍을 유지한다. 사문·표행·강호·초식·출수 등의 표현은 인물의 신분과 상황에 맞게 쓰고, 민초는 생활감 있는 말투를 유지한다. 과도한 고어·한자어로 뜻이나 조작법을 흐리지 않는다. 보상·분기·말하는 인물·콜백은 문체 수정만으로 바꾸지 않는다.
- 서체는 제목·인물 이름에 번들된 붓글씨, 긴 대사·설명·수치에 번들된 명조체를 사용한다. 새 문구의 글리프 지원·줄바꿈·잘림을 확인한다. 새 무공·아이템 행은 공통 아이콘/하이라이트 처리를 사용해 마우스와 키보드 가시성을 유지한다.
- 적 행동 예고는 공격/수세 같은 큰 기세만 표시한다. 공격 종류·무공명·내기 비용·위력·전용 아이콘·툴팁을 예고에서 노출하지 않는다. 실제 출수한 뒤의 전투 기록은 구분한다.

- 수동 저장은 대화·거래·전투 중 금지한다. 버튼 비활성화와 실제 쓰기 차단은 `save_system.gd`의 공통 제한을 따른다. 탐험·분기 선택창 저장 및 구버전의 대화·거래·전투 저장 불러오기는 유지한다. 회귀 검사에 필요한 과거 저장은 테스트 전용 `legacy_save_fixture.gd`로 구성하며 런타임 우회 경로는 만들지 않는다.

- 도시 확장 시 바닥에 건물·담장·문을 다시 굽지 않는다. `city_scenery.gd`와 공통 프리팹의 투명 그림·발밑 충돌·Y정렬을 사용하고, 열린 문은 가운데 통행/좌우 기둥 충돌/지붕 가림을 함께 확인한다. NPC는 발뿐 아니라 전신 표시 영역도 건물과 겹치지 않게 배치한다. 미니맵과 전체 지도는 같은 오브젝트 배치를 따른다.
- 일반 마을 NPC는 별도 지시가 없으면 `data/basic_npc_portraits.json`의 기본18장(기존 공용10장+무창 주민8장)을 재사용한다. 성별·나이·직업에 맞춰 고르고 이름·설정과 그림 파일을 분리한다. 새 전용 이미지의 자동 제작을 금지하며 사용자가 별도 지시할 때만 추가한다.
- 한 대화의 다른 인물에게 같은 초상화 파일을 쓰지 않는다. 같은 성별의 기본 풀에서 빈 그림을 배정한다. 부족하면 대화를 나누는 등 구성으로 해결하고 자동으로 새 그림을 생성하지 않는다. 대화 기록은 현재까지 표시한 줄만 보여 주며, 미래 대사/미선택 분기를 노출하거나 읽는 동안 진행/보상을 발생시키지 않는다.

- Q는 의뢰 일지, F는 NPC/거래/조사, F2는 도움말, L은 실행된 교전 기록이다. 일반 의뢰는 실제 수락/보류·수행·완료 보고가 연결된 의뢰인에게만 !를 표시하고, 달성 후 ?/완료 후 제거 규칙을 따른다. 일반 의뢰는 별도로 확정한 선행·배타 조건이 없으면 모두 동시에 수락·진행·완료할 수 있는 것을 기본으로 한다. 새 의뢰마다 동시 진행 여부를 사용자에게 다시 묻지 않는다. 진행/완료/보상 상태를 의뢰별로 분리하고, 목표 추적 변경이 다른 의뢰를 중단하지 않게 한다. 공유 NPC의 진행 대화를 완료 잡담이 가로막지 않게 한다. 보상은 완료 대화 끝에서 한 번만 지급한다. `adventure-usability.md`의 현재 입구·저장 호환을 유지한다.
- 구매·습득·복용·의뢰 갱신 등은 공통 알림/효과음 경로를 사용하고, 커서 올림이나 적의 미래 계획을 소리/기록으로 노출하지 않는다. 환경 설정은 이야기 저장과 분리하고 새 상태 필드는 구버전 읽기 기본값·검증을 함께 추가한다.

- 맵 이동은 WASD/방향키만 사용하고 인물·조사·포탈은 F로 상호작용한다. 클릭 이동·인물 클릭 자동 접근을 재도입하지 않는다. 마우스는 전투·거래·인벤토리·지도 안내 등 UI 선택에 유지한다.

- 장사 밖의 일반 의뢰에는 오성을 기본 보상으로 자동 부여하지 않는다. 의뢰별 사용자 확정을 따르며, 무창 「돌아오지 않는 약초꾼」은 완료 보고 후200문만 지급하고 능력치·명성은 올리지 않는다. 무창 「품삯에서 빠진 세 줄」은 사용자 지정 예외로100문·오성2(상한200)를 보고 완료 후 한 번 지급하며 명성·호의도는 올리지 않는다.
