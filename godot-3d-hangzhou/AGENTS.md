# 독립 항주 3D 테스트

- 기존 `godot/` 본게임과 분리한다. 2D 저장/진행/컨텐츠를 바꾸지 않는다.
- 사용자는 NPC 없는 향락·사치의 항주, 긴 야시장, 수로의 유람선과 도원의 기존 청색 복장 기반 3D 캐릭터를 요청했다.
- 실제 메시/충돌/3인칭 이동을 사용한다. 2D 그림 판을 3D 캐릭터로 대체하지 않는다.
- `tools/build_dowon.py`와 GLB를 함께 유지한다. 플레이에 Blender를 요구하지 않는다. 새 메시 재생성 시 고유 얼굴·복장 기준을 보존한다.
- 기존2D 미술의 화풍 지침을 이 프로젝트에 픽셀 셰이더 강제로 적용하지 않는다. 얼굴/복식과 중국풍 세계관은 유지하고 스타일화3D로 표현한다.
- 새 동선을 추가하면 시작점·건물 충돌·카메라·다리·승선·물 복귀를 실제 물리 검사하고 스크린샷을 갱신한다.
- 외부3D 자산을 추가하면 배포 허용 라이선스/저작자/원본 주소를 보관한다.
