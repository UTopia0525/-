# 항주 · 등불과 물길 — Godot 3D 탐험 테스트

기존 2D 본게임과 별도로 실행하는 단일 플레이어용 3인칭 3D 프로젝트입니다. 2D 저장/퀘스트를 수정하지 않습니다. NPC·전투·의뢰는 없는 공간/캐릭터/조작 검증용입니다.

## Windows 실행

1. 저장소 폴더에서 `git pull --ff-only`로 업데이트합니다.
2. Godot 프로젝트 목록의 **가져오기**에서 `godot-3d-hangzhou/project.godot`를 선택합니다. 기존 `godot/project.godot`과 다른 프로젝트입니다.
3. 처음 에셋 가져오기가 끝나면 **F5**로 실행합니다. Godot4.6 이상, Compatibility 렌더러를 사용합니다. Blender는 플레이에 필요하지 않습니다.

| 조작 | 기능 |
| --- | --- |
| WASD / 방향키 | 카메라 방향을 기준으로 이동 |
| 마우스 | 시점 회전 |
| 휠 | 카메라 거리 조절 |
| Shift | 달리기 |
| Space | 뛰기 |
| Esc | 마우스 커서 풀기/시점 조작 복귀 |
| 화면 왼쪽 클릭 | 시점 조작 복귀 |
| Tab | 전체 전경 보기/돌아오기 |
| F1 | 조작/탐험 안내 |
| F3 | 저녁/밝은 조명 비교 |
| F4 | 그림자/MSAA를 끄는 경량 모드 |
| M | 음악 일시 정지/재생 |
| R | 시작 위치로 복귀 |

시작 위치에서 물길을 따라 북쪽으로 걸으면 긴 야시장과 취월루가 보입니다. 두 아치형 다리로 양쪽 거리를 오갈 수 있습니다. 동쪽 나루의 경사판을 통해 등영화방 유람선 갑판에 걸어서 올라갈 수 있습니다. 취월루는5층 외관과 출입 가능한1층을 갖추며 위층 이동은 없습니다. 물에 빠지면 시작 위치로 돌아옵니다.

## 제작 범위와 자산

- 독립된 실제3D 지형/건축: 장식된5층 취월루, 양쪽 수변 상가, 비단·도자기·과일 노점, 홍등 줄, 야외 찻상, 돌다리2개, 나루와2층 누각 유람선.
- 수면 셰이더의 잔물결과 등불빛, 저녁 하늘, 안개, 그림자/창문·등불 발광을 사용합니다. WoW급 완성 자산이 아니라 공간과 동선을 검증하는 자체 제작 스타일화3D 시제품입니다.
- 도원은 기존 초상화의 청색 겹깃 무복·흰색 속깃·갈색 띠/손목 감개·검은 묶은 머리/삿갓 없음에 맞춰 제작한 독립 GLB입니다. 얼굴·손·신발·겹옷·머리카락이 실제 입체 메시입니다. 관절 노드로 다리/팔 보행을 구동합니다. 이미지 판을 세운 캐릭터가 아닙니다.
- 모델 생성 원본은 `tools/build_dowon.py`입니다. 재생성에만 Blender4.3+가 필요하며 `blender -b --python tools/build_dowon.py`로 GLB를 만듭니다.
- 건축과 캐릭터는 이 프로젝트에서 생성한 원본 형상이며 외부 상업용3D 에셋은 없습니다. 건축은 재료별로 메시를 합쳐 그리기 호출을 줄였습니다.
- 글꼴은 기존 프로젝트의 NanumMyeongjo/NanumBrushScript를 재사용하며 OFL을 동봉했습니다. 음악은 기존 자체 제작 항구 BGM을 재사용합니다.
- 기존2D 전투/의뢰/저장과는 연결하지 않습니다. 설치 없이 실행하는 웹 버전이나 Windows 실행파일은 별도 내보내기하지 않았습니다.

## 검증과 캡처

`godot --headless --path godot-3d-hangzhou --script res://tests/smoke.gd`는 모델/관절·시작 지면·W이동·두 다리 횡단·유람선 승선·건물 충돌·물 복귀·취월루 입장·카메라 벽 회피·경량 모드·NPC 미배치·BGM 반복을 검사합니다. 기존 저장과 분리된 XDG 폴더에서 실행했습니다.

`tests/capture.gd`는 실제 Godot 렌더를 `screenshots/`에 저장합니다. GPU가 없는 개발 환경의 llvmpipe 캡처는 느릴 수 있으며 일반 PC의 성능 수치를 대신하지 않습니다. 시작 위치/조명/카메라를 최종 조정한 뒤 생성합니다.
